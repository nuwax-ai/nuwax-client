# 客户端扩展与 Agent 环境配置

开发验收统一运行集成分支的 **Nuwax Dev**：

```sh
npm run dev -- --frontend source
```

此模式使用 `~/.nuwax-dev` 开发档案，不复制安装版账号或插件数据。主题与 DSH 保持各自的包格式，通过同一壳能力入口供 Agent 使用。

## 用户入口

设置页的「Agent 环境配置」分别控制主题、客户端偏好和受信插件管理，默认均关闭。授权按服务域和账号保存；登出、换域或关闭开关会撤销已有连接及排队中的主题修改。MCP 自身没有扩大授权的工具。

- **主题**：Agent 读取规范和当前文件，将内置主题或关联目录复制成个人主题，提交修改并选择应用。保存前校验完整包和读取版本；无效修改不发布，冲突须重新读取。
- **客户端偏好**：首批开放链接打开方式，取值为客户端内打开或系统浏览器。其他设置键不可写入。
- **受信插件**：对接 DSH 原生 Plugin Manager 安装、启用、禁用和移除额外 Bundle；核心运行包受保护。安装的插件会执行本机代码。
- **插件配置**：只开放第三方插件在 DSH Settings 中声明的公开实时字段，复用配置格式、revision 和秘密字段脱敏。核心模型、宿主与运行时配置不开放。

DS-Bot 使用 DSH 原生 MCP Client，授权变化会动态替换工具连接。现有 Nuwax Agent 通过已有本地 MCP 登记和代理获取相同工具。DS-Bot 需要先完成自己的 Nuwax 模型授权并启动，才能管理其插件。

## 恢复和结果

个人主题修改落到客户端管理的实际目录。多文件先写入暂存目录，全部校验后更换目录并提交注册表，最后发布完整快照。用户关联的外部目录继续由原有监听器读取，Agent 编辑其个人副本。

主题注册表保留最近最多五份恢复记录，并限制历史总大小；重启后仍可使用。设置页的「主题修改历史」可恢复文件及当时的主题选择，即使 MCP 已关闭也可由用户操作。

「近期环境变更」记录当前账号的操作类型、时间及结果，不记录文件正文、配置值、平台凭据或包管理器输出。插件操作保留原生 `application` / `restartReason` 等结果；需要重启时仅报告已保存。撤销授权阻断新调用，并请求原生管理器取消进行中的安装；原生管理器已进入应用阶段的操作可能无法撤销，插件代码的外部副作用不属于主题回退范围。

DS-Bot 独立界面的视觉样式仍由其上游主题系统管理；Nuwax 主题覆盖桌面壳及已适配的业务界面。

npm run typecheck:main

真实 DS-Bot 集成测试运行原版 DSH、DS-Bot 和原生 MCP Client，用确定性模型验证主题读取、个人副本、文件修改、应用、恢复及撤权。它不替代真实平台模型、实体麦克风或签名安装包验收。CI 商业门禁安装锁定的 DSH 依赖后运行该测试，原生平台任务另验 MCP 连接和插件管理。

### Dev 模型联调代理

未打包且设置 `NUWAX_DEV_PROFILE=1` 的进程可通过 `NUWAX_DSH_DEV_MODEL_PROXY` 和 `NUWAX_DSH_DEV_MODEL_PROXY_TOKEN` 接入一次性测试代理。地址仅接受带端口的 `http://127.0.0.1`，令牌须为 64 位十六进制随机值；无参数时继续使用平台代理，安装包忽略这两个参数。

测试代理使用平台模型路由格式 `/<modelId>/v1/messages` 或 `/<modelId>/v1/chat/completions`，自行持有真实上游凭据。客户端仍验证已有平台授权、所选模型、请求体模型及当前账号代次，向测试代理只发送短期本地令牌。参数在主进程消费后从环境移除，不进入 DSH 子进程、模型目录和设置库。测试代理须独立限制目标模型、拒绝未授权请求，并在验收后关闭；该结果单独标记为 Dev 直连验收，不证明平台模型代理已恢复。
