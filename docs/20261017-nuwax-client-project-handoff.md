## 3. Windows 安装与升级、完整产品缺口 🔄

- **背景**：最近刚升级了 Windows 的安装和升级体验。
- **已进 beta.5**：
  - 一键升级 `edd25e2a`，只在 win32 上生效。
  - 升级中断恢复 `af8a4c2c`。
  - 「新版本就绪」状态 `a65c537a`。
  - 系统应用名 `03ddf967`。
  - Win10 1511 终端兼容 `e8f1b70a` 和 `4b451aa8`。
- **现状**：
  - 安装器是 NSIS 加 MSI，只有 x64，`oneClick=false`。MSI 不能自动更新。
  - 每次升级都是全量下载，没有增量更新。
  - 安装调用的是 `quitAndInstall(false,true)`，升级时可能还会弹出安装窗口，要实机确认。
- **缺失梳理结论**（已完成，只读）：
  - **高优先**：
    1. 安装耗时 14 到 16 分钟。
    2. 卸载会递归删除安装目录里未知的工作区（U1），有丢数据风险。
    3. beta 包未签名，安装时出 SmartScreen 提示。
    4. 主窗口放行任意 http(s) 导航，`openExternal` 不校验协议。
    5. `agentRunner` 用 `shell:true`，apiKey 出现在命令行里。
  - **中优先**：
    - 没配 `uninstallDisplayName`，卸载列表显示名大概率还是 Nuwax。
    - 没有 deep link，也没有文件关联。
    - 没有 Windows ARM64 包。
    - Win10 1511 只在 Win11 上回归过。
    - Linux 只有 AppImage 在自动更新范围内。
    - Mac 和 Linux 的升级还是两步。
  - **低优先**：
    - `autoUpdater.ts:119` 有 UTF-8 拼接问题。
    - 兜底地址指向社区版。
    - 卸载没有清理数据的选项，也没有防火墙提示。
    - 静默安装参数 `/S` 没写文档、也没验收。
- **建议顺序**：
  1. 在 win-pc 上实机验 beta.5：卸载显示名、升级窗口、安装耗时。
  2. 修 U1，并加上清理数据的选项。
  3. 收口三个安全项。
  4. 修 NW-050 和 UTF-8 拼接问题。
