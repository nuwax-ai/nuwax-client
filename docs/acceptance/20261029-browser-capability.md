# v3.1.0 浏览器扩展能力验收

2026-10-29。客户端分支 `release/v3.1.0`，浏览器实现已提交，并合入该发布线的远端修复。Beta.9 的前端源码固定为 `b56f85f8bf8d916bca67cd81dea9edc4d407e8a4`，产物固定为 `3371cca424e591eed39404d78face88729164bbd`，两者均已推送并提交双 pin。以下区分源码、本机 Electron 与安装包构建证据，真实安装验收仍待完成。

## 实现

- `browser` 按现有 DesktopFeature 静态注册，仅 nuwax 默认启用，关闭/注册失败回退系统浏览器。首次打开才创建网页窗口。
- 客户端设置选择应用内独立窗口或默认浏览器，保存后下一次点击立即生效；能力不可用时不展示应用内选项。
- 独立窗口具备标题/域名/完整链接查看、后退/前进/刷新/停止、复制、外部打开、查找、50%–300% 缩放、打印和原生置顶。
- 复用 electron-browser-shell 固定提交 `3817c4236f8511156086eb4541f364679b277b40` 的网页承载代码。源码旁保留原始 MIT 文本与改造说明，并通过独立 `third-party/source-components.json` 在打包阶段合并声明。原生采集配方、总清单及生成器保持原字节，capture-only 声明字节等价测试通过。
- 普通外链统一分流。支付显式用途及旧前端未标注的外域 native.openWindow 调用保留专用窗口；业务窗口中的普通外链仍遵循偏好。POST、referrer、opener、登录凭据、下载和离开确认继续由宿主策略负责。

## 2026-10-30 窗口与导航修复

本轮基于客户端 `793c1265` 修改浏览器模块。修复验证后用户授权提交并发布新的 Beta，发布目标使用下一可用版本 `v3.1.0-beta.11`；Beta.10 已在另一条维护线占用，未移动或续跑该标签。安装后功能验收由用户执行，以下本机和源码证据不代替安装包验收。

- 系统标题栏合并到 52px 工具栏。macOS 使用 `titleBarStyle: hidden`，左侧预留原生红绿灯位置；Windows/Linux 使用与客户端主窗口一致的无边框方式，右侧显示最小化、最大化/还原、关闭按钮。按钮均为非拖拽区域，窗口控制仅通过所属工具栏的受限 IPC 执行。
- 导航失效源于 `dialog.showModal()`：原生网页 WebContentsView 位于工具栏 renderer 之上，遮住网址弹窗，模态遮罩又拦住工具栏。改为可收起的非模态网址行；主进程按照固定行高调整网页视图边界，不接收任意 renderer 尺寸。网址和查找同时展开时边界为 136px，单行展开为 94px，全部收起为 52px。
- “复制链接”作为工具栏独立图标，并从更多菜单移除。窗口控制复用已有四语文案，颜色跟随客户端主题。关闭按钮继续调用 `window.close()`，保留网页离开确认与宿主清理流程。

## 2026-10-30 Beta.11 反馈：打开窗口延迟

修复基线为 `22dc99aa`（Beta.11）。原逻辑在本地工具栏就绪后还等待远端文档，再于 DOM 就绪时显示窗口；慢响应或阻塞脚本会直接推迟窗口出现。现改为导航开始且本地工具栏就绪后显示窗口，首文档提交前隐藏原生网页视图，显示本地加载提示；文档提交后切换至网页。不在客户端启动时预建窗口。

- 先加入扣住首响应的 Electron 夹具，修复前在工具栏就绪后等待 1.5 秒仍未显示，断言失败；修复后在服务端没有发送响应时即调用显示，本机两次记录为 107ms、79ms。这是本机夹具数据，不表示所有网站或所有系统都能在同一耗时内完成加载。
- 原生 GUI 检查中将响应额外扣住 8 秒，实际窗口已显示工具栏、“停止加载”和本地加载提示。
- 初始页面尚未提交时，停止后重试改为加载已请求的网址，避免 `reload()` 只重载 about:blank；加载期间关闭、既有导航/查找/缩放/置顶/离开确认回归通过。
- 浏览器的显示和聚焦仅由模块负责，宿主不在远端 DOM 到达后再次聚焦。专用业务窗口继续沿用原来的文档就绪策略，两种所有权路径有单元回归。
- 新增 direct/gateway × window/webview 四个真实下载场景：服务器扣住响应期间浏览器先显示；返回文件后自动隐藏，下载完成后清理窗口，文件字节完整。原有 14 次下载/18 个专用窗口回归也通过。
- 浏览器/宿主域测试 70 项通过；主进程/preload 与 renderer 构建通过；模块边界和宿主桥快照检查通过。12:34 的商业门禁为 3786 通过、18 跳过，结果对应当时工作区快照；更新器、活动状态等另有并行改动，保留原状，不属于本轮浏览器修复。

本节修复尚未发布新的安装包；Beta.11 内容保持不变。Windows/Linux 原生安装后的窗口时机仍待对应平台验收。

## 2026-10-30 紧凑头部

- 主界面 Windows 窗口按钮为 40×28px，原浏览器头部为 52px。本次头部收紧为 36px，导航按钮 28px、图标 16px；Windows/Linux 窗口键宽 40px，点击区域覆盖 36px 整行，便于在顶部边缘操作。
