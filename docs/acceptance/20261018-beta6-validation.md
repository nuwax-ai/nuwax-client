## 基线已经具备的能力

- Windows 一键更新、进度展示、安装范围保持、旧版本退出及新版自动启动；更新提示「新版本就绪」与版本说明入口。
- Windows 安装中断恢复、中文 PowerShell 兼容、早期 Win10 的 WinPTY 内嵌终端后端。
- 中文系统应用名及 Finder 多种中文 locale 显示名，商业更新配置入包及 ZIP/DMG 校验。
- 登录/登出/企业换域生命周期、内置 ACP 引擎、普通项目多会话隔离（NW-041）。
- 现有截图、录屏、剪贴板和 IM 宿主能力探测；开源许可证入口。
- 已合入的 Computer Use 基础控制。未承诺所有 OS、多屏、DPI、UAC、Wayland 或 OSWorld 指标已通过。
