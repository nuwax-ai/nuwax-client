# Windows 一键升级验收（2026-10-16）

## 实现范围

- 基座更新服务提供默认关闭的 `installAfterDownload` 策略，商业组合根仅对 Windows 启用。关于页、业务版本徽标、菜单和托盘复用下载/安装入口。
- 更新任务覆盖下载、校验、安装前清理和启动安装器；并发入口复用同一任务，成功后保持占用到退出，失败可重试。新增 installing 状态，检查更新不得打断当前任务。
- 商业 NSIS 仍为 assisted（oneClick=false）：首次安装保留范围、目录和完成页；`--updated` 跳过交互页、沿用当前路径和范围，完成后以桌面用户启动新版并自动关闭。
- 目录页被跳过时也跳过 vendor 的路径追加逻辑，防止自定义旧目录被追加产品名。
- Windows 在窗口和 IPC 可用前初始化更新策略及退出清理回调；后台复检通过同一检查入口，遵循自定义更新源。
