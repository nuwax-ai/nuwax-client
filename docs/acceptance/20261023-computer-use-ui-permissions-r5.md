## 本批行为

- 客户端内 300×220 预览默认右上，可在窗口内拖动；关闭仅隐藏显示与预览采集，托盘可重开。
- 预览只列运行/暂停对象，可切换并调整显示顺序。排序不修改执行调度，修复相同执行 revision 下列表未刷新的问题。
- 接管/停止保持可见；多窗口接管继续使用原有撤权、排空、精确激活；旧单任务接管暂停自动操作，由用户切回目标窗口。
- 托盘“电脑操作”入口显示活动对象和最近 100 条结束摘要。历史只含名称、时间、步数、结束状态，不保存图像、输入、剪贴板或可恢复的授权。
- 权限拖拽卡片归属主窗并跟随隐藏/最小化/关闭，不抢系统设置焦点。daemon 静默启动，缺权限时失败关闭；权限请求限于明确点击，single-flight、20 秒有界且可取消。
- 退出/取消先撤销本次私有结果文件，再精确清理对应权限宿主。原生宿主在系统请求前以 O_NOFOLLOW 打开预创建文件，验证当前用户、0600、普通文件、单链接，并持句柄写回；解决 LaunchServices 迟到派生的取消空窗。
