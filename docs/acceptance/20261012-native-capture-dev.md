## 用户验收操作

1. 点击客户端顶部导航旁的相机按钮「截图与录屏」，选择画质。
2. 截图：选整屏、窗口或区域；区域拖动框选；可加矩形、椭圆、箭头、画笔、文字、马赛克并撤销重做；确认后检查预览和尺寸，再点击保存。
3. 录屏：选择 MP4、WebM 或 GIF，再选择来源；3 秒倒计时后录制；测试暂停、继续、停止；检查结果预览、尺寸和时长并保存。托盘也有停止入口。
4. 取消：选择器按 Esc 或点击取消；录制控制条点击取消；再次发起应恢复可用且不留下结果。
5. 检查原始物理像素尺寸，没有随画质档位缩小；最低档超过 maxBytes 时，调用方应看到 exceedsMaxBytes，而不是收到缩小图片。

IM 的原有按钮尚未接入新桥，不能用来验收本次原生实现。接入契约见 `docs/native-capture-api.md`。

追加菜单入口：macOS 系统菜单栏的「截图与录屏」、Windows 既有自绘菜单的同名入口。应用内截图快捷键为 `⌘⌥S` / `Ctrl+Alt+S`，MP4 录制为 `⌘⌥R` / `Ctrl+Alt+R`；没有注册后台全局快捷键。macOS 本轮已通过真实菜单点击进入截图选择器，快捷键和 Windows 实际操作列入用户验收。

IM 负责人交接见 `docs/nuwax-im-native-capture-integration.md`，包含既有 IM 的接线位置、窄窗菜单、独立读取示例、错误/生命周期处理与多屏联调清单；IM 业务代码未修改或部署。

## 选区与操作条联动修正（2026-10-12 晚间）

用户反馈：录制的区域/屏幕与控制 UI 脱节。根因是录制控制条原本优先放到另一屏，截图模式/标注条固定在屏幕顶底。

- 截图模式、标注和确认现在在同一选区旁浮层中；重新框选后立即跟随。拖动框选时隐藏，松开后显示。
- 定位共用 DIP 规则：选区下方 → 上方 → 侧边；整屏或无外部空间时放到所选屏工作区底部，避开菜单栏/Dock，不自动跳其他屏。
- 倒计时、录制、暂停、继续、处理中控制条保持位置，仍可手动拖动。暂停边框同步为黄色虚线，处理时移除边框且不触发取消。
- 窗口来源仍缺少真实 OS 窗口边界，工具栏放在执行窗口选择的屏幕；不宣称跟踪目标窗口跨屏移动。
- 51 项定向单测通过：窗口定位16、窗口生命周期13、录制6、窗口安全11、preload5；features 严格类型检查、主进程开发构建、桥契约、模块边界、pin 与差异检查均通过。overlay 232 文件一致。
- 隔离双屏真实 Electron DOM/IPC 验证通过：副屏负坐标、1.25x 像素映射；截图与录制两种模式的操作条都跟随两个不同选区、底部自动翻到上方；录制窗口在 countdown/recording/paused/recording/encoding 五次状态变化中保持 `(-1020,156,440,60)`；处理时仅边框销毁，录制未被意外取消。
