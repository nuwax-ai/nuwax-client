# 3.0.17-beta.7 功能与验证清单

本版只在 beta.6 上修正 Windows 无效授权入口和升级进度弹窗。其余功能、未纳入项及业务回归范围沿用 [beta.6 完整清单](https://github.com/nuwax-ai/nuwax-client/blob/41ec712ee317e96222a27fd8e601643f80c9c53c/docs/acceptance/20261018-beta6-validation.md)。beta.6 的 Windows 授权说明页验证项由本版的「不显示入口或页面」取代。

- 已公开 [v3.0.17-beta.7](https://github.com/nuwax-ai/nuwax-client/releases/tag/v3.0.17-beta.7)，发布时间为 20:25（Asia/Shanghai），不可变 tag 指向 `cb436f9d5a0e25377c90de507bdd82d9d9515b01`。本节和功能总览是发布后补记，未移动 tag 或改变产品源码。
- [GitHub Actions](https://github.com/nuwax-ai/nuwax-client/actions/runs/39121986639) 首次运行通过完整源码门禁与五平台构建，29 个发布资产完成 SHA256 校验；macOS 两个架构均完成 Developer ID 签名和 Apple 公证。
- S3、OSS 的 Beta 指针字节一致，均为 `3.0.17-beta.7`；稳定版仍为 `3.0.16`，两处稳定版指针与发布前逐字节一致。详见 [发布校验记录](./20261018-beta7-publication.json)。

- 以下人工清单仍需实际执行，模拟桥界面验证、构建及发布校验不等同于真实安装、升级和业务验收已完成。

## 本版功能总览

以下包含 beta.6 已集成的 worktree 成果和 beta.7 修正，方便直接按功能验证；构建通过不代表各操作系统人工验收已完成。

| 功能 | 本版行为与验证重点 |
| --- | --- |
| Windows NSIS 安装、升级与卸载 | 一键下载安装、保留安装目录和范围、重启新版；升级保护额外文件；卸载默认保留本地数据，主动勾选才清理列出的当前用户目录；MSI 沿用官网下载入口 |
| 升级反馈 | 关于页及包内版本徽标下载、安装时只有按钮和行内状态；失败可查看详情并重试，不再另弹 loading／进度框 |
| macOS／Linux 更新 | 下载后再次点击安装；Linux 分 AppImage、deb、rpm，按各自文件替换／系统包管理流程升级 |
| 平台权限 | Windows 不显示无操作的授权入口；macOS 保留首次总览、逐项授权、轮询及重启提示；Linux 保留现有说明和截图自测 |
| 业务新窗口 | 普通 HTTP(S)、企业子域、非默认端口、相对业务路径及跨域导航保持可用；重点验证 window.open、target=_blank、原生新窗、SSO 和下载跳转 |
| 错误与会话 | NW-050 错误、截断、拒答、轮次上限明确结束为失败；400 不重复重试；既有 NW-041 多会话消息、取消与状态隔离 |
| 登录与服务 | 登录、登出、企业换域共享主进程生命周期，避免重复注册和旧账号状态串用 |
| 截图、录屏与 IM | 保持现有选区、复制、保存、录制格式及宿主能力探测；按真实系统权限验证 |
| Windows 终端 | 保持中文输入输出、尺寸调整和 Ctrl+C；早期 Win10 的 WinPTY 需由对应旧系统验收 |
| Computer Use 与品牌 | 保持已有基础控制，macOS helper 使用主应用图标；中文应用名称与四语言界面保持 |

本地文件直访仍由发布门控关闭；大规模 Computer Use 产品化、终端多开、pi-agent、NW-009、NW-044、Windows ARM64 原生包等未新增。完整边界与其余人工步骤见上方 beta.6 清单。

## 人工验证

| 场景 | 操作与预期 |
| --- | --- |
| Windows 首次运行 | 使用独立测试账号或虚拟机快照中的全新应用数据打开 beta.7；不出现权限总览或授权说明弹窗，普通聊天及实际支持的功能可用 |
| Windows 设置 | 打开设置；侧栏没有「授权」，不再展示「无需预先授权」等说明页；已有设置、截图与录屏入口保留 |
| macOS 权限 | 首次引导、设置入口、授权／撤权、重新检测及重启提示按 beta.6 清单回归 |

| 关于页一键升级 | 在运行 beta.7、存在更高测试版本时发起 Windows NSIS 更新；下载与安装保持行内状态，不再出现额外进度框，宿主继续负责安装和重启 |
| 关于页分步升级 | macOS／Linux 下载完成后仍需明确点击安装；安装等待期间只在按钮反馈，不出现额外应用内进度框 |

| 失败与重试 | 在测试环境中验证下载失败、宿主拒绝安装及迟到的安装错误；错误有详情、等待态释放，可重试且不重复提交 |
| 其它回归 | 登录、服务生命周期、业务新窗口及外域链接、文件保护、截图录屏和正常会话沿用 beta.6 清单 |
