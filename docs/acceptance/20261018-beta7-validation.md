# 3.0.17-beta.7 验证清单

本版只在 beta.6 上修正 Windows 无效授权入口和升级进度弹窗。其余功能、未纳入项及业务回归范围沿用 [beta.6 完整清单](https://github.com/nuwax-ai/nuwax-client/blob/41ec712ee317e96222a27fd8e601643f80c9c53c/docs/acceptance/20261018-beta6-validation.md)。beta.6 的 Windows 授权说明页验证项由本版的「不显示入口或页面」取代。

## 源码范围

- 基座 pin：`51177cd6b8190510d016f24e1a21f0a5e1350296`，只移除关于页的延迟安装进度弹窗。
- 前端 pin：`cc1bda80eaa59e075616df1fef3f7ac0c33363d2`，只调整客户端版本徽标及其测试；没有引入独立前端分支的其它改动。
- 产物 pin：`c16358ad0b200dda0a0a3fa8c45f14ae9c2a02a1`，构建戳 `cc1bda80e`。资料库及 IM 子模块 pin 不变。
- 商业 overlay：Windows 隐藏授权导航、入口、页面内容，主进程不再发起无实际步骤的授权引导。没有关闭 Windows 其它功能或安全机制。

## 人工验证

| 场景 | 操作与预期 |
| --- | --- |
| Windows 首次运行 | 用新的测试 profile 打开 beta.7；不出现权限总览或授权说明弹窗，普通聊天及实际支持的功能可用 |
| Windows 设置 | 打开设置；侧栏没有「授权」，不再展示「无需预先授权」等说明页；已有设置、截图与录屏入口保留 |
| macOS 权限 | 首次引导、设置入口、授权／撤权、重新检测及重启提示按 beta.6 清单回归 |
| Linux 权限 | 保持现有平台说明与截图自测；不显示 macOS TCC 开关 |
| 关于页一键升级 | 在运行 beta.7、存在更高测试版本时发起 Windows 更新；下载与安装保持行内状态，不再出现额外进度框，宿主继续负责安装和重启 |
| 关于页分步升级 | macOS／Linux 下载完成后仍需明确点击安装；安装等待期间只在按钮反馈，不出现额外应用内进度框 |
| 版本徽标 | 包内前端按上述一键／分步策略操作，日志卡、行内状态和错误提示可用；在线网页徽标应先确认站点已部署相应前端修复 |
| 失败与重试 | 在测试环境中验证下载失败、宿主拒绝安装及迟到的安装错误；错误有详情、等待态释放，可重试且不重复提交 |
| 其它回归 | 登录、服务生命周期、业务新窗口及外域链接、文件保护、截图录屏和正常会话沿用 beta.6 清单 |

注意：beta.6 升级到 beta.7 的首次操作使用 beta.6 的旧界面。不能用该次升级仍出现旧弹窗，判断 beta.7 中的新界面未生效。未代替用户触发 UTM 中的下一次升级。
