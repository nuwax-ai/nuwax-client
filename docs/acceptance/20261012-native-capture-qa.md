# 原生截图与录屏提测单

日期：2026-10-12。客户端分支：`codex/native-capture`。范围：本轮开发客户端与业务 API；真实安装包和 IM 菜单部署另行验收。

## 提测基线

- Electron 基座 pin：`484ff6b36e73c21c0a5dc1b01aeae9fb6d07c106`。
- 前端源码 pin：`7b6c5e6f91`，在客户端原有 `6f3985583f` 上仅新增公开桥契约与 `getCaptureBridge`；未夹带工作区的 IM/资料库 pin 变更。
- 当前开发平台：macOS arm64；业务页直接加载 `https://testagent.xspaceagi.com`。
- 入口：客户端相机、「截图与录屏」菜单；应用内 `⌘⌥S` 截图、`⌘⌥R` MP4。Windows 对应 `Ctrl+Alt+S/R`，尚待真机。
- 独立操作完成后进入客户端预览与保存。IM 菜单须由 IM 调业务桥，完成后回填原会话的待发送附件区；当前 IM 尚未接线/部署。

## 测试顺序与预期

| 优先级 | 操作 | 预期 |
| --- | --- | --- |
| P0 | 菜单、相机、快捷键分别启动截图/录屏 | 同一原生流程；连续点击不会重开或抢占正在进行的操作 |
| P0 | 主屏/副屏分别选整屏、窗口、区域 | 来源与结果属于所选屏；不同画质不缩小像素；窗口使用真实帧尺寸 |
| P0 | 重选区域，并靠上下左右边缘框选 | 图标操作条随选区移动，空间不足翻到另一侧，留在所选屏内 |
| P0 | 录制倒计时、暂停、继续、停止 | 工具条保持位置；计时排除暂停；红框直角且四边均匀；暂停黄虚线，处理时移除边框 |
| P0 | MP4 / WebM / GIF 分别短录制、预览、保存后打开 | MIME/扩展名、时长、尺寸正确；视频能播放，GIF 能动；文件不是空文件 |
| P0 | 区域录屏选奇数宽高，检查输出边缘 | MP4 偶数对齐处理正确，红框/控制条不进入画面；以结果尺寸为准 |
| P0 | 在任一屏按 Esc 或取消，随后再次启动 | 全部覆盖层关闭，不产生附件/空文件，下一轮可用 |
| P1 | 矩形、椭圆、箭头、画笔、文字、马赛克、撤销重做 | 图标、悬停提示与操作一致；标注只在选区内，保存结果保留标注 |
| P1 | 四档画质、maxBytes、上传限额、长录制 | 不缩放尺寸；超限可识别；不返回损坏或半成品 |
| P1 | 录制中锁屏/挂起/拔屏/登出/换域 | 取消采集、清理窗口/临时文件；旧句柄不可继续读取 |
| P1 | Windows 混合 DPI、负坐标、横竖屏、上下排列 | 控件与来源对应，输出按实际物理像素，边缘不串屏 |

IM 项目另测：菜单发起截图及 MP4/WebM/GIF → 完成后进入发起会话附件区 → 用户确认发送 → 对端预览/播放/下载。录制中切聊天不能错投新会话；取消不生成附件；超限/权限拒绝/编码失败有明确提示。接线步骤与独立适配器见 [IM 交接指南](../nuwax-im-native-capture-integration.md)。

## 已知限制和安装包阻塞

- 不采音频、不支持跨屏拖一个选区、WebP 暂不可用；HDR 尚未真实色调映射。
- 窗口来源没有 OS 桌面边界，工具条保留在发起选择的屏幕，暂不跟随目标窗口跨屏移动。
- 全屏控制条排除、真实双屏混合 DPI/HDR、Windows、长录制与正式安装包仍待实机；不能因 contentProtection 或模拟测试通过就判通过。
- capture 的 FFmpeg/libvpx 严格来源与声明检查通过；实际商业包的旧资源仍有 **13 项声明/许可证缺口**，严格 pack 门禁会阻止出包：uv、ripgrep、lanproxy、ttyd、node、mcp-proxy-ts、nuwaxcode、nuwax-codex-acp-ts、nuwax-file-server、claude-code-acp-ts、computer-use 未登记，以及 agent-kit/applescript 许可证未知。本次不绕过门禁。
- 暂无签名安装包/生产发布；源码提交后仍需同步相关仓库提交并走正式打包链，才能开展安装/升级验收。
