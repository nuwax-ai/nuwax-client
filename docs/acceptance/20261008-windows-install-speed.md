## 后续验收需要补齐

1. 同一 win-pc、相同资源和前端 pin、相同旧版本与安装模式，比较默认 7z 和显式 ZIP QA；下载耗时单独计量。
2. 从安装进程开始采样，分别记录关闭/确认等待、旧文件移除、归档展开、复制、临时目录清理和客户端启动；取得退出码及新包版本。
3. 在原实时防护设置下同步记录安装器、Defender 和物理磁盘活动；用按文件归因的记录确认扫描热点。
4. 同时验证中断/失败恢复和更新缓存行为。只有耗时下降且这些行为通过，才推进默认安装策略。

此前 3.0.10 的约 14 分钟 GUI 观察含约 3 分钟关闭确认等待，见 [release-channels](20261008-release-channels.md)。两次的版本和计时边界不同，不能直接当作回归幅度或 7z/ZIP 对照。
