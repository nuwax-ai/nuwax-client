# 电脑操作浮窗 UI 重构与源码预览记录

本次从 `fix/stable-3.0.22` 的 Beta.5 源码 `a81419fb` 继续，只调整浮窗界面和拖动边界。用户已要求停止退出问题排查，未完成的更新加强改动已另存补丁，本次交付不含该改动。

## 界面变化

- 单任务面板改为 288px 宽的圆角卡片，运行和普通暂停状态均约 183px 高；顶部为状态和关闭，中间为当前对象及最近操作，底部固定接管、停止和次级暂停/继续按钮。
- 默认客户端右上角。拖动和缩小窗口时按卡片实际尺寸限制位置；关闭仅隐藏预览，托盘入口可重新显示。停止按钮在其他控制操作等待时仍可用。
- 普通暂停以状态和继续提示表达；需要处理的暂停原因另行展示。桌面模式接管明确提示自动操作已经暂停、用户可切换窗口操作，避免暗示已经完成窗口聚焦。
- 亮暗主题、中英文长文案及窄窗均保留按钮。多窗口预览统一配色、圆角、状态栏和接管/停止操作，整理掉重复覆盖的旧样式；沿用既有任务切换、排序及 IPC。
