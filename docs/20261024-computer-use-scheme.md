## 2. 开关与上下文注入（用户零配置）

- **开 CU**：客户端动态注入 `cua` MCP + CUA 用法提示到本地 agent 会话上下文。  
  配方固定：先观察 → 优先 `element_index` → 坐标兜底 → 动作后复核；用户**无需**手配 MCP 或 skill。
- **关 CU**：上下文中**完全不出现** CUA 工具与指导。
- **同会话先开后关**：翻转时注入短指令，明确「CUA 已关闭，勿再调用桌面控制 / cua 工具」。再开可发「已重新开启」短指令。

## 3. Agent 光标

- **默认开启** agent cursor 可视化（Background 投递，不移动用户真指针）。
- 设置里保留 **光标开关**（可关）。

## 4. 授权模式（配置项）

- 做成用户可配：
  - **询问式**：敏感/约定动作执行前询问用户；
  - **全部开启**：开关打开后不逐次询问（仍受黑名单与硬禁约束）。
- 首次开启仍要同意书；macOS 系统授权（辅助功能 / 屏幕录制）走现有引导。

## 5. 安全边界 — 黑名单软件

- 用户可配置 **黑名单软件**；CU 遇到则 **直接跳过**（不操作该应用/窗口）。
- 发现软件两层：
  1. **静态**：已装应用列表（macOS：`/Applications` + `mdfind`；Windows：注册表 / 开始菜单）；
  2. **运行时**：窗口枚举实时比对黑名单。
- 范围策略（不再暴露「整个桌面/限定窗口」UI）写入 **提示词 / guidance**，由 agent 自决，但黑名单硬拦优先于模型决策。

## 6. 截图隐私

- 明确并实现：截图**存储位置**（本机 CU 数据目录，默认不上传）。
- **敏感内容**处理：密码框等（如 `AXSecureTextField` / 锁屏类）打码或跳过送模（实现选与现有能力一致的最小可靠方案，默认偏严）。
- 留存：任务结束后短期清理；导出诊断前可预览列表。同意书写明会截屏。

## 7. 容器与宿主机 GUI

- **本 beta 产品边界**：helper 与用户同机同交互图形会话；**不做**容器内 helper 直控宿主机 GUI。
- 若未来需要：宿主机装 helper，容器内 Agent 经本机私有 socket / MCP Proxy 调用（另开需求，不进本 beta 范围）。

## 8. 删除操作范围配置

- 删除用户可见的「整个桌面 / 限定窗口」配置与选窗 UI。
- Agent 自主决策操作范围；策略写入 CUA 提示（含黑名单、敏感确认规则）。

## 9. 删除浮层功能菜单与窗口选择

- CU 浮层**不开放**功能菜单、窗口选择给用户。
- 浮层仅服务「三种用户操作」+ 最少状态展示（阶段/步数/原因短句可留）。

## 10. 用户只保留三种操作

1. **暂停 / 停止**当前操作；
2. **全程接管**（暂停并接管，用户动手）；
3. **关闭 Computer Use 开关**。

急停快捷键与托盘停止视为「停止」通道，保留。

## 11. 设置页保留项

- **模型配置**（含现有 VLM/会话相关配置入口，按现网保留）；
- **Agent / Computer Use 总开关**；
- **光标开关**；
- **首次开通**：安装助手、系统授权（辅助功能/屏幕录制）。

其余专家项（自检、导出诊断、清记录、范围说明等）不对普通用户浮层开放；可进失败态/高级/诊断，本 beta 默认隐藏。

## 验收（摘要）

1. 关 CU → 无 cua 工具与指导；开 CU → 自动注入配方，零手配。
2. 同会话关 → 短指令「已关闭勿调」；再开可「已重新开启」。
3. 默认光标开，设置可关；Background 不移真鼠标。
4. 无「整个桌面/限定窗口」用户配置；无浮层选窗与功能菜单。
5. 用户仅能暂停/停止、接管、关开关（+ 急停键）。
6. 授权模式可配；黑名单命中跳过；截图策略符合第 6 节。
7. 设置仍有：模型、CU 开关、光标、安装助手、系统授权。
