# 规格：resident-lifecycle

- 对应 intent：plans/20260928-resident-lifecycle-intent.md
- 状态：按已确认约束实施，技术边界从现有调用链核对。

## 方案与契约

1. gateway 只在已有停止/刷新入口收尾本实例的升级连接，关闭幂等且不会等待未知进程。
2. 通用 SSE 保持调用方与回调契约，每条连接管理自己的 watchdog；显式取消真实 abort，完成保留尾部消息窗口；旧 AppDev 两阶段请求各自拥有 controller。
3. AppDev ensure 的迟到响应不能在失效实例重新运行 keepalive；必要任务保活与 UI 轮询分别决策。
4. 宿主状态在订阅和文档加载后可同步，登录页无通知 collect，异步收尾不复活已卸载轮询。恢复按既有业务行为补查。
5. 终端流控保持字节顺序与完整性，不杀 PTY；ComputerServer 背压不以无依据断流/事件丢弃实现限额。
6. 思考计时状态有实例/容量边界，保留当前会话耗时；预览仅按既有内容契约抽取 HTML，observer/timer 成对释放。
7. 项目日志仅清理日志，保留活跃文件与任务数据；容量/TTL 明确，可独立回退。

## 验证

真实本地 HTTP SSE/WS 关闭、真实 React/ahooks 卸载与迟到响应；正常消息、尾部消息、并发、取消、断网和重连；终端顺序/流控；浏览器与宿主隐藏/恢复；前端会话合同、商业测试、overlay/pin 检查与构建。24/72 小时发布包观测另列实际完成情况，不以单测替代。

## 否决方案

隐藏时全停服务/容器、SSE 达阈值直接丢事件、无测量重写虚拟列表、清理整个工作区、将商业注入副本提交基座。
