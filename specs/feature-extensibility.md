# 规格：渐进扩展接缝

- 对应 intent：plans/20261002-feature-extensibility-intent.md
- 本轮为既有行为的结构收敛；技术基线来自当前源码与既有架构规范。

## 生命周期

托盘停止与重启在商业生命周期已注入时走同一 AuthLifecycle；社区保持 serviceManager 路径。停止撤销在途代次并调用聚合停止。操作失败不得把托盘状态标成成功。用可注入依赖的接线模块测试真实生命周期竞态，避免导入并启动整个 Electron main。

## Overlay 兼容检查

检查指定旧/新基座提交间的变化与当前 overlay 的交集，包括新增同名文件、删除、内容及模式变化。目标基座将 overlay 文件路径本身变为目录、符号链接、子模块，或将其祖先目录变为非目录对象时，必须迁移路径或修正基座，不能以审查记录放行。overlay 文本固定 LF 检出，二进制保持原字节，使实际内容摘要可跨平台复用。检查只读，不同步、不 checkout、不 fetch。变化必须人工对照源码合入商业实现；审查记录绑定新基座文件对象/模式与当前 overlay 内容摘要，失效记录不能放行。更新器在移动基座检出前执行此检查，遇到未审查冲突保留所有原检出与 WIP。overlay:check 继续只承担同步一致性检查。

## 会话工作区动作

会话展示层消费类型化的工作区动作；旧 conversationInfo 依赖集中于兼容适配边界。现有入口未注入动作时沿用原行为；注入动作的入口不需要旧 model 即可执行 OpenUI/文件联动。会话消息 store、发送/停止/恢复/队列、文件选择和预览刷新语义保持不变。

## 宿主桥类型

自包含契约放在可独立构建的前端仓；外层脚本生成商业 overlay 的类型快照，并在 CI 检查规范化换行后内容一致。前端保留旧宿主可缺少命名空间或方法的兼容类型，preload 暴露对象必须满足完整契约。共用 payload 类型，保持现有 IPC channel 和转发逻辑；不引入新桥协议或版本协商。

## 工作台面板

保留现有 usePreviewTabs 状态机，将工具元信息、侧栏激活策略和固定工作区渲染入口收敛为静态类型定义。小型工作区 hook 只管理已有视图切换与恢复；服务连接、环境准备与 keepalive 顺序保持不变。工作台注入已有文件打开动作，保持文件选择与刷新触发语义。新增面板不依赖动态注册或全局插件框架。

## 节点扩展专项

- 只迁移现有 Agent、RouteDecision、HumanInteraction，普通 Workflow 节点沿用原工厂和配置。以纯数据/纯函数 NodeDefinition 统一调色板名称与描述键、flowKinds、顺序、默认配置/名称、外观资源及可选 backendType；定义不导入 React、属性表单或网络 API。
- 现有 NodeRegistry 保留属性表单注册，选择面板直接以 map 中是否存在为准，避免维护第二张面板名单。现有 extensionRegistry 保留分支端口、连接与配置同步职责，不引入动态插件平台。
- AgentFlow 组合入口在子树首次渲染前完成幂等 handler 注册，不能依赖父组件 passive effect 与异步取数据的先后顺序。图工具保持只依赖中立 registry。
- 在确认旧逻辑后，将 AgentFlow 分支重载边生成和保存端口能力识别接到 handler。普通分支、异常分支、历史缺 uuid、旧端口映射、节点 id/edge id 和后端类型保持原兼容语义；不改变后端 payload 字段或存储格式。
- 本域若回归复现 Human SELECT 普通回落连接被清空、删边后旧选项目标残留，按独立 bug 修复处理：画布现存边是重建连接的事实源，保存/undo 同步不得丢失普通回落，也不得保留已删除的目标。不迁移缺 uuid 或旧 askConfig 协议。
- 覆盖默认配置实例隔离、调色板/flowKinds/类型映射、连接后保存再重载 round-trip、删除/空分支及 legacy fallback。运行 AgentFlow/extensions/flowKind/workflowProxy 与相关节点/保存回归，随后 arch、增量 TS、生产构建与独立复核。

## 分域类型门专项

- 继续使用前端安装的 TypeScript 与现有 tsconfig.typecheck.json 检查项目，不另造弱类型配置。首期明确覆盖节点（含 AgentFlowCanvas）、会话核心、AppDevPro 工作台及宿主桥类型契约；相关单元/集成测试纳入各域。域外错误只报告，不将结果表述为全库类型通过。
- 诊断按域、仓库相对路径、错误码、完整消息和出现次数精确对照已审查基线；行列移动不导致误报，消息或同类数量增加必须失败。路径与依赖引用须跨平台规范化，不能按错误码整类豁免。
- 检查默认只读。已经减少的旧诊断要求主动收缩基线，防止未来回流仍被放行；可提供仅删除旧记录的 prune 入口，存在新增诊断时拒绝写入。CI 不生成或扩大基线。
- 未知域、配置/生成类型缺失、编译器异常、无输入、域文件未被编译、无文件的项目诊断等必须失败，不能把环境错误当历史债务。现有严格检查选项不能因 gate 配置而放宽。
- 由本地 scripts 与 package 命令提供入口，在独立前端 CI 与外层 pinned-frontend CI 接入；两处共用同一 gate，不改变 shell 双轨门或构建/发布输入。
- 已确认的节点历史修复：本地 NodeMetadata 精确继承 installed X6 顶层模型类型；动画使用 X6 3 的关键帧 API 及其实际返回类型，保留 600ms、无限循环、分支颜色、取消和去重语义。不得用 any、ts-ignore 或放宽后端配置类型消错。
- 回归覆盖诊断计数/消息/行列、Windows 路径、域隔离、旧基线收缩、配置故障与真实 TypeScript 新错阻断；节点创建/保存重载及动画启动、去重、取消和重启保持验证。无需重新跑未改变的 shell 或会话运行时门。

## 节点生产源码清理专项

- 以现有节点域 39 条基线中的 10 条生产源码诊断为边界，测试夹具债务另行处理。不新增节点协议、接口字段或后端存储迁移，不修改 NodeConfig 来适配第三方表单类型。
- 自动布局通过既有 GraphContainerRef.getGraphRef 取得画布；保留现有 BFS 顺序、坐标和孤立节点处理策略。未初始化或空画布继续安全回落，不增加新布局引擎。
- AgentFlow 内置 Header 因外部编辑页已有顶部栏而隐藏；自动布局沿用现有可见 ControlPanel 转发相同回调，覆盖嵌入与全屏。保持隐藏规则，避免重复顶部栏；普通 Workflow 不新增此按钮。入口回归使用真实 Layout/Header/ControlPanel，图 DOM 可隔离。
- workflowProxyV3.getEdges 的返回类型必须对应真实保存的 EdgeV3[]；图回调及 FormList 默认枚举明确类型，Markup 取 installed X6 支持的声明类型，不使用 typeof 值代替真实数据结构。
- NodeConfig 到 AntD 表单的值写入需保留 setFieldsValue 合并/错误状态等实际语义，contextParams 任意值不能因类型修复被删除或序列化改变。必要的第三方类型边界集中在小型适配器并用真实表单回归说明，不用 any/ts-ignore 或宽泛双断言消错。
- 自动布局只在坐标实际变化后同步代理待保存状态并统一触发一次既有防抖保存；立即离页仍通过原保存链保留坐标，空图、未初始化、无 Start 或位置未改变不新增保存请求。回归须验证真实按钮到 dirty、保存请求及坐标，不能只手工调用 payload 构建方法。
- 验证实际自动布局按钮到画布 Ref、节点位置及断连/循环/空图安全；真实表单字段填充、合并、字段保存及可见性保持；原节点创建/保存/重载/生命周期/动画回归、类型基线 prune、全库诊断零新增、架构与生产构建通过。

## 测试类型债务专项

- 本批范围是当前基线中的 15 个测试文件、26 个记录与 50 条诊断（节点 29、会话核心 21）；工作台与宿主契约已为零。生产源码、全库域外债务与新业务协议不扩大处理。
- 测试夹具需满足实际 ChildNode/NodeConfig/MessageInfo/RequestResponse 等契约；legacy 路由字段按实际兼容形状使用既有类型或测试局部精确扩展，端口颜色断言继续验证运行数据。必填元数据、枚举、节点 id、分支条件及 hook 参数按真实接口补齐。刻意模拟非法 wire 数据的用例须显式引入单一异常并保留断言，不能改成正常数据来满足静态类型。
- React Ref 依照当前可变/只读声明初始化；Mock 与 renderHook rerender 使用准确的参数和返回类型，保留回调行为。仅删除已失效的 expect-error，不新增 any、双断言、ts-ignore 或批量绕过类型检查。
- 保留既有用例数量、行为断言、异常与历史数据覆盖；不以删除断言或改生产接口完成门禁。重复夹具可在符合既有架构边界的最小测试 helper 中集中，不能让生产模块依赖测试数据。
- 修改稳定后由主代理统一收缩基线，预期四域基线全部为空；用 full noEmit 完整消息计数确认 335 → 285、零新增。执行完整节点回归、test:conversation、架构与脚本门自测；测试限定改动无需重复生产构建。由全新只读 verifier 独立复核。

## 兼容与验证

- 不新增线上 IPC channel、HTTP 字段或存储迁移，不退役 V1 回退路径。
- 生命周期覆盖商业/社区、成功/失败、注册中停止、停止后重新启动。
- 脚本覆盖真实临时 Git 仓库：无重叠、覆盖变化、新增/删除/模式、有效/过期审查记录、无工作树/index 副作用。
- 前端覆盖动作注入、旧入口兼容、OpenUI 与文件预览行为；运行会话合同网和 lint:arch。
- 宿主桥覆盖生成一致性和 TypeScript 正反例；工作台覆盖切换/恢复、预览页签与面板挂载语义。
- 社区与商业测试顺序执行于本隔离检出，最后重新同步 overlay；源码测试、构建和实机验收分开报告。
