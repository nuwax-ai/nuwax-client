# 规格：本机文件面板读写

- 对应 intent：`plans/20261025-local-file-management-intent.md`
- 继承 `local-file-access.md` 的文档、会话、sandbox、协议和授权边界；本规格取代其“写操作保持原接口”的本机行为。

## 功能入口与范围（2026-10-28 澄清）

文件树面板是本次文件管理的入口：列表/搜索、预览及子资源、打开/定位、编辑保存、新建、删除、重命名、跨目录移动、上传文件/文件夹、ZIP 导入、单文件下载和工作区导出都由统一文件访问层按目标电脑分流。不能因功能在 Chat 页面内，便将面板上传误归类为会话附件。

会话输入框仅纳入选择项目目录，按宿主当前电脑、其他电脑和云端区分。附件发送、粘贴/拖入附件仍沿用消息附件链路。此范围不要求消息发送在断网时可用。

跨目录移动复用工作区内的源/目标路径语义，不能仅有底层 rename 能力就宣称面板已有可用的移动功能。移动前完成受影响文件的草稿保存；成功后刷新目录、预览路径和已打开页签；失败保留原路径及草稿，不覆盖已有目标、不将目录移入自身或其后代。跨电脑迁移不等同于工作区内移动，不从本次措辞推导跨电脑复制后删除。

上传需保留文件字节和文件夹相对结构；ZIP 导入须保留既有覆盖确认及保留目录语义，拒绝压缩包越界路径和链接逃逸，失败不得误报成功。导出沿用完整内容和原子落盘约定。这些是待补齐的契约，不代表 Beta.1 已实现全部入口。

本机身份与服务就绪状态必须区分：已确认当前电脑后，即使换到新会话或服务暂未就绪，也应明确反馈本机不可用。用户点击重试时需要重新解析失败的工作区，不能重复等待同一个失败结果。预览兼容旧同会话资源地址时，空目录参数与默认根语义一致，禁止跨会话或越界授权。

## 接入与契约

前端继续在 `features/client-shell/localFileService` 判定本机，`apiUpdateStaticFile` 统一分流，页面不复制宿主判断。前端 `hostBridge.ts` 是类型事实源，经脚本生成商业 overlay 快照。

localFiles API v2 增加可选 `updateFiles(contextId, changes)` 和 `writable` 能力。变更项为现有文件操作的最小子集：name、operation(create/modify/rename/delete)、contents、isDir、binary、renameFrom。主进程验证全部参数后，串行执行同一 runtime 的变更；每项文件保存原子提交，批次不承诺跨文件事务。旧本机只读桥不能因缺写能力而把写请求转到云端。前端业务服务把本机错误转换为明确失败返回码并提示，现有自动保存保留脏内容，不泄漏未处理拒绝。

前端沿用列表的 localFile 来源，写入前校验 cId/contextId；释放上下文后保留有界的近期来源记录，迟到保存不能仅因当前无记录就转发云端。显式切换远端后的新文件不携带旧来源，继续使用原接口。

## 文件语义

- API v3 的 `beginTransfer / writeTransferChunk / commitTransfer / cancel` 绑定原生上下文；每块最多 1MiB，按文件序号和精确 offset 接收，未收完整或发生错误不能提交。上传文件夹沿用现有选择器过滤及相对路径规则，消息附件不调用此桥。
- 上传由主进程串行进行，每文件临时落盘、校验原文件身份后替换；取消、权限或磁盘失败不截断原文件。ZIP 导入复用本机服务既有覆盖/保留规则，先拒绝越界、链接、保留设备名及重复/冲突条目；最多 10,000 个条目，解压单文件不超过 256MiB、总计不超过 1GiB。导入阶段只发往固定 loopback 地址，不带业务凭据、不跟随重定向。

- 新建文件/目录必须不存在；不递归创建未显示的父目录。
- 编辑仅文本普通文件，保留权限；临时文件写完并再次校验文档与文件身份/修改时间后替换，取消和失败清临时文件。
- 重命名保留文件内容、目录和链接本身，不覆盖目标；同批父目录重命名不展开成逐个子项修改。
- 删除调用 Electron `shell.trashItem`，现有界面确认保留；回收站错误直接失败，不以 `rm` 兜底。
- 所有写路径在真实工作区内，拒绝工作区根、相对越界和目录软链越界；编辑不写入软链指向的其他文件。读取、显式系统打开沿用原规格。
- 登出/导航/文档失效会使排队请求过期；已交给系统回收站的原生操作无法撤销，不承诺事务回滚。

## 验证

注册三态、真实临时文件增改/重命名/删除、原文件保留、冲突、路径/链接边界、跨 owner、过期队列、前端本机/远端/旧桥分流与失败不回云端；修复并运行隔离 Electron 的协议/桥集成脚本。商业/社区质量门、宿主类型快照和特性边界分开检查。安装包及系统回收站真实 UI 仍需两平台验收。
