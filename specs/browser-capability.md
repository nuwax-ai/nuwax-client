# 浏览器扩展能力

`browser` 静态特性仅面向 nuwax，默认启用，`features.browser.enabled` 覆盖；首次打开才创建窗口。基础层分类普通链接，读取 `nuwax.linkOpenMode`（`in-app` / `system`，缺省 `in-app`）。关闭或注册失败回退系统浏览器，不维护第二套普通外链窗口。

浏览器模块自管窗口、页面和窄 IPC；宿主通过公开入口提供页面会话、导航/下载/凭据策略，特性不引用宿主数据库或鉴权实现。工具栏为本地独立页面和临时 session，远程内容为共享网页 session 的 WebContentsView；页面不能操作工具栏 IPC。

普通外链入口覆盖 window.open 与 native.openWindow。普通外链、同源业务链接和未标记用途的历史开窗调用统一使用定制浏览器，共用一个窗口，每次新开页签。原有站内同窗路由保持原设置；已有页面内导航不新建页签。支付入口显式标为 `{ purpose: 'payment' }`，单独开窗口，也使用同一套定制顶栏；支付子窗口继承用途，包括未重复标记的相对业务地址。不能仅凭域名或 POST 猜测支付用途。站内业务、POST、受保护附件不按普通外链分流，显式系统浏览器设置只影响普通外链。

页签切换和关闭位于顶栏；关闭按钮平时隐藏，hover 或键盘聚焦时替换左侧网站图标，停止加载显示方块。Ctrl+Tab / Ctrl+Shift+Tab 切换，Cmd/Ctrl+W 关闭当前页签，关闭最后一页才关闭窗口。前进后退按当前页签的历史显示；查找词、匹配结果、地址展开、加载与错误状态由各页签独立维护。复制、刷新、打印操作当前页签，复制显示 toast；置顶属于窗口，缩放沿用 Chromium 同站点规则。远程标题仅作为文本渲染，工具栏 IPC 只能操作所属窗口中的页签。

保留 Chromium 原始 popup guest、POST 请求、共享网页 Cookie、opener/回调和 window.close。普通页签不随请求方销毁而连带关闭；支付仍跟随其请求方清理。下载空页的隐藏、销毁只作用于对应页签。关闭网页前尊重 beforeunload，退出/换域撤销相关窗口；所有创建、监听、IPC 随特性释放。

浏览窗口访问 HTTPS 主文档遇到证书校验失败时，原生确认框显示目标站点、失败原因和信息泄露风险，提供“取消访问”和“继续访问（接受风险）”，默认取消。用户主动确认后，Chromium 在本次客户端运行的共享网页 session 中信任该主机的当前证书，其他窗口访问同主机也会生效；不同主机、不同证书仍需确认，重启客户端后失效。提示文案明确这一范围；不设置全局证书忽略开关，不替未授权的 iframe/子资源申请例外。窗口关闭、停止加载、导航变化或对话框异常时，尚待确认的请求拒绝，迟到结果无效。
