# 合并前评审

以本次变更为范围，读取根目录 `REVIEW.md` 和相关实现，检查行为、维护性、安全边界及验证是否充分。已有本批次评审结论直接复用，不增加独立的重构或多遍评审阶段。

仅在缺少相关证据或发生新改动时补跑必要检查；不默认执行社区全量测试。确需社区测试时使用隔离副本，避免清除商业 overlay。

报告具体问题、位置、实际验证结果和未覆盖范围；已有问题属于在途改动时说明归属。不自动提交、合并或批准 PR。
