# Agent 会话截图回填

- 范围：用户确认仅接入客户端截图；IM 已有同类逻辑，不增加系统剪贴板监听。
- 实现：复用 `capture.onShortcut` 和现有采集/复制/分块读取桥，截图前只有聚焦且可编辑的 Agent 输入框可以认领。确认后复制图片，并复用附件上传流程加入草稿，由用户手动发送。
- 入口：全局快捷键沿用现有认领链；客户端菜单进入宿主 interactive 时，也先询问同一窗口内的业务输入框。应用在后台时继续只复制。
- 隔离：锁定输入框实例、页面/会话草稿作用域和代次；切换后即使切回也不接收迟到结果。取消、禁用、无权限、卸载不回填；成功句柄始终释放，重复请求不启动第二次采集。
- 落点：前端 MentionEditor 聚焦查询、共用截图 hook、ChatInputUnified/ChatInputHome 接线；壳 capture 特性复用现有受信认领协议分派宿主入口。
- 验证：截图 hook 与真实附件流程回归，壳入口/授权测试，前端 `test:conversation`，相关页面交互检查；源码验证不等同安装包验收。
- 状态：源码实施与本地验证完成；未打包发布。
