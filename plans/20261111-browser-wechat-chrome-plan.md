# 内置浏览器外观与交互调整

按用户提供的微信 macOS 截图，将已有浏览能力的界面做得接近微信，供今晚上线。

- 顶栏使用紧凑标题胶囊，刷新和更多位于胶囊内；右侧放查找、复制和置顶。用户确认去掉微信截图中的独立窗口形状图标，默认浏览器打开仅留在更多菜单中。保留历史导航、网址查看、快捷键和平台窗口控制。
- 原生更多菜单按刷新、复制链接、调整文字大小、查找、打印、默认浏览器打开分组，并从标题胶囊下方展开。
- 复制成功显示“链接已复制”，失败显示重试提示；重复操作更新提示，提示在顶栏内显示，避免被原生网页视图遮挡。
- 用户已确认本次不加问 AI、多标签页、全文翻译、收藏和浏览记录。复用现有窗口、权限、地址映射和下载链路。

验证：相关浏览器单测、locale 一致性、renderer 构建，以及真实 Electron 顶栏输入/IPC 和原生视图布局回归。安装包与 Windows 实机外观仍按发布验收执行。

已完成：18 项相关单测、主进程类型检查、renderer 构建、Electron 40.8.2 实际输入/IPC 回归通过。去掉右侧独立窗口形状图标后已重新构建并复验。真实回归覆盖顶栏与菜单复制 toast、剪贴板异常、提示消失、页内查找/快捷键、窗口关闭和 800px Windows/Linux 渲染布局；尚未打包发布。
