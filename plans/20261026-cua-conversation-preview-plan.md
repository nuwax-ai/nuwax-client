# 实施计划：按会话展示 Computer Use 预览

- 对应规格：`specs/cua-conversation-preview.md`
- 状态：代码及自动化验证完成；用户已授权。

## 落点

1. `main/services/featureHost` 与 `_kit` Agent 通用端口：解析宿主会话元数据，不改变引擎生命周期契约。
2. `computer-use/sessionAuthority`、任务控制器/注册表与运行态：保留宿主确认的业务会话归属。
3. `computer-use/conversationContext`：观察主窗口受信 guest 的原生导航事件并解析已知业务会话路由。
4. `controlWindow`：按上下文筛选预览、会话内选中/排序/关闭状态及迟到消息保护。
5. 特性组合入口与旧 renderer 控制条：同步展示上下文，保留全局主动管理及急停。

## 实施与验证

在基于 Beta.5 的隔离工作区实施，不覆盖原工作区 WIP。先补会话切换与归属回归，再完成实现；使用已有依赖在隔离基座同步商业 overlay。完成相关回归、商业构建、边界与 pin 检查；记录未知路由及安装包验收边界。

## 风险与回退

会话身份缺失或歧义时默认隐藏，不展示其他会话任务。导航和截图返回存在竞态，切换时撤销预览代次；任务执行状态不受展示操作影响。回退本轮代码即可，不迁移持久执行权限。
