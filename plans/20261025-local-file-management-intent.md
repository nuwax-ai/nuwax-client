# 意图：客户端文件面板通过 Electron 访问本机文件

- 日期：2026-10-25
- 状态：已接受；用户明确范围为预览、打开、编辑、新增、删除，并选择删除进入系统回收站。

## 目标与范围

当前会话/项目选择本机电脑时，已有文件面板经 Electron 完成预览、系统打开、编辑保存、新建文件/目录、重命名和删除；删除沿用现有界面确认并进入系统回收站。沿用现有本地列表、搜索和流式预览，不另建文件管理 UI。

浏览器、旧宿主、云端和其他电脑保持既有路线。已确认本机后的失败明确反馈，不转发云端写请求。上传、ZIP 导入与 Git 操作不属于本次五项文件操作的改造范围。

## 约束与验收

写操作限定当前会话解析的工作区，不删除工作区本身，不跟随目录链接越界；新建/重命名不覆盖已有目标，保存采用临时文件替换。登出、换域、导航及工作区失效后不得继续投递新写入。

版本候选仍以 3.0.23 为基线；最终是否命名 3.1 未定。本批不发布、不改 tag、不操作用户安装实例。Mac/Windows 实包的真实编辑、保存、回收站验收分别保留证据。

## 开放问题

无阻塞产品决定。回收站不可用时直接失败，不改为永久删除。
