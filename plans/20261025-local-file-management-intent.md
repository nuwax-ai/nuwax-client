# 意图：客户端文件面板通过 Electron 访问本机文件

- 日期：2026-10-25
- 状态：已接受；2026-10-28 用户进一步明确以文件树面板的全部文件操作为范围，删除进入系统回收站。

## 目标与范围

当前会话/项目选择本机电脑时，文件树面板的列表、搜索、预览、系统打开、编辑保存、新建文件/目录、重命名、跨目录移动、删除、上传文件/文件夹、ZIP 导入、单文件下载和工作区导出统一经文件访问层完成。删除沿用现有界面确认并进入系统回收站。沿用现有文件面板，不另建文件管理 UI。

浏览器、旧宿主、云端和其他电脑按宿主能力及目标电脑使用相应路线。已确认本机后的失败明确反馈，不转发云端文件请求。2026-10-28 的范围澄清取代原先排除上传、ZIP 导入的约定；Git 版本管控仍按独立业务处理。

会话输入框仅纳入“选择项目目录”：选择宿主当前电脑时打开系统目录选择器，其他电脑/云端使用对应目标的目录浏览；本机取消或失败不改开远端选择器。会话附件、粘贴图片、拖入文件后发送属于独立的消息附件链路，不纳入此次文件树面板改造。会话消息中的工作区文件进入面板预览后，仍按该文件的目标电脑和来源处理。

## 约束与验收

写操作限定当前会话解析的工作区，不删除工作区本身，不跟随目录链接越界；新建/重命名不覆盖已有目标，保存采用临时文件替换。登出、换域、导航及工作区失效后不得继续投递新写入。

版本候选仍以 3.0.23 为基线；最终是否命名 3.1 未定。本批不发布、不改 tag、不操作用户安装实例。Mac/Windows 实包的真实编辑、保存、回收站验收分别保留证据。

## 开放问题

无阻塞产品决定。回收站不可用时直接失败，不改为永久删除。
