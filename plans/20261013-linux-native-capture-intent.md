# 意图：补齐 Linux 原生截图与录屏

- 日期：2026-10-13；发起人：用户。
- 状态：功能目标已接受；依据用户明确要求“Linux 也需要支持，现在开始做一些补齐实施”。

## 问题

客户端面向 macOS、Windows、Linux，但原生采集的 Linux 平台被排除；菜单、快捷键和 MP4/GIF 资源也未接入。现有 IM 公开接口可沿用，不能把能力参数模拟测试当成 Linux 桌面验收。

## 预期结果

- Linux 可从客户端菜单、设置页、应用内快捷键以及受信 IM 原生桥发起截图或 MP4/GIF 录制。
- 截图支持来源选择、区域、既有标注/文字字号、确认/取消；录屏支持区域、倒计时、暂停/继续、停止、结果读取与回填。
- 多屏来源由用户选择，采集不串屏；Wayland 不依赖不存在的全局窗口坐标。
- Linux x64/arm64 发布包带有经校验的编码资源、精确源码和许可证；不依赖用户系统 FFmpeg 或特定 GPU。

## 受影响的能力面

商业 overlay 采集引擎、私有采集窗口、客户端菜单/快捷键/托盘、资源构建及发行链、IM 接入说明。公开 capture API 保持兼容；IM 业务仍由独立项目接线。

## 约束

沿用无音频、单会话、单来源内选区、受信主框架 IPC、登出/锁屏/取消清理；不新增 GPL/nonfree 编码器。保护现有 Windows/Mac 热修、子模块 WIP 和产物 pin，不发布或推送。

## 已收敛的边界与待验证项

- X11 沿用每屏冻结覆盖层；Wayland 通过 portal 授权一次，读取真实帧后在普通窗口内选择/标注，录制复用同一条流。
- Linux 没有 Electron 内容排除保证：录制时避免桌面红框，全屏/来源坐标模式隐藏控制窗，并提供托盘暂停/继续/停止。
- Linux 软件 H.264 使用固定源码 OpenH264 + LGPL FFmpeg；自编译 OpenH264 不享 Cisco 官方二进制专利费覆盖，沿用现有 H.264 发行授权待确认项。
- 用户建议检查 OrbStack；当前没有 Linux VM，Docker Linux arm64 可用于隔离编码/X11 桌面验证。真实 Wayland portal 和正式安装包矩阵仍需单独验收。
