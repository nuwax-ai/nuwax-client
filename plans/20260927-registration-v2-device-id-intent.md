# 意图：商业客户端注册 v2 与稳定设备身份

- 日期：2026-09-27
- 状态：用户已授权接口切换和稳定设备编码实现。

## 问题

注册仍调用 `/api/sandbox/config/reg`。现有 macOS machineId 是硬件 UUID，Windows MachineGuid、Linux machine-id 是系统安装身份；失败时使用电脑名，可能因为重装系统、改名或临时读取失败产生不同设备。

## 预期结果

- 商业注册使用 `/api/sandbox/config/reg/v2`，始终携带稳定的 `deviceId`。
- 同一电脑升级、重启、换账号、换域和改名后保持身份；正常硬件 UUID 可读时，清除应用数据也能重新推导相同编码。
- 不上传原始硬件编码，不改变社区版身份算法。

## 受影响的能力面

商业主进程注册编排与系统身份读取；通过 overlay 承载。

## 约束

保留 ticket 鉴权、savedKey 迁移、会话代次检查和服务启动顺序。不修改基座 pin，不处理历史服务端设备记录。
