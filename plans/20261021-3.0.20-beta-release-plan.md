## UTM 卸载阻断与 Beta.5 候选

用户在 UTM Windows 192.168.64.2 的 Beta.3 真实卸载失败。日志定位到显式删除本地数据分支的 Git 插件 pack 索引：文件 ReadOnly|Archive，但用户/SYSTEM/Admin 均有完整权限；在隔离副本上 File.Delete 复现拒绝访问，清除副本只读属性后删除成功。程序载荷已删除 31,512 项，错误发生在后续数据清理；原有泛化提示不能正确描述这个阶段。安装恢复任务在独立 `fix/windows-uninstall-readonly` 修复，保留旧 scope WIP，不与之混合。现场剩余数据已保全。用户随后明确停止代理真机验收，发布按代码与必要自动门禁推进，包交由用户验证。
