# 需求说明：首次进入后的电脑列表刷新

## 背景和目标
用户首次登录后，首页早于本机注册和隧道启动完成。电脑选择器只获取一次候选，后续上线的电脑无法选择。用户已要求实施此前分析的修复。

## 用户角色
在 Nuwax 客户端首页或会话输入框选择执行电脑的用户。

## 功能范围
首载获取列表；首次启动期间有限重试；打开下拉重拉；客户端生命周期状态通知触发补拉，并补发当前状态防止错过事件。暂时缺少电脑不覆盖后端选择记忆；用户手动选择优先于旧请求。复用现有候选 API 和宿主命令通道。

## 核心流程
登录进入页面 → 获取候选 → 本机尚不可见时有界重试 → 宿主启动完成触发补拉 → 电脑出现并可选；后续打开下拉仍获取最新候选。

## 字段和状态
候选以 `/api/sandbox/config/select/list` 为准。宿主仅提供生命周期 phase 和可选本机沙箱 ID；ready 是刷新触发器，不伪造在线候选。

## 权限规则
仅商业客户端向受信 webview 下发状态；不得暴露 ticket、savedKey、configKey 或用户信息。页面不发起注册或业务服务启动。

## 异常场景
接口失败保留已显示候选；请求并发合并；卸载及过期响应不能更新状态；后台暂停重试，恢复时按剩余预算补拉；只读、固定电脑、云端模式保持既有约束。
