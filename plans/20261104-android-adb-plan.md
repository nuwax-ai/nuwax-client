# Android 手机操作（下一版本）

- 首版通过 PR #86 合入 `alpha/v3.1.0`。本次将 Android 手机操作移植到 `release/v3.2.0`。
- 新增独立 `android` 特性，复用受信宿主设置、Agent 会话参与者及本地 MCP 注册端口，不改变桌面 Computer Use 的目标和授权。
- 用户在客户端设置中检测 ADB、刷新设备、明确选择已授权手机并开启；默认关闭，重启、登出、换域、锁屏、服务停止后重新授权。MCP 不能自行选择设备或打开能力。
- 首期提供截图、点击、滑动、返回/主页/最近任务按键和 ASCII 文本输入。每个动作绑定当前会话最近截图；切换设备、停止、断线、取消、超时立即撤销，写动作不自动重试。中文输入、安装应用、任意 shell、无线配对与自动解锁不在本段范围。
- 主机命令使用参数数组；远端 `adb shell` 参数单独转义；手机命令使用 `-t` 绑定本次确认的 transport ID。监听设备状态，断线、重连或监控退出后要求重新开启。截图只经内存返回模型，不保存到磁盘或日志；设备信息只在明确检测/开启后读取。
- MCP 使用本机认证通道和每会话临时凭据，参与者只在当前 prompt 期间允许动作；同一手机单飞，跨会话观察不能复用。宿主急停/取消能中断在途进程。
- 验证：设备解析、命令参数与注入、防串机/串会话、陈旧观察、断线与取消；特性边界、桥契约、类型检查及真实授权设备截图/安全操作。源码/真机/安装包结果分别报告。

参考：[Android 官方 ADB 文档](https://developer.android.com/tools/adb)及 [ADB 设备跟踪协议](https://android.googlesource.com/platform/packages/modules/adb/+/refs/heads/main/docs/dev/services.md)。

## 3.2 按需安装

- 设置入口继续随壳提供，手机控制默认关闭。客户端启动和读取状态不检测设备、不下载依赖。用户点开启或检测设备后优先使用现有 ADB，找不到时显示官方安装选项。
- 版本、系统支持、下载大小和 SHA256 固定在主进程。用户确认 SDK 条款后，主进程从 Google 下载，连接中断时有限续传。校验归档与 ADB 文件后，将 ADB、所需库和上游 NOTICE 缓存到本产品数据目录。
- 安装结束后重新检测，用户选择手机并单独确认控制权限。取消、退出、登出或换域中止在途安装。按需安装不修改系统 PATH、不申请管理员权限，也不安装 USB 驱动。
- 缓存被破坏时重新确认安装。官方归档不支持的平台、网络不可达或企业限制下载时，允许填写本机 ADB 路径。
- 验证固定下载来源和校验、缓存复用、取消和安装失败恢复，并分别记录生产壳代码增量与启用后的下载/缓存大小。
