# Android 手机操作（下一版本）

- 客户端基于 `release/v3.1.0` 独立开发，PR 回到同一分支；本次不发布安装包。今晚只有 PC Web/H5 的 `feat-2026.11` 上线，邀请功能已完成，不重复开发。
- 新增独立 `android` 特性，复用受信宿主设置、Agent 会话参与者及本地 MCP 注册端口，不改变桌面 Computer Use 的目标和授权。
- 用户在客户端设置中检测 ADB、刷新设备、明确选择已授权手机并开启；默认关闭，重启、登出、换域、锁屏、服务停止后重新授权。MCP 不能自行选择设备或打开能力。
- 首期提供截图、点击、滑动、返回/主页/最近任务按键和 ASCII 文本输入。每个动作绑定当前会话最近截图；切换设备、停止、断线、取消、超时立即撤销，写动作不自动重试。中文输入、安装应用、任意 shell、无线配对与自动解锁不在本段范围。
- 主机命令使用参数数组；远端 `adb shell` 参数单独转义；所有命令显式使用 `-s`。截图只经内存返回模型，不保存到磁盘或日志；设备信息只在明确检测/开启后读取。
- MCP 使用本机认证通道和每会话临时凭据，参与者只在当前 prompt 期间允许动作；同一手机单飞，跨会话观察不能复用。宿主急停/取消能中断在途进程。
- 验证：设备解析、命令参数与注入、防串机/串会话、陈旧观察、断线与取消；特性边界、桥契约、类型检查及真实授权设备截图/安全操作。源码/真机/安装包结果分别报告。

参考：[Android 官方 ADB 文档](https://developer.android.com/tools/adb)（`devices -l`、`-s`、`exec-out screencap -p` 与远端 shell 转义）。
