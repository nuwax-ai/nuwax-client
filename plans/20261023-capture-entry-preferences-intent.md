# 意图：截图启动、偏好和统一截图录屏入口

- 日期：2026-10-23
- 基线：用户要求实施；隐藏窗口默认关闭已由用户确认。

## 问题和预期结果

Windows 点击截图偏慢；隐藏客户端窗口没有设置；默认快捷键与用户习惯不符；截图浮层缺少录屏切换。

截图不等待视频编码器检测；隐藏窗口开关持久化且默认关闭。可修改的截图和录屏快捷键，默认 Command/Ctrl+Shift+A、Command/Ctrl+Shift+R，客户端应用菜单同步显示实际快捷键。菜单显示截图、MP4、GIF，录屏参数决定初始模式；宿主浮层支持切换并保留选区。

## 范围和约束

商业壳 overlay，保持现有应用内快捷键作用域；业务页固定 screenshot/record API 的返回语义、权限和来源校验不变；IM 显式调用可切换类型的 interactive API。用户后续明确授权提交，并要求 IM 直接合入 main、PC Web 直接合入 origin/feat-2026.9.30；同步更新消费 pin，不发布安装包。真实 Windows 启动耗时及安装包仍需实机验收。

## 待确认

无阻断问题；采用现有快捷键作用域，录屏快捷键按用户追加要求使用 R；macOS 为 Command，Windows/Linux 为 Ctrl。Linux 正在录制时的停止/暂停控制键保留。

## 追加范围：IM 回填

IM 内按钮直接回填当前会话待发送区；快捷键只由触发时聚焦的 IM 输入框接管。无 IM 焦点时展示宿主预览（可复制、保存）。采集期间切会话则复制剪贴板，不插入新会话；任何入口均不自动发送消息。
