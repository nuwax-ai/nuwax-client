## 实施范围与顺序

1. 复现配置写回、失败恢复清理导致开关丢失的路径；用户开启偏好与执行就绪分离，普通设置写回不得覆盖特性托管字段。首次安装仍关闭，显式关闭始终生效。
2. 旧窗口/多窗口配置接入 Agent 选窗：真实窗口校验后绑定，不恢复已删除的选窗 UI，不绕过窗口/任务隔离。授权软超时继续观察，显式取消/退出终止观察。
3. 在最终解析目标上强制黑名单；询问式不能依赖模型自行重复按钮标签；确认许可按任务和动作隔离。四语准确说明截图传给所选模型；脱敏与留存归属本模块。
4. 模拟光标用有 id 的宿主请求，独立消费回执，按 driver 租约复位；窗口策略只开放所需的宿主控制。对齐 observation 配方。
5. 统一停止排空时的预览展示/选择状态；接入正常结束、启动与周期截图清理。
