# BUG 2687：Windows 客户端截图与 GIF 优化

来源：https://zt.nuwax.com/index.php?m=bug&f=view&bugID=2687 。用户补充：反馈来自 Windows 客户端。工单只读。

实现基线：`release/v3.0.23` / `dae2c666`；PR 从最新发布线 `5d6ade3a` 建立隔离工作树。截图实现归外层 `overlay/`，原工作区其他在途内容保留。

## 范围与验收

1. Windows 截图/录屏快捷键注册为全局热键，失焦或隐藏到托盘后仍可触发已有捕获入口；改键时先预留新绑定，失败保留旧绑定，关闭/退出释放。macOS 继续仅前台注册，Linux 保留现有路径。
2. 截屏选区界面任意位置右键直接取消整次捕获并关闭全部屏幕选区窗口；不生成选区、不提交标注、不弹出菜单。录制控制窗不因右键误停。
3. 定位并优化 GIF 停止后的编码耗时；保留原始像素、帧率/色数档位、循环、取消、大小上限与私有文件边界。用本地编码前后对比记录耗时、文件与尺寸，区分本机证据和 Windows 实机结果。

## 实施与验证

- 扩展捕获快捷键绑定的现有生命周期并复用可信 IPC 分发；补 Windows 背景触发、改键回滚、释放及 macOS 回归。
- 截屏窗口接入右键取消、限制绘制仅响应左键；用真实 Chromium 输入验证选区前/选区后/多屏取消。
- 先比较现有 GIF 编码与候选路径，再采用有收益且不改变输出契约的实现；补对应编码回归。
- 同步本任务 overlay 后运行捕获域测试、特性边界、`check:pin` 和 diff 检查。仅对本任务输入构建隔离验证资源；不发布版本、tag 或更新指针。
- Windows 物理多屏、系统热键冲突及安装包验收若无目标环境，明确保留待验收，不以模拟测试代替。

## 结果

代码以独立分支 `codex/bug2687-windows-capture` 提交，目标为 `release/v3.0.23`。Windows 商业客户端真实安装包验收仍待目标环境。

- Windows 注册全局截图/录屏快捷键，失焦及托盘状态保留绑定；改键失败保留旧绑定，退出释放，macOS 前台策略及 Linux 入口保留。
- 后台快捷键捕获前不置前主窗口，成功后恢复窗口显示预览；取消及 IM 草稿通道不置前窗口。
- 选区界面任意位置右键取消整次捕获；画布仅左键绘制。真实 Chromium 右键输入覆盖未选区、文字输入、录屏选区及三个模拟显示器的共同关闭；录制控制条右键不会取消或停止。
- GIF 采集帧率按最终档位上限设置（默认高档从 30 降到 15 fps；MP4/WEBM 不变）。编码使用同一已关闭源文件的两个独立读取通道生成全局调色板与应用调色板，降低整段解码帧排队内存；保留尺寸、色数、抖动及循环。

### 验证

- 改前：先提交回归测试，在隔离工作树的 4 个定向测试文件中确认 9 项失败；真实 Chromium 未选区右键取消也已确认超时。失败日志已保存。
- 改后：捕获及关联域 **40 个测试文件 / 453 项全部通过**；隔离 PR 工作树的 `npm run test:commercial` 全量 **3668 项通过 / 18 项跳过（300 个文件通过，1 个跳过）**。原生输入脚本在隔离工作树再次通过，覆盖截图标注、右键取消、模式切换及录制控制条。
- 主进程 esbuild 构建 smoke、模块导入边界、`git diff --check` 通过。本任务 12 份 overlay 文件与子模块副本逐字节一致。
- 初始共享工作区的 `check:pin` / overlay 检查受已有依赖、Midscene 与 `.gitignore` 改动阻挡。PR 隔离工作树的 `check:pin`、overlay 检查均通过；这些既有改动未进入本分支。
- 全库 TypeScript 有 249 条诊断；隔离副本恢复本任务改前文件后对照，未发现本任务新增诊断。隔离基线因未复制父工作区依赖另有缺依赖诊断，故不宣称全库类型检查通过。

本机 macOS arm64 使用锁定的 FFmpeg 8.1.3 对同一 6 秒、1280×720 输入编码；四档文件 SHA256、尺寸、时长、帧数均与原实现完全相同。单次样本如下，耗时包含本地编码进程与元数据读取，不能外推为 Windows 耗时保证：
