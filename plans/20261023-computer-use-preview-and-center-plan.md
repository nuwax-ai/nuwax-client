# Computer Use 预览与托盘任务中心调整

用户验收反馈：预览过大；默认右上角、可拖动、可关闭；仅呈现进行中窗口，可切换和调整顺序；历史集中托盘入口。接管、停止为必备操作。继续保持窗口内归属、默认关闭及退出/更新有界清理。

- 预览展开默认 300×220，收起为紧凑条；拖动限定主窗口可见区域，缩放后重夹取；保存位置。旧大尺寸偏好迁移为新尺寸。
- 关闭只隐藏预览并暂停预览采集，不停止任务，不因普通状态更新重新弹出；从托盘或明确查看动作重开。
- 悬浮区仅含 running/paused 窗口，支持切换、向前/后调整展示顺序；排序不改变 Agent 调度或系统窗口层级。接管/停止常驻可达。
- 托盘复用通用 activities 端口增加“电脑操作”常驻入口；主窗口内任务中心分进行中与历史，提供每对象接管/停止与全部停止，不新增独立桌面窗口。
- 历史仅持久化最多 100 条任务摘要（ID、窗口显示名称、时间、状态、动作计数）；不保存截图、输入/剪贴板、模型响应、授权能力或可恢复的控制标识。历史不能恢复任务权限。
- 验证可信 sender、拖动边界/异常值、关闭后状态更新、任务过滤/排序、历史去重/重启/清除、托盘关闭/退出；保持原自动化门，并在指定两台真机安装与截图。
- 锁屏支持单独核查：当前 lock-screen 无条件暂停，先核实上游和双平台锁屏行为。默认保留安全暂停，不将隐藏/熄屏的验证当作系统锁屏可用证据。
