# DS-Bot 与 DSH 插件运行时实施

已接受方案：保留现有引擎，新增独立完整 DSH Runtime 和窗口；DS-Bot 0.2.7 / DSH 0.2.1-rc.5 固定组合；模型统一通过 Nuwax 代理并保留平台权限与计费。首期包括 Bot 协作、恢复、定时任务、每 Bot 浏览器、Office 和本地语音。

实施顺序：真实组合与模型协议验证 → 受管理运行时和账号生命周期 → 独立窗口及受限浏览器桥 → Office / 语音资源 → 定向行为测试、真实桌面和平台验收、CI 安装包门禁。

运行包使用上游公开 profile-boot、Cordis 与插件 API，不修改上游 DS-Bot 或 agent-platform。数据只在当前产品档案中按域与账号隔离；主进程持有商业 ticket 与平台专用 API Key，插件只取得代次绑定的回环调用令牌。登出、换域和退出先撤权再清理所属进程。

平台真实模型权限、工具调用、流式输出和账单，以及五平台安装包验收，必须分别记录证据。源码或模拟模型通过不代表这些验收完成。当前发布线不自动合入此特性；安装包验证沿用已有基线，最多四次，不发新版本。
