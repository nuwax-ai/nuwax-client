# 截图标注再次编辑

用户验收发现：文字与图形完成绘制后不能再次选中修改，文字缺少独立字号。

状态：实现、捕获域 191 项测试、隔离 Electron 原生交互与 PNG 像素回归、严格类型检查及 main 构建通过；待用户在开发客户端验收。

## 实施范围

- 标注保留为可编辑对象；增加选择工具、选中边框与缩放控制点。
- 点击已有文字进入编辑，拖动文字可移动；文字字号独立于线宽，提供数值输入。
- 矩形、椭圆、箭头、画笔、马赛克可选中、移动、缩放、删除；适用的颜色与线宽修改即时预览。
- 编辑保持原来的绘制顺序；撤销和重做覆盖新增、修改、移动、缩放及删除。
- 选择辅助框不进入最终 PNG，所有坐标按截图物理像素转换，沿用当前屏幕选区。
- 增加四语言文案，保持现有截图/录屏和 IM 公共桥契约。

## 验证

- 纯函数测试验证图形命中、尺寸、历史恢复、修改后的叠加顺序。
- 隔离 Electron 原生输入回归验证文字重编辑、字号、图形移动缩放、撤销重做与 PNG 结果；保留多屏放大镜回归。
- 运行捕获域测试、类型检查、构建和 overlay/pin 检查；刷新开发客户端后交给用户验收。
