# NW-333 Windows 关闭自启动后清理遗留注册

在本组独立工作区实施。当前 Electron 登录项只匹配当前 exe/参数，历史产品 AppUserModelID 的 Run 项、Startup 快捷方式可能在换路径后残留；保存的关闭选择也没有在下次启动时重新协调。

1. 保留 Electron 当前项读写，Windows 状态读取采用 executableWillLaunchAtLogin，覆盖同 exe 的不同参数。
2. 新增局部 Windows 适配器：枚举 HKCU/HKLM 的 32/64 位 Run 项和两处 Startup 目录；只删除精确产品标识与 Nuwax.exe 匹配，或当前/标准安装路径且旧产品名匹配的项。数据与命令分开传递，删除前复核原值，禁止提权和触碰其他产品/开发档案。
3. 用户关闭时先保留关闭意图，再移除并回读；失败返回失败，下一次包启动按已保存的关闭意图重试，不能被默认开启覆盖。没有创建过计划任务的代码依据，不删除未知计划任务。
4. 用注入的注册表/快捷方式夹具覆盖旧路径、多参数、机器级拒绝访问、条目竞争替换与异产品保留；测试绝不访问真实 Windows 启动设置。完成商业保护网和本地提交，正式 Windows 场景保持待验。
