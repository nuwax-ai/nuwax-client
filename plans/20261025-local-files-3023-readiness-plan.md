# 本地文件直访接入当前候选线

- 基线：`release/v3.0.23@1f947181`；版本最终沿用 3.0.23 或改为 3.1，由用户后续决定，本批不改版本。
- 范围：按用户澄清及 `specs/local-file-management.md` 完成文件预览、打开、编辑、新增、删除的本机路线；删除进入系统回收站。沿用现有读能力，补齐写桥。
- 工作区：独立 `codex/local-files-3023-readiness`，保留原工作区、旧重开分支与 PR #66 的改动。

## 实施

1. 先将注册回归恢复为缺省开启 / 显式开启 / 显式关闭三态，证明当前 release 硬门控阻止前两态。
2. 移除 local-files 清单的发布强关，继续通过通用注册表和 `features.local-files.enabled` 读取设置；不在组合根加入特性分支。
3. 在 local-files 模块中增加有界路径与原子保存的写操作，扩展前端桥事实源/生成快照、preload 和能力白名单，前端在现有服务入口分流。
4. 修正 Electron 验收脚本对旧特性入口的引用，只启用待验 local-files；复用旧分支的跨平台路径夹具与 Windows 运行入口。
5. 同步当前 API 状态；给出内聚、分层、维护性结论，以及代码、测试、运行时和实包各自完成度。

## 验证与交付

- 分域：注册、local-files、工作区解析、来源/凭据隔离和 preload。
- 当前前端 pin 的本地文件相关回归；宿主桥、特性边界、overlay 和 pin 检查。
- 隔离副本内商业与社区质量门；真实 Electron 仅用临时 profile / 文件夹具，不读取用户文件或账户。
- 不以历史 Mac/Windows 结果替代当前候选安装包验收；Windows 仅 EXE，保留真实账户、保存对话框和升级验收缺口。
- 仅形成代码分支和评审材料，不触发安装、系统配置、tag、发布或公开更新指针。
