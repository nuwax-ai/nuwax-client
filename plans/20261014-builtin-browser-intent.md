## 问题

1. **网页任务只能绕道 Nuwax Computer Use。** 今天 Agent 操作网页只能经独立程序 Nuwax Computer Use（内含 cua-driver）驱动外部浏览器：需要辅助功能和屏幕录制授权，占用整个桌面，用户无法在客户端内看到页面或直接接手。没开 Computer Use 的用户没有任何网页操作能力。
2. **现有控制层让任务频繁中断。** 主进程网关的设计偏向"防出事"，没有把"任务能完成"当目标：
   - 任何一次工具报错（如找不到元素）都会暂停任务并关停 Nuwax Computer Use 守护进程，必须用户点恢复（`overlay/.../cua/taskController.ts:109`、`mcpGateway.ts:179`、`computerUse.ts:1032`）。
   - 同一动作同参数连续超过 3 次即判定"重复动作"，且不可恢复；连续滚动、方向键选择等正常操作会直接终止任务（`taskController.ts:83`、`:133`）。
   - 整台桌面只有一个使用者；浏览器类工具在后台执行、不占用鼠标，也被"桌面忙"拒绝（`taskController.ts:65`）。
   - "动作前必须先观察"不区分目标：观察 A 窗口后可以操作 B 窗口（`taskController.ts:78`）。
   - "限定窗口"模式把浏览器整体排除，无法做到"只操作这个浏览器窗口"（`windowScope.ts:12`）。
   - 约 50 个原始工具直接交给模型，没有"什么情况用哪类工具"的指引。
3. **没有任务成功率的度量。** 现有验收覆盖安全控制和签名，没有覆盖 Agent 是否把任务做成、做了多少步、打断用户几次。

## 预期结果

可观察的验收点（不写实现方案）：

1. **客户端内可浏览。** 用户在客户端内打开浏览面板，可以手动浏览、登录网站；Agent 在当前会话里读取页面、导航、点击、输入、滚动，用户实时看到每一步。
2. **不依赖系统授权。** 内置浏览不需要辅助功能和屏幕录制授权，macOS、Windows、Linux 行为一致。
3. **用户随时接手。** 用户可以暂停 Agent、直接在页面上操作，再交还；交还后 Agent 必须先重新读取页面，才能继续操作。
4. **登录态可复用且隔离。** 网站登录态保存在客户端专用的存储分区，重启后保留；与 nuwax 前端页面、商业账号的登录 cookie 互不可见。
5. **两条通道，一套控制。** 内置浏览和 Nuwax Computer Use 共用一个控制条和同一套会话控制权、预算、暂停和停止、操作记录。并发按资源划分：桌面前台输入全局只允许一个使用者；内置浏览按标签页加锁，不同会话可以同时操作各自的标签页。
6. **错误分级，不再动辄停机。**
   - 可恢复错误（元素不存在、引用过期、页面已跳转）作为结果交还模型，计入预算，不打断任务。
   - 结果不确定（超时、连接中断）时暂停，等待用户处理。
   - 越权或违反安全规则时直接停止。
   - 只有第三类情况才关停 Nuwax Computer Use 进程。
7. **重复判定改为"无进展"判定。** 同一动作重复执行、且前后观察结果没有变化，才判定卡住；触发后允许用户人工恢复一次。
8. **观察对应目标。** 写操作的目标（窗口、标签页）必须与最近一次观察的目标一致。
9. **限定窗口模式支持浏览器。** Computer Use 限定到某个浏览器窗口时，允许对该窗口对应的页面使用浏览器类工具。
10. **模型有工具选用指引。** 网页任务优先走内置浏览；原生应用和跨应用操作走 Nuwax Computer Use；内置浏览打不开的网站，可以改由 Nuwax Computer Use 操作用户自己的浏览器（降级方式见开放问题 4）。
11. **有基准任务集。** 覆盖网页类和原生应用类任务，记录成功率、步数、人工介入次数和耗时；改造前后各跑一次做对比。

## 用户角色

- **商业版已登录用户**：可以使用浏览面板，也可以看着 Agent 操作并接手。
- **Agent**：本地引擎会话，凭宿主在会话创建时签发的凭据调用工具（沿用 `cua/sessionAuthority.ts` 的机制）。
- **未登录**：不提供 Agent 网页操作能力。浏览面板本身是否可用见开放问题 2。

## 字段和状态

- **标签页**：空闲、加载中、Agent 操作中、用户操作中、崩溃或无响应。每个标签页记录归属会话和最近一次观察的版本号。
- **任务**：沿用现有阶段（运行、暂停、停止、失败、完成），新增"等待用户交还"。暂停原因区分：用户暂停、结果不确定、无进展、预算耗尽、越权。
- **操作记录**：工具名、目标（窗口或标签页）、结果分级、耗时。不记录输入内容、页面正文和截图，与现有规则一致。

## 权限规则

- 网页工具只对持有有效会话凭据的本地引擎会话开放。登出、换企业域、取消任务、退出应用时，立即撤销凭据，迟到的响应不能恢复操作权限。
- 网页内容所在的进程不具备客户端内部能力：没有 Node、没有客户端预加载接口，与 nuwax 前端页面和商业账号 cookie 分区隔离。
- 导航只允许 http 和 https；不允许忽略证书错误。
- 访问本机和内网地址的策略待定（开放问题 5）。客户端自身在本机回环地址上有网关和文件服务，这里存在被网页或 Agent 误用的风险。
- 网站申请摄像头、麦克风、定位、通知等权限，默认拒绝或询问用户（开放问题 5）。

## 异常场景

| 场景 | 预期处理 |
|---|---|
| 网站拒绝嵌入式浏览器（如部分 Google 登录） | 明确提示，并提供降级到 Nuwax Computer Use 的路径 |
| 页面崩溃或无响应 | 标签页标记为崩溃，当前动作按"结果不确定"处理，可重新加载 |
| 页面跳转后元素引用失效 | 作为可恢复错误交还模型，要求重新读取页面 |
| 网页打开新窗口或弹窗 | 进入新标签页，归属同一会话 |
| 网页 JS 对话框、HTTP 认证框 | 读取后由 Agent 处理，或交给用户处理 |
| 用户关闭面板或标签页时 Agent 正在操作 | 取消在途动作，任务暂停 |
| 两个会话争用同一个标签页 | 后来者被拒绝，并给出明确原因 |
| 页面过大，读取结果超长 | 截断或分段返回，不能整页塞给模型 |
| 登出、换域或应用退出 | 撤销凭据，停止在途动作；网站登录态是否清除见开放问题 3 |
