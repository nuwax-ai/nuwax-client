# BUG 2687：截图工具栏、录屏设置与结果预览

来源：[禅道 2687](https://zt.nuwax.com/index.php?m=bug&f=view&bugID=2687) 三张飞书参考附件；2026-10-28 用户明确本次范围。

## 范围

- 顶部提供截图 / 录屏切换，保留整屏、窗口和区域选择；选区下方使用浅色横向图标工具栏，保留标注、样式、撤销/重做与取消/确认。
- 录屏选区旁提供开始录制按钮与 MP4/GIF 格式选择，沿用现有编码器可用性、选区、时长与质量约束。
- 录屏结果使用独立视觉样式的预览区、播放/时长信息以及下载、复制到剪贴板操作。普通视频支持播放与定位；GIF 保留循环预览，不提供虚假的视频时间轴。
- 通用截图入口确认后直接复制静态图片，完成后释放临时结果，不再打开预览弹窗；复制失败明确提示。IM 已有会话草稿附件接入保持现有行为。
- 不做滚动截图、提取文字、摄像头、鼠标设置、时间轴裁剪；不改 GIF 编码或系统热键逻辑。

## 实施

1. 修改产品 overlay 内捕获窗口布局与交互；使用现有受信窗口桥，不增加对外接口。
2. 调整常驻结果控制器和录屏预览组件，覆盖复制、保存、关闭及卸载时的互斥与资源释放；同步四语言。
3. 在隔离的源码与 overlay 合成副本运行捕获域测试，以隐藏 Electron 合成画面验证布局、模式/格式切换、选框与标注回归并保存截图。
4. 检查边界、overlay、pin 与差异，仅同步本次文件；不覆盖当前工作区其他在途改动。

## 验收

- 截图工具栏在窄屏和靠边选区内可用；标注、字号、撤销/重做、选框调整及右键/Esc 取消继续有效。
- 模式切换保留选框，MP4/GIF 选择影响实际输出；缺失编码器时沿用现有失败提示并阻止录制。
- 静态截图成功后复制一次且无结果弹窗；复制失败、捕获取消、并发、卸载后迟到响应不泄漏临时结果。
- MP4/GIF 仍有预览、下载和复制，异步操作期间阻止重复操作，失败可重试。
- 源码和合成窗口验证不等于真实安装包、多屏/DPI与系统剪贴板验收。

## 实施结果

- 已完成顶部截图 / 录屏切换、浅色横向图标工具栏、按需展开的标注样式，以及 MP4/GIF 录屏设置面板；“开始录制”按参考附件使用纯文字按钮。模式切换保留选区和上次格式。固定 GIF 入口在桌面与 portal 来源中均保留正确格式，不放宽主进程输出校验。
- 静态图片确认后直接复制，成功/失败均释放临时结果；复制期间保持并发锁，卸载后的迟到完成不弹提示。静态图片不再强行显示隐藏的客户端；录屏结果继续恢复主窗口展示预览。
- 录屏预览使用真实媒体播放器、文件信息及下载/复制按钮；GIF 使用循环图片预览。四语言文案与 I18N_KEYS 已同步。
- 隔离商业副本捕获相关 **37 个测试文件、415 项通过**；调整窗口恢复策略后，主进程入口 **25 项定向回归通过**。
- 隐藏独立 Electron、合成三屏与 Chromium 输入通过：标注编辑与字号、颜色、撤销/重做、窄屏布局、模式与格式切换、选框八方向缩放/移动、最终输出 crop、右键/Esc 取消、录制控制条。真实 React/antd 预览验证通过 MP4 播放/定位、复制、下载、关闭、窄屏，以及静态图片自动复制无结果弹窗。
- 捕获主进程模块 esbuild、预览 renderer 构建、模块边界与 diff 检查通过。全库 TypeScript 仍有既有诊断；同一隔离副本对照修改前后未发现新增诊断，不宣称全库类型检查通过。
- 工作区旧 overlay 台账有 9 个本任务路径落后于已提交来源。确认 16 个现有任务文件逐字节等于修改前 HEAD overlay 后，备份旧文件与台账并校正已验证的生成归属，再经正式同步脚本应用。正式同步同时更新了此前落后的生成副本，外层源码仅含本次捕获改动。最终 `overlay:check` 为 0 个待同步文件，`check:pin` 通过；其他在途源码未被覆盖。
- 未打包或发布；Mac/Windows 真实安装包、物理多屏/DPI 和系统剪贴板互操作仍待实机验收。
