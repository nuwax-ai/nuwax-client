## 实施

1. 新增仅手动触发的 package-validation workflow，独立并发组、只读仓库与 Actions 权限，不接入 Release/OSS/更新指针，不使用发布凭据。

3. 使用既有本地 pack 入口、独立临时输出；Windows 仅 NSIS EXE；只上传完整包与验证上下文/哈希，排除更新 yml、blockmap、MSI 和发布元数据。
4. 同一 validation_series 跨源码提交、手动新 run 和 rerun 合计最多 4 次启动；读取历史失败时停在构建之前，不自动换系列或重试。当前这一轮不通过新系列绕过已达到的停止条件。
5. 禁用 Beta 发布工作流中的 QA 分支/手动触发入口；Beta tag 正式路径及 Stable 工作流不改。
