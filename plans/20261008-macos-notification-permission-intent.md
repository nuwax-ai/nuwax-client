# 意图：检测 macOS 消息通知是否开启

- 日期：2026-10-08
- 来源：用户要求「添加一个消息通知是否开启的检测（macOS）」；在现有系统授权页增补一项。

## 问题与预期结果

用户无法从客户端授权页确认 macOS 是否允许本应用发送消息通知。增加「消息通知」状态，未开启或无法检测时可前往系统通知设置；返回客户端或手动刷新后重新检测。

## 范围与约束

- 检测当前 Electron 应用身份的系统通知授权，区别于 IM 的应用内通知偏好和专注模式。
- 沿用既有 permissions IPC 和授权页，不新增业务接口，不自动申请授权、不发送探测通知。
- 仅 macOS；Windows/Linux 沿用当前行为。保留现有工作区改动，商业实现留在 overlay。
- 无新增产品决策；技术未知项是原生读取及打包可用性，由编译、Electron 实测与回归验证。
