# 意图：修复 Windows 升级安装无法关闭 Nuwax

- 日期：2026-09-23　发起人：用户
- 状态：已接受（用户明确要求接手处理，2026-09-23）

## 问题

Windows v1.0.28 assisted 安装向导在安装阶段提示“Nuwax 无法关闭。请手动关闭它，然后单击重试以继续。”，导致升级无法继续。

## 预期结果

普通用户启动的 Nuwax 能在升级安装时正常退出；若应用清理耗时，安装器会等待；若进程仍未退出，安装器会结束 Nuwax 进程树，避免其子进程继续锁定安装文件。无法关闭时仍提供重试或取消提示。

## 受影响的能力面

仅 Windows NSIS assisted 安装器的运行中应用关闭流程；macOS、Linux、MSI 与应用业务功能不变。

## 约束

- 仅修改商业 overlay，不改基座 submodule。
- 保留 per-user 安装只处理当前用户进程的限制。
- 不在本轮引入 UAC 提权强杀；安装器无权关闭的提权应用继续由用户手动关闭。
- 打包后 Windows 交互式安装验收仍是最终行为证明。

## 开放问题

- 无；提权运行的应用不自动弹 UAC，按手动关闭兜底处理。
