# 意图：Nuwax 客户端扩展体系与 Agent 环境配置

- 日期：2026-11-04
- 发起人：产品需求
- 状态：目标及产品边界已确认（用户，2026-11-05）

## 问题

现有两个任务分别提供了主题配置能力和 DSH 插件运行能力。用户进一步希望：内置几款可直接使用的主题，同时支持自定义；开启本地 MCP 后，Agent 可以修改主题文件；以后还能通过壳公开的配置和扩展接口，调整自己的工作环境。

目前主题包、本地目录关联和热更新已有实现；DSH / DS-Bot 已有独立运行宿主实现，仍在完成验收。连接两者的通用壳能力入口、Agent 授权及受控变更流程尚待交付。

## 背景和总目标

### 产品边界

- 面向用户集成的是 DS Bot 工作台，DSH 是内部运行底座和插件兼容层。
- 用户选择保留独立窗口，只展示 Bot 对话、团队、记忆、任务、浏览器等业务功能；不提供切回经典 DSH Agent、DSH 账号或通用管理界面的路径。
- Nuwax 主壳统一管理启停、模型授权、显示语言以及兼容插件的安装、启用、禁用、公开配置和移除。Bot 窗口的运行配置入口跳转主壳；现有 Bot 任务与数据不搬迁。
- 主题与 DSH/DS Bot 仍使用各自包格式；不重写运行时或原生插件管理器。第三方来源、许可证及开源致谢保持可查。

**将 Nuwax 建设为用户可自定义、可接入第三方插件，并可授权 Agent 配置和扩展的桌面工作环境。**

用户可以直接使用内置能力，也可以制作自己的主题、安装兼容插件，或用自然语言让 Agent 在已授权范围内完成这些操作。壳负责声明支持的能力、检查变更并报告实际生效结果。

最小新增交付应优先覆盖前三项：形成可由真实 DS-Bot 调用的主题 MCP 闭环。代码集成和已有功能验收分别保留证据，不因目标接受而视为完成。

## 用户角色

- 普通用户：使用内置主题和 DS-Bot，控制 Agent 的授权范围，查看和恢复配置变更。
- 自定义用户/主题作者：编辑主题目录、校验、导入导出和分享主题包。
- Agent：发现并调用用户授权的壳能力；首个闭环优先使用 DSH / DS-Bot，随后验证现有 Nuwax Agent 的复用。
- 插件作者：沿用 DSH 插件格式与生命周期接入兼容插件。

## 功能范围与交付顺序

### 第一阶段：现有两项能力各自完成交付

1. 主题：收敛内置主题、个人副本、目录编辑、热更新、导入导出及恢复默认。
2. DSH：继续完成现有真实运行和安装包验收。当前人工验收依用户已定范围，先集中于 macOS arm64。
3. 两项能力归入同一客户端扩展规划，分别保留实现与验收状态。

### 第二阶段：用主题打通 Agent 配置环境的首个闭环

1. 用户开启本地 MCP，并授权主题能力。
2. Agent 读取规范、当前主题、可编辑个人副本及版本。
3. Agent 按要求提交多个主题文件的修改。
4. 客户端完成完整校验、并发检查、保存及快照发布，返回实际结果。
5. 用户查看效果，可撤销合法但不满意的修改；关闭授权后后续操作被拒绝。

本阶段交付应能通过真实 DSH / DS-Bot 对话完成“创建一个个人深色主题并应用，再恢复原主题”，无需为每种风格修改客户端源码。

### 第三阶段：复用同一入口开放壳配置和 DSH 插件管理

1. 只开放明确声明格式、生效方式和恢复方式的壳配置。
2. 对接 DSH 原生插件管理的查询、安装、配置、启用、禁用和移除。
3. 按能力与操作授予权限，展示变更记录和执行结果。
4. 验证同一能力接口可供现有 Nuwax Agent 使用，避免为每个 Agent 重建一套配置逻辑。

第二阶段可与第一阶段剩余验收并行设计，但整合后的完成结论须同时包含基础能力与跨模块闭环证据。

## 核心流程

```text
用户提出环境调整需求
    → Agent 发现壳公开的能力与当前状态
    → 检查用户授予的操作范围
    → 提交主题、配置或插件操作
    → 对应服务校验并执行
    → 返回实际生效状态与恢复入口
```

统一能力发现、授权和结果反馈。主题继续使用静态主题包；DSH 插件继续使用自己的运行时和原生管理器。主题可独立使用。

## 字段和状态

- 能力：稳定标识、配置格式、支持的操作、当前可用状态和不可用原因。
- 授权：调用方、允许的能力与操作、有效状态；撤销须阻断后续调用。
- 主题/配置变更：目标、读取时版本、候选修改、校验结果、生效方式、恢复记录。
- 插件操作：插件身份与版本、操作类型、当前状态、完成状态、失败原因及重启要求。
- 配置变更至少区分：待校验、冲突、校验失败、已保存、已生效、等待重启、已恢复；具体字段在接口规格阶段确定。

## 权限规则与约束

- Agent 通过壳提供的受控能力修改允许的资源；主题文件写入由主题服务解析目标目录和包内路径。
- 内置主题修改时先生成个人副本，保留默认主题作为恢复入口。
- 现有主题偏好作用域、页面来源检查、DSH 账号/域名隔离与模型凭据管理继续生效。
- 主题支持完整候选校验、版本冲突检测和历史恢复；插件恢复遵循原生生命周期，不承诺撤销任意插件代码已产生的外部副作用。
- 原有 Nuwax 会话引擎与独立 DSH Runtime 继续各自承担既有会话，不因统一入口改变会话归属。
- 独立插件窗口是否跟随 Nuwax 主题，需要单独适配和验收，现有主题覆盖不能直接推导为已覆盖 DS-Bot UI。
- 扩展规划不自动授权合并、发布或追加出包；保留当前 DSH 冻结源码的 macOS arm64 验收及出包预算。
- 不修改或提交 `agent-platform`；平台依赖缺口交由相应负责人处理。
- 当前发布排除的终端持久化、多终端和运行实例管理不随本次整合带入发布线。

## 异常场景

- 无效主题、资源缺失、保存失败：返回具体错误，保留最近有效状态。
- 用户或其他 Agent 已修改同一主题：返回版本冲突，重新读取后再提交。
- 写入过程中出现目录监听事件：不向页面发布未经完整校验的中间状态。
- 授权关闭或运行身份失效：后续调用被拒绝，不能仅移除入口而继续允许已连接调用方操作。
- 配置需要重启：返回等待生效状态，不能仅因保存成功就报告已生效。
- 插件缺少依赖、启动失败或运行时不可用：显示真实状态与恢复操作，不以进程存在作为成功依据。
