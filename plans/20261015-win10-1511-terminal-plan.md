# Windows 10 1511 终端兼容实施计划

对应规格：`specs/win10-1511-terminal.md`。本次为既有兼容性 BUG 的跨模块修复；用户已明确要求保留旧系统内嵌终端，继续实现，无额外产品决策。

1. 固定 WinPTY 归档与许可证；实现独立兼容服务、WinPTY 生命周期和 ttyd 协议测试。
2. 增加 Windows build 边界选择及测试，保持新系统和其他平台路径。
3. 将兼容资源构建、散列缓存、许可证接入 prepare / pack / Windows CI；缺失时构建失败。
4. 运行针对性测试与商业质量门，检查 overlay 同步和 pin 纯净性；在可用 Windows 上真实运行兼容后端。
5. 记录验证证据及 Build 10586 安装包验收限制，提供可复现命令与产物位置。
