# 计划：Nuwax 客户端 3.1 Beta

## 目标与决定

- 2026-10-19 用户决定：后续客户端需求放到 3.1；先建开发线，完成需求后再发 beta.1。目标首个版本为 `3.1.0-beta.1`，目前不创建 tag、Draft、安装包发布或更新源指针。
- 开发线：`release/v3.1.x`。起点为 `9b8f06984d4131ca16a94261897242ab2336c32a`，已经包含公开 beta.7、Windows NSIS 卸载名称修复，以及对应验证记录。
- 3.0 stable 的历史归档与 main 同步已交给其他人。本任务停止接管 PR #26 和旧 main 的 overlay 兼容记录，不等待归档完成再开始 3.1。
- 本轮独立工作区：`/Users/apple/.codex/worktrees/client-3-1-beta/nuwax-client`。后续代码从 3.1 线开独立 `codex/*` 分支，经 PR 回流；不混入其他工作区的未提交改动。
- 本文件是 3.1 的持续计划。[10 月需求审计](./20261019-october-client-followup-plan.md)保留为版本切换前的历史事实，不再以其中的 3.0 合并安排驱动本任务。

需求来源：[10 月版本规划](https://agent.nuwax.com/repo/doc/Fy9KinwyNzHU6XsH?hide_menu=true)、[团队问题表](https://agent.nuwax.com/repo/doc/xcCBum7Kqz4TVJYU)、[产品问题表](https://agent.nuwax.com/repo/doc/UikwEDyq6NhUP2JM)。

### 3.1 后续 Beta 候选

| 需求 | 已有基础 | 纳入实施前还需确认 |

| IM/资料库/订阅页面问题 | 共用前端与独立微应用承载 | NW-065/080/098/106 等先确认实现归属与当前包复现，不按“桌面客户端”模块字段全改成壳任务 |

终端多开、pi-agent、NW-009、旧 UTF-8 跨仓修复及受保护验收工作区，沿用原暂缓/叫停/冻结决定；开启 3.1 不自动解除这些决定。确需恢复时再按具体任务调整计划。

### 3.1.0-beta.1 发布条件

1. 明确本次实际纳入的任务，具备对应实现、相关自动化证据与未覆盖范围；未定位的问题继续公开跟踪，不借版本升级标为已修。
2. 变更经 PR 进入 `release/v3.1.x`。基座、前端和产物 pin 对应且远端可取；overlay、来源授权、认证及发布物完整性检查保持有效。
3. 相关源码检查通过；发布前执行完整社区/商业双轨、前端、桥契约和平台构建门禁。社区测试使用隔离副本。
4. 对实际候选完成登录、普通会话、业务新窗口、文件、截图录屏及安装/升级回归。Windows ARM 仿真、真实 x64、旧 Win10、MSI、系统权限与签名分开记录。
5. 完成需求与验收后，再按 `npm run release -- --version 3.1.0-beta.1 --dry-run` 预检，并根据当时的发布授权创建不可变 tag、经现行流水线发布。预检通过不等于已经发布。
