# 截图快捷键冲突修复

状态：代码实现与代码级验证完成。针对 macOS Command+Shift+A 被其他应用系统热键截获的问题，补齐前台注册和拒绝/回滚链；保留应用内作用域和默认键。

## 改动

- 在截图偏好模块封装 macOS/Windows 的系统快捷键注册检查：保留注册直到同步配置写入完成后释放；已有其他特性的注册不能覆盖或注销。Linux 不做全局注册探针，避免 Wayland 授权及持久绑定副作用。
- macOS 主窗口获得焦点时注册截图/录屏系统热键，失焦立即注销本模块拥有的绑定，关闭窗口时清监听；保存后重新绑定，迟到回调必须校验代次和窗口焦点。继续复用既有 IM 焦点认领与宿主截图入口。其他平台沿用原输入路由。
- 保存截图/录屏键前检查可用性，失败不写配置、不通知菜单刷新，返回可区分的错误；保持现有 settings.set 的布尔成功值与 Promise 拒绝语义。
- 前台改键先预留新组合，写入完成前新回调不能触发；注册被拒绝或写入失败时旧绑定保持有效。成功后按差异切换，保留未改的录屏/截图键，不先释放全部绑定再争抢。
- 设置页对不可用组合给出换键提示；说明应用内作用域及其他应用全局快捷键的冲突边界。四语言同步。
- 不宣称临时注册能检测所有事件拦截器：本机飞书运行时默认键的探针成功，自动化向 Nuwax 定向发送该组合可打开截图；这不等于真实物理按键冲突已复现或解决。系统已占用的同键不能通过保存设置强制抢占。
- 本机两个 Electron 40.8.2 进程注册同键均成功，否定了“外部应用占用必然返回 false”的检测假设。[Electron 上游说明](https://github.com/electron/electron/issues/53770#issuecomment-5613616812)确认该返回值取决于 macOS 版本及对方注册方式。前台注册用于补齐触发路径，失败检测仅拒绝已知不可用状态，不保证识别所有共享绑定或独占截获。

## 回退

撤回本批前台注册、预留/写入编排、设置调用与文案，恢复原有菜单快捷键及设置保存行为；没有持久化迁移。
