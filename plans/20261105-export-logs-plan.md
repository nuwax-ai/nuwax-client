# 日志 ZIP 导出

- 在日志页“打开目录”旁增加“导出日志”，调用仅限壳本地主框架的 IPC。
- 主进程固定读取当前产品应用目录下的 logs，弹出保存窗口，默认下载目录及带时间戳的 ZIP 文件名。
- 流式递归压缩全部日志及子目录，保留链接而不跟随读取；临时文件写完后再替换目标，失败清理临时文件。
- 导出期间显示加载状态，取消静默，成功及失败用四语言提示。
- 验证真实 ZIP 内容、产品目录隔离、来源授权、取消、失败及再次尝试；运行相关测试和构建。
