# Windows 安装、卸载权限反馈

已知事实：本地签名 Beta.4 在同学的 Windows 11 23H2 普通用户安装时解压失败，默认和自定义目录均试过；管理员安装成功。提供的卸载日志在 `ProgramRemoval` 阶段对 `C:\Program Files\Nuwax\LICENSE.electron.txt` 报拒绝访问，范围为 `CurrentUser`，历史数据尚未开始清理。

隔离复现：UTM 上同一签名包的 ZIP 与实际 nsisunz 插件在高、低权限令牌下均解压成功；生产路径选择宏在两种令牌下均返回用户 Programs 目录。普通用户删除受保护程序文件、删除只读自有程序文件，均可复现所提供的卸载异常。不能据此宣称复现了原机的首装失败。

实施范围：

- 程序文件删除前检查真实删除权限；不足时在任何程序移除和历史数据清理前停止，保留原始目标与权限信息。
- 仅对嵌入清单声明的自有程序文件处理只读位；保留未知文件，不调整 ACL、不跟随重解析点。删除失败尽力恢复只读位。默认保留历史数据不变。
- 权限错误提供明确重试指引，不按路径猜测注册范围，不自动切换账户或安装范围。
- 在解压和退出旧客户端前，检查程序、临时及缓存目录的真实写入权限，失败明确指出目录；不创建目标安装目录。
- 增加只读原机诊断入口，收集该产品的注册、路径权限、文件属性、包签名和安装阶段；不读取业务数据、不改目录权限。

验证：运行 Windows 原生卸载夹具，覆盖只读自有文件、默认保留数据、权限不足发生在后续文件时仍无部分删除、锁与重解析点等边界；编译完整 NSIS 安装/卸载模板。原机首装验收需诊断结果支持，按用户后续授权统一消费 PR #132 的备份清理修复，在既有 Beta.4 基线上构建一个隔离 Windows 候选（按 SHA/run 区分），不占用新版本或改已发布 Beta.4。签名仅本地进行，原机 23H2 留待明日验收。

已验证：UTM Windows 11 原生 PowerShell 5.1 高、低权限令牌卸载各 17 项通过（低权限无跳过，含后续文件拒删及纠权重试）；安装预检高、低令牌各 14 项通过（含三类目录拒写、中文路径、重解析与探针清理）。完整 vendor 安装/卸载模板及定向 Node 检查 32 项通过，新增安装预检后重新编译确认。
