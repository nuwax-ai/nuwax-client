# 截图与录屏 UI 优化

针对当前截图标注工具混排、样式操作不直观的问题，优化原生浮动面板的层次与可发现性。

状态：实现及本地回归通过；win-pc 菜单、截图和三格式录制连续两轮真实采集验收通过，已修复 Windows 资源构建/依赖、MP4 探测与小区域编码、选择窗高度偏差。已安装的 3.0.14-beta.1 未包含功能，Windows 新包尚未发布/替换；物理多屏等范围与首轮偶发无帧观察项见 `docs/acceptance/20261013-capture-ui-windows-menu.md`。

## 范围

- 将绘图、撤销/删除、样式和截取范围/完成操作分组，统一面板与状态视觉。
- 提供常用颜色、字号快捷选项，保留自定义颜色和 8–144 字号；线宽显示当前数值。
- 样式区跟随当前工具或选中对象显示，选区工具、辅助提示、禁用及键盘焦点更明确。
- 美化录制控制条与窗口源列表，保留直角录制边框、选区跟随和 IM 返回契约。
- 浮动工具栏与提示限制在当前屏幕可用范围内，验证小屏与边缘选区布局。
- 用户追加 Windows 真机问题：核对 win-pc 安装版本与发布代码，补齐 Windows 顶部自绘菜单的截图/视频/GIF 动作；沿用现有捕获控制器与结果预览，保留悬停切换逻辑。
- 用户追加 Windows 实际采集验收：在 win-pc 登录桌面运行当前分支的隔离应用，使用生产捕获实现和锁定源码构建的 Windows 编码资源，验证真实截图、标注、MP4/WebM/GIF、暂停恢复、取消及播放；保存自建测试画面和分项报告。

## 验证

- 运行捕获域回归和独立 Electron 输入回归，验证快捷样式、撤销重做及 PNG 输出。
- 用隔离合成画面查看截图/文字/录制状态和紧凑布局，确保控件不溢出。
- 构建 main，同步 overlay 并检查 pin；保留其他工作区改动，更新开发客户端供手动验收。
