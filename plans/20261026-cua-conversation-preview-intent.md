# 意图：电脑操作预览只属于当前会话

- 日期：2026-10-26
- 状态：已接受；用户明确要求实施本轮会话中确认的展示规则。

## 问题与结果

当前浮窗聚合全局活跃任务，切到未调用 Computer Use 的会话仍能看到其他会话的窗口。改为只展示当前会话关联的活跃窗口，同会话多个窗口继续层叠。离开会话隐藏预览，切回恢复；用户主动关闭后不因切换或状态推送重开。

## 边界

切换只影响预览和预览采集，不暂停、恢复或停止执行任务。不恢复运行态自动打开任务详情的旧逻辑，不增加版本、出包、发布或修改前端产物 pin。会话归属由宿主的 ACP 会话元数据确认，不使用模型参数、窗口标题或最近活跃任务猜测。无法确认当前会话时隐藏。

## 开放问题

无产品待确认项。前端会话路由与宿主 ACP `projectId` 的对应关系需以当前源码核实；不能确定的入口保持隐藏，并在实施记录注明。
