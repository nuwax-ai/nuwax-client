# 意图：兼容 Windows 10 1511 的内嵌交互终端

- 日期：2026-10-15
- 状态：已接受；用户明确要求兼容工单 #2675 的 Windows 10 1511 / Build 10586，沿用内嵌终端。

## 问题

Nuwax 3.0.15 在该系统中启动 ttyd 失败：`ConPTY init failed`。MCP、Agent、文件和代理服务启动成功，终端失败使总体状态成为 service-failed。ConPTY API 从 Windows 10 1809 才提供。

## 预期结果

旧系统无需升级 Windows 即可启动内嵌交互终端；支持中文输入输出、Ctrl+C、尺寸调整、独立会话目录及关闭清理。较新 Windows、macOS 和 Linux 沿用现有终端。

## 受影响的能力面

商业客户端的终端可执行文件选择、兼容服务、资源准备、Windows 构建及开源声明。保持现有 WebSocket 地址、tty 子协议和 ttyd 帧协议，前端不引入第二套协议。

## 约束

- 兼容目标为 Windows 10 1511 x64；不扩展到 Windows 7/8、32 位 Windows。
- 终端继续只监听回环地址；复用现有网关的会话目录路由。
- 不通过忽略失败、禁用终端或切换外部窗口宣称完成。
- 兼容程序使用独立进程与 WinPTY API，不绑定 Electron/Node 原生模块 ABI。
- 保留现有 WIP；用户后续授权打 Beta 包给原反馈人复测，不改禅道状态。

## 开放问题

没有阻塞实现的产品问题。用户确认当前没有可用 Win10 测试机；Build 26200 的结果仅算回归测试，Build 10586 兼容性由原反馈人使用 Beta 包复测确认。
