# 截图快捷键误报页面失效修复

## 问题与范围

快捷键经 `HOST_CAPTURE_MENU_IPC` 到宿主常驻 `CaptureLauncher`，其 preload `interactive()` 却固定调用业务页的 `capture:interactive`；正常宿主页被业务页受信校验拒绝，返回 `untrusted`。截图、MP4、GIF 共用此入口。

## 实施

1. 为宿主交互捕获补齐独立内部 IPC，preload 按桥的宿主/业务身份选通道。
2. 两个通道复用同一参数校验和捕获实现，分别使用已有 hostIpc / ipc 校验，保留状态、结果所有权、模式切换、时长限制和会话取消语义；不修改公开桥类型或前端契约。
3. 用真实 preload 桥串联主进程处理器补回归，先复现失败，再验证宿主截图/MP4/GIF、业务页兼容及越权拒绝。在隔离的基座源码与 overlay 合成副本运行捕获域质量门，保留当前工作树在途改动。

## 验收边界

代码回归通过后记录结果；已安装客户端仍须使用包含修复的构建进行物理快捷键与系统剪贴板验收。本次不自动打包、发布或修改版本/pin。
