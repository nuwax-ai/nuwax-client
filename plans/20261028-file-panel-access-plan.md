## 实施顺序

1. 在 `nuwax/src/features/client-shell` 收敛来源判定和工作区恢复：区分宿主当前电脑身份与服务就绪状态；新会话服务不可用不回云端；用户重试重新解析工作区；目录选择复用一致的目标判定。
2. 补齐本机预览子资源：Markdown 空目录参数、HTML 旧同会话静态资源地址；继续按 owner/会话/授权根隔离，拒绝跨会话及目录越界，不放开业务凭据或回云端代理。
3. 在现有 `local-files` 特性及 API v3 桥中补面板上传文件/文件夹与 ZIP 导入能力。文件按 1MiB 分块传入主进程，上传采用临时文件与冲突校验后原子替换；ZIP 先校验条目与链接，再流式调用本机 file-server 导入指令，沿用覆盖确认和保留目录语义。取消、失败和会话过期不得转云端或报成功。前端类型事实源、overlay 快照、preload 与能力声明保持同步。
4. 对照面板工具栏、右键菜单和页面回调逐项接入。移动底层已有工作区内跨目录 rename，但面板缺独立入口；补入口时复用草稿保存及变更队列，处理冲突、目录自包含、预览路径和页签更新。保留删除进回收站、导出完整字节与取消清理语义。
5. 核对会话框选择目录仅在目标为当前电脑时用系统目录选择器；其他电脑/云端按目标浏览；不改 `ChatInputUnified` 的附件发送。

## 用户补充：Windows GIF 生成耗时

- 默认高画质改用低扰动的有序抖动，最高档保留原有误差扩散算法；不调整选区像素、帧率或色数，也不修改 FFmpeg 原生资源配方。
- 使用随包 FFmpeg，对同一段 1280×720、30fps、5 秒 VP8 素材交替编码三轮：默认高画质输出均为 1280×720、75 帧、5 秒；平均 2,753ms → 1,073ms，输出 7,444,397 → 6,518,604 字节，样本 SSIM 0.957970 → 0.960744。详见 `.cache/acceptance/gif-file-panel-20261028.json`。
- 该基准使用 Windows 参数路径、运行于 Mac ARM64，不能标作 Windows 性能验收；Windows 实际耗时和主观观感由 win-dbg 验证补齐。

## 三问自查

- 内聚：本机来源及重试归 `localFileService`，分块生命周期和原子上传归 `local-files/transfers`，面板移动复用草稿保存队列，不改消息附件上传。
- 分层：页面/面板消费统一文件服务；所有新 IPC 仍校验 owner、上下文与登录代次，原生主进程固定资源根与 loopback 目标；无新增架构违规。
- 维护：新命令采用可选 v3 能力，旧读取/写入能力继续兼容；本机缺少新命令时明确失败而非回云端。移动同步普通/差异页签与后代路径，失败保留源文件和草稿。
