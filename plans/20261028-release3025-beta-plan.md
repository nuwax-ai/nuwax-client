## 断网预览定位与补齐

- 本机主文件通道是 `nuwax-local://` 授权协议，直接从文件系统读 bytes，不需云端文件接口。真实独立 Electron 会话使用不可达代理阻断 HTTP/HTTPS 后，新授权文本文件仍能读取；本机 HTML 及其本机 CSS/JS/文件引用继续加载，通过原生协议的撤权、跨窗、越界、媒体 Range 与播放回归。
- 发现并修复：已知本机来源的上下文释放后，裸兼容 URL 曾可返回 null 并退云；现明确 `expired`。本机 Markdown 中同会话的旧 `/api/computer/static/{cId}/...` 图片路径现转换到当前授权根；跨会话或另指定根的图片不借用当前授权。
- 当前运行客户端为 3.0.24，所在电脑 MBP128；可见会话 `1743794` 的执行电脑显示为 soddydeMac-mini。本机配置工作区下未找到该会话目录。这是文件来源需要核对的现场证据，不将它等同于同机直连失败或声称已修复该远端文件离线访问。远端电脑文件不因当前客户端具备本机直连就自动变成本机离线副本；不加入隐式同步/下载。
- 前端验证：预览/路由/真实 Markdown 组件 9 文件 189 项通过；会话域 116 文件 1190 项通过；四个类型域零诊断，分层门通过（97 条既有豁免）。其余全库类型存量不作全绿声明。
- 继续走查发现：同一电脑 UI 重新注册时会丢已知本机标记，导出缺少上下文时也可退云；补齐同源历史继承及共用查找入口。新增回归在改前实际失败 3 项，修后通过；首次旧桥使用新会话夹具，保留浏览器/旧桥兼容断言与显式远端切换。
- PDF 的 @js-preview/pdf 2.0.10 内嵌 PDF.js 4.7.76，却默认从 unpkg.com/pdfjs-dist@3.1.81/cmaps/ 读取字符映射；这是本机文件 bytes 之外的实际外网依赖。现将精确匹配版本的映射以内联数据随前端入包，关闭 worker 自行取映射，不安装不使用的 Node canvas/path2d。Adobe 映射许可证随静态资源保留。真实 Electron 断网首次预览未嵌字体中文 PDF，实际取用 UniGB-UCS2-H 与 Adobe-GB1-UCS2，生成 1 个 canvas、11023 个非白像素，通过。
- 补齐后分域 11 文件 222 项、会话域 116 文件 1190 项通过；四个类型域零新增诊断，分层门通过。真实 Electron 断网及原生回归全部通过，仍不等于签名安装包或当前现场文件归属验证。

## 用户补充：目录选择与本地操作直觉

用户确认选当前电脑目录应直接弹系统目录选择框，文件树与预览沿本机来源。核对现有 `WorkspaceDirPickerModal` 共用入口先等待 `pickLocalWorkspaceDirectory`，本机成功/取消/失败均不挂载远端目录组件；仅明确未接管的旧桥、浏览器和其他电脑保留远端入口。`workspaceDirectoryPicker` 核对宿主 sandboxId、串行系统对话框，并在返回时复核身份；选择路径通过会话 workspacePath 交给原生工作区解析器。该入口已存在，本轮复用并验证，不新造另一套目录浏览 UI。

- 此次确认后进一步收紧首次访问：完整 v2 桥和 sandboxId 匹配即确认本机来源，不再等到目录解析成功才设标记。首次解析失败回归在改前实际失败 1 项；修后 4 文件 60 项通过，旧桥及显式远端兼容保留。
- 目录选择入口 2 文件 18 项通过。真实 Electron 中实际 PureMarkdownRenderer + ds-markdown + rehypeRaw 验证无序/有序列表的流式残留和最终剥离共 4 场景，通过；旁路业务卡片使用夹具，不代替完整在线会话验收。
- 外层脚本 456 项通过。前端冻结只选择本轮修复，另以合并提交送入声明版本线以满足 pin 远端可达，不将版本线上后续无关 AppDev 更新带入 Beta。
- 页面加载方式与文件数据路线独立：本地化页面消费包内 pin；直连页面消费线上部署。Beta 带配套前端，说明中提示开启本地化加速验收包内修复；本轮未部署生产 PC Web，也不修改用户当前客户端加载设置。
