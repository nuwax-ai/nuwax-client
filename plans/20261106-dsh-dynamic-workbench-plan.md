# DSH 原生插件工作台实施计划

## 目标

以 DSH Host/Client 插件生态承载 Nuwax 页面和本地生成组件。ACP 管理 Agent 执行，配置与 MCP 调用同一组工作台能力。首批贯通文件、终端和用户/Agent 共用浏览器。

## 基线与版本

- 基线为扩展集成分支 f70c784c，实施分支为 codex/dsh-dynamic-workbench。
- DSH 0.2.1-rc.5，better-sidebar 0.28.2，沿用现有账号隔离和宿主授权。
- 工作台使用独立 Profile，启动与 DS-Bot 模型授权解耦。
- 页面与 Agent 的会话身份由主进程验证。文件服务未就绪时报告实际失败，支持重试。

## 阶段

1. V0 完成真实插件加载、工作台入口、会话映射和浏览器/MCP 兼容原型。
2. V1 将文件、终端、浏览器作为 DSH 原生插件接入现有会话。
3. V2 提供组件发现、布局、配置、锁定、撤销和恢复能力。
4. V3 提供本地插件生成、构建、预览、版本激活与保存。
5. V4 建立故障清单、候选修复、场景验证与回退闭环。
6. V5 按依赖拆分首批业务页面，处理个人修改与产品升级兼容。

## 验收

- 原包安装/加载/禁用/恢复，覆盖实际 Client 挂载。
- 真实 DSH 会话与业务会话绑定，切换、并发、失效和重启可恢复。
- ACP Agent 经授权 MCP 操作界面，返回实际结果。
- 浏览器使用同一页面实例，支持人工接管并撤销自动化连接。
- 文件首次不可用和首次解析失败均可重试恢复。
- 布局并发修改检测、模块加载失败与最近有效版本恢复。
- 源码定向测试、真实 Electron 测试分别记录证据，安装包验收单独执行。

## 实施进度

- 已核对集成基线，原有 DSH 定向测试 19 项通过。
- V0 已打通独立 Profile、原生插件管理器、DSH Agent/Session 生命周期和 ACP 会话专属 MCP。
- V1 首批文件预览、原生终端、共享浏览器已接入独立工作台窗口。
- V2 已提供组件发现、布局版本检查、用户布局锁、显隐、分栏、浮动、尺寸及原生撤销/重做。布局适配绑定 DSH 0.2.1-rc.5。
- 真实 Electron 已覆盖 better-sidebar 0.28.2 的安装、Client 挂载、禁用和恢复，文件内容、终端执行、浏览器接管、会话隔离及布局保护。
- 商业回归 3,832 项通过、1 项跳过，DSH 定向测试 23 项通过，前端定向测试 65 项通过，主进程类型检查和构建通过。
- V3–V5 继续按后续批次交付，本批 PR 面向 alpha/v3.1.0，真实安装包与其他平台验收另行安排。
