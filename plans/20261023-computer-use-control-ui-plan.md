# 电脑操作浮窗界面重构

- 根据用户 Beta.4 截图，重做单任务浮窗，并将多窗口预览统一到相同的轻量视觉。
- 默认在客户端内部右上角；缩减文字堆叠，清楚展示运行/暂停状态、当前操作对象、最近一步和步骤数。接管与停止始终可见，暂停/继续为次级操作；保留关闭与拖动，窄窗口自动约束位置。
- 只展示正在操作/暂停的对象，任务历史继续由托盘入口承担。多窗口切换排序与现有预览、安全撤权、IPC 边界不改。
- 使用已有图标与翻译体系，兼容亮暗主题、键盘焦点和辅助名称；禁止在产品文案里暴露技术细节。
- 验证：复用现有交互测试，补必要的窄窗/拖动边界检查；在 mac-dbg 的新 Beta 以真实运行、暂停、关闭重开状态截图验收。代码与测试成功不等于包内视觉已通过。
