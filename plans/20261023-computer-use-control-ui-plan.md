# 电脑操作浮窗界面重构

- 根据用户 Beta.4 截图，重做单任务浮窗，并将多窗口预览统一到相同的轻量视觉。
- 默认在侧栏以外的会话内容区右上角。小尺寸窗口缩略图与层叠为主，悬停或键盘聚焦显示暂停/继续、停止、关闭；点击目标安全接管切窗。保留拖动，窄窗口自动约束位置，详细信息由托盘进入。
- 只展示已绑定的正在操作/暂停窗口。多窗口选择排序只改变预览顺序，实际接管沿用安全撤权与精确聚焦；浮窗私有 IPC 缩减到必要动作。任务目标配置、模式、诊断与历史由托盘入口承担。
- 使用已有图标与翻译体系，兼容亮暗主题、键盘焦点和辅助名称；禁止在产品文案里暴露技术细节。
- 验证：复用现有交互测试，补必要的窄窗/拖动边界检查；在 mac-dbg 的新 Beta 以真实运行、暂停、关闭重开状态截图验收。代码与测试成功不等于包内视觉已通过。

## 正式版前的位置调整

- 用户确认初始浮窗处于侧栏以外的整个会话内容区右上方，留出间距并避开顶部工具栏，不锚定到中间较窄的消息流。
- 单任务和多窗口共用初始定位：右侧内收 24px，顶部 72px。已拖动位置继续保留，缩窗仍按实际尺寸约束在客户端内；隐藏、关闭、接管和停止协议不变。
- 冻结 Beta.6 不改。本次位置调整只进入后续正式版源码，不能把 Beta.6 既有真机截图当作该调整的包内验收证据。
- 本次位置调整在独立源码副本运行现有 4 个界面域测试文件，29 项通过；原仓库基座工作区不执行 overlay 同步或清理。

## 浮窗职责收敛（用户后续确认）

- 根据最后确认，移除独立的展开/收起状态，以更小的窗口替代。只提供暂停/继续、停止、点击目标窗口后安全接管并切到目标、多窗口层叠和关闭。不再在浮窗展示窗口配置、模式切换、诊断、完整列表及历史。
- 默认缩略图尺寸 240×152 DIP（含边框阴影留白），最多显示四层，每层向左下错位 8px，总尺寸最多 264×176。实际窗口缩略图填充预览；悬停或键盘聚焦才显示操作条，亮暗主题一致。
- 标题拖动和缩略图直接拖动均支持，移动 4px 后判定为拖拽，松手不误触接管；位置持久化与小窗口约束保留。
- 多窗口预览共用原有单在途/500ms 采样预算，前后窗口交替轮询；关闭或主窗口隐藏立即停止预览。绑定、代次变化或锁屏立即丢弃旧帧。
- 多窗口选中层切至前方；目标点击继续沿用现有先撤权、等待原生动作排空、再精确切窗的接管流程，不新增或绕过执行权限。
- 目标选择、当前任务详情（窗口、状态、操作模式、最近动作）、历史统一由托盘「电脑操作」进入任务面板。首次尚无目标时在客户端内的任务面板完成选择，不让浮窗继续承载复杂表单。
- 历史只补可选的模式/范围摘要，兼容旧记录；不保存输入、剪贴板或屏幕内容。关闭预览不等同停止任务。
- 仍在当前仓库修改，保留其他任务正在编写的截图入口需求文档与全部基座 WIP；Beta.6 原包验收及后续源码交付分开记录。

- 内聚：预览页面只呈现窗口、层叠和四类控制，复杂管理归任务中心；预览调度统一限流和清理。
- 分层：renderer 与私有预览只调用宿主控制接口，任务授权、代次撤销、原生排空和精确接管仍在既有执行层；历史新增字段仅摘要，不含执行能力。
- 维护：删除旧表单、折叠菜单和多余控制路径；历史字段可选以兼容旧数据；保留断言私有 IPC 来源、关闭/隐藏/退出清理及陈旧帧拒绝的测试。
