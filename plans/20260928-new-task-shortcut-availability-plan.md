# Nuwax 客户端新建任务显隐与快捷键同步

用户要求客户端也跟随后台菜单状态，使“新建任务”隐藏后快捷键失效；启用时继续进入首页，不提前创建默认智能体会话。

1. 前端以已过滤的 `firstLevelMenus` 中 `new_conversation` 为唯一展示与能力状态，通过现有 `layout` 桥上报 `newTaskAvailable`；宿主命令消费端同样门控，布局卸载时上报不可用。
2. 商业客户端沿 `nuwax:layout-sync` 校验并接收该布尔值，仅主窗口受信业务 guest 更新主菜单状态。默认不可用；刷新、整页导航、guest 销毁时清理旧状态，独立窗口不覆盖主窗口。
3. mac 原生文件菜单、Win/Linux 自绘文件菜单及 guest `before-input-event` 都读取同一状态；隐藏时不显示新建任务项、不发送命令，启用后恢复。社区基座既有行为保持兼容。
4. 商业代码只编辑 `overlay/`，检查现有差异后同步到基座；前端修改在独立 `~/workspace/nuwax`，不覆盖源码子模块或产物 pin。
5. 运行前端桥/布局、主进程生命周期/快捷键、preload、原生/自绘菜单的定向回归，验证 overlay 同步与 pin 归属；具备启动条件时用源客户端做真实键盘验收。

保留已有会话、应用权限、Tab 样式、客户端 overlay 与图标工作，不提交、推送、打包或发布。已有前端开发服务不停止。
