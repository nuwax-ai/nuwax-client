# 女娲Nuwax 1.0.14（beta）

休眠控制版：锁屏/最小化/托盘隐藏时自动暂停后台轮询，恢复可见立即补拉；设置页新增「休眠控制」开关。

## 变更

### 休眠控制

- 新增宿主可见性感知：窗口最小化、托盘隐藏、锁屏时，webview 内的全局事件、积分、会话快照等后台轮询自动暂停，不再空打后端；恢复可见后立即补拉一次并恢复轮询。
- 客户端设置新增「休眠控制」开关（默认开启），即点即存即时生效。
- 本特性由壳层可见性桥、前端轮询消费端、设置开关三侧组成，本版全量进包。

### 说明

- 浏览器端（非客户端环境）不受影响，轮询行为保持原样。

## 升级须知

- 含 1.0.13 全部变更（会话进度胶囊重构与未读提醒）及此前 beta 版全部变更。
- 数据目录 `~/.nuwax`、更新通道不变，存量 beta 客户端可直接在线更新。
- Windows beta 包为未签名构建（正式版手签）；SmartScreen 提示「未知发布者」选「仍要运行」。mac 双架构自动签名+公证。
