# Nuwax 3.0.16-beta.4

- 修复部分早期 Windows 10 系统内嵌终端无法启动的问题，增加 WinPTY 兼容后端，保留中文、缩放、Ctrl+C、工作目录隔离与进程清理。
- 修复 macOS 安装包缺少 `app-update.yml` 导致升级下载失败的问题，签名前生成配置，发布前核验应用、ZIP 和 DMG。
- 统一 Linux deb/rpm 后续重写升级配置的格式与通道规则，避免完整包校验误判。

本轮以 3.0.15 为基线。Windows 11 验证仅作回归；Windows 10 1511（Build 10586）兼容性仍待原反馈人安装本 Beta 复测。

已安装且缺升级文件的 macOS 旧版，请下载完整 DMG 覆盖安装本版。
