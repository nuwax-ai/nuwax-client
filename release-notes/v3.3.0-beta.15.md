# Nuwax 3.3.0-beta.15

- 服务地址填错后可以改回来。在设置里切换服务地址前，客户端会先经当前网络（含系统代理）探测新地址：
  域名解析失败或网络不通时保留现有登录状态和服务，说明原因并提供「仍然切换」，企业代理、内网地址
  确认无误后可以继续。页面加载失败时会显示错误类型和服务地址，可以直接修改或选回上一个地址，保存后
  重启并重新登录。
- 外部插件或其依赖卡住、导致 Agent 一直无响应时，可以恢复原会话。握手或旧会话加载超时后，客户端用
  新进程跳过外部插件重试，优先恢复原会话；仍失败则退出并保留原有数据。这样恢复的会话里，每条消息
  发送前都会提示「外部插件及其安全检查均已停用」，可选择「停用外部插件并继续」或「停止本次对话」；
  取消或超时都不会发送，自动放行模式下同样需要确认。
- 开发联调：`make harness-local` 默认开启待办清单（update_plan）开关，`NUWAX_UPDATE_PLAN=false
  make harness-local` 可关闭；宿主环境里的 `NUWAX_UPDATE_PLAN` 现在会传给引擎进程，此前被子进程环境
  白名单丢弃。随包引擎 0.18.68 尚不读取该开关，安装包暂无可见变化。开发模式下由权限页触发的受控重启
  会保留 Vite 和前端进程，旧进程清理完成后重新启动。
- 除上述变化外与 3.3.0-beta.14 相同。
