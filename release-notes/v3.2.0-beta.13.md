# Nuwax 3.2.0-beta.13

- ACP 适配器升级到 `1.2.48`，随包 `nuwax-harness` 引擎升级到 `0.18.58`。
- 模型请求：Chat / Anthropic 协议也按剩余输出空间收紧上限，减少超上下文导致的中断。
- provider 声明的模型现在会出现在模型列表中（修复 ACP `session/new` 报
  `nuwax-harness did not return any models`）。
- TUI：空会话切换模型不再报 `thread/read` 失败；切换到其他厂商的模型时正确 re-home
  （保留历史、provider 一并切换），不再误报「默认模型未保存」。
- 切模型前的历史预读改用分页 turns 接口，消除 full-history 弃用告警。
