# 女娲Nuwax 1.0.36

桌面会话隔离与登录态强化正式版：webview 会话策略收口（外部页面隔离、业务桥接范围收紧）、登录态跨网关/业务域镜像、Windows 升级链多项可靠性修复、Computer Use 三平台、工作空间目录管理。含 1.0.5 以来全部 beta 版本变更。

## 变更

### 桌面会话隔离与安全

- webview 会话策略统一收口：业务域动态来源判定（登录域名/本地网关/覆盖配置），权限（摄像头/麦克风/剪贴板/通知等）仅在顶层文档与实际请求帧均属业务域时放行；业务页内嵌第三方 iframe、外部页面一律隔离到独立内存会话（无桥接、无权限、无持久化）。
- 外部页面（含跳转与弹窗）进入隔离会话，不再继承宿主登录态与桥；业务域变更时相关弹窗自动关闭。
- webview 导航边界：跨域顶级跳转移入隔离窗口，可信页 302 到外部域在提交前拦截。

### 登录态与会话

- ticket 会话在本地网关与业务域之间镜像同步，本地化加速形态下登录态保持一致；cookie 登录链路稳定性与原生会话校验收紧；过期凭据自动清理并留观测日志。
- 企业登录换域、登出重登等场景的凭据生命周期修复（此前的多项 beta 验证收口）。

### Windows 升级可靠性

- 升级安装时主动关闭应用进程树（优雅关闭 10 秒宽限后强停），安装目录不再被残留子进程锁定。
- 覆盖安装失败修复；旧卸载器遇安装目录内 `nul` 等保留设备名误报「无法关闭」的问题处理；非法安装名状态自动恢复。
- NSIS 安装器资源查找 Windows 路径语义修复。

### 更新体验

- 新版本后台自动发现（启动首查 + 每小时轮询 + 唤醒补查）；更新徽标文案与进度反馈优化；「重启更新」全屏加载遮罩；打开「关于」页静默刷新检查。

### Computer Use（三平台）

- macOS / Windows / Linux 全平台支持（mac 首次授权引导、Windows 开箱即用、Linux GNOME Wayland 输入通道）；外部落盘统一收进 `~/.nuwax/computer-use`；视觉模型（VLM）配置即点即存。
- macOS 全磁盘访问检测与初始化授权引导（文件链路受 TCC 管理时的静默失败修复）。

### 工作空间与文件

- 工作空间目录选择弹窗支持新建与重命名（内置文件服务升级 1.5.2）；文件名支持前后空格。
- 商业版窗口最小分辨率 1200×720（主窗/弹窗统一）。

### 界面与交互

- 标题栏拖拽手势化重构（页面控件零吞没）；标准应用菜单（mac 六菜单 / Windows 五菜单）；设置弹窗重构（左导航+行式布局）；会话进度胶囊重构与未读提醒；文件树虚拟滚动；侧栏页签切回零请求等多项性能与体验优化。
- 深色模式可读性、i18n 插值、布局对齐等细节批次。

### 电源与休眠

- 「允许锁屏运行」电源保活三档；休眠控制（锁屏/最小化/托盘隐藏时暂停后台轮询，恢复即补拉）。

## 升级须知

- 含 1.0.5–1.0.36 全部 beta 变更。
- 数据目录 `~/.nuwax` 不变；更新通道切换为 stable。
- Windows 包为签名构建（SmartScreen 无「未知发布者」警告）；mac 双架构签名+公证。
- beta 客户端升级：设置页「检查更新」或等待自动发现（默认域将随本版回归正式域 agent.nuwax.com；已有配置不受影响）。
