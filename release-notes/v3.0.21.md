# 女娲Nuwax 3.0.21

- 修复 Windows 卸载后重新安装、全新安装时，仅解压后退出且不显示安装向导的问题：尚未创建的默认安装目录也能正确解析，保留目录安全校验，并在无效目录被拒绝时显示明确错误。
- 修复 Windows 卸载选择删除本地数据时，遇到 Git 等只读文件或目录删除失败的问题；保留路径与目录链接保护，并区分程序移除和本地数据清理失败的提示及日志。
- 修复 Computer Use 视觉模型“测试连接”的误报：给推理模型保留足够的回答额度，兼容 GLM 的答案包装；区分回答截断与图片识别失败，并显示可读提示，不再露出 `{visionVerificationFailed}` 等内部错误码。
- 本地服务自动选择可用端口，遇到占用自动避让；升级迁移旧配置，设置页无需填写端口。包含服务重启状态、启动错误分类及 Windows 跨盘构建修复。
- Windows 完整安装包增加修复/升级、先修复再卸载入口；处理备份丢失、失效恢复标记和旧卸载器缺失或失败，补齐登记全部或部分丢失、原目录被旧卸载删除后的中断重试恢复，保留现存个人数据与未知文件。清单损坏或冲突时，自动升级停止，完整包可明确选择保留现场后修复。
- 完善 Windows 安装目录及 per-user/all-users 范围隔离，保护并存副本、未知工作区和其他副本的快捷方式（包括已改指向其他副本的默认入口）；升级保留现有别名，只清理所选安装自身的程序载荷。
- Windows 安装使用 ZIP 直接解压，减少重复写盘；保留实际安装目录识别、卸载性能、快捷方式及图标修复，按安全保留策略清理过期成功备份。
- 有更新时显示“新版本就绪”，点击或悬停可查看日志；macOS 与 Windows NSIS 可从日志底部一次发起下载、校验、安装和重启。下载与安装显示行内状态，不再弹出阻挡页面的进度窗口；失败后可重试；修复分段响应可能导致中文更新日志乱码的问题。
- PC 重命名弹窗支持输入法组字回车保护，补齐历史记录页入口；记住分组与项目的展开/收起状态。
- PC 附件上传完成前禁止发送并提示状态，支持图片及附件卡片双击打开；Web 导航切换时主动刷新伙伴未读数。
- 保留服务异常不误登出、全局轮询静默、登录态发码 ticket 及女娲Nuwax 系统名称等 3.0 已有修复。

本次使用 3.0 维护线及 9.30 前端。已安装 3.1 Beta 的用户需手动安装本版；线上 PC 页面随 PC Web 部署生效。旧客户端升级到本版仍使用旧入口，macOS 一键流程从本版发起后续升级时生效；MSI 保持手动安装。

已知问题：若旧卸载已删除整个安装目录、仅残留私有登记，且未指定原安装目录，重试可能安全停止（退出码 2），现存数据与备份保留；请按原安装范围传 /currentuser 或 /allusers，并以 /D=原安装目录 参数启动完整包重试；/D 放在命令末尾，不加 /REPAIR。此类无 /D 入口尚待修复和验收。扩展原生矩阵及其他范围的自动更新端到端仍单独验收。

已知问题：若机器已有 all-users（所有用户）安装，标准用户选择 /currentuser（仅当前用户）安装仍可能误触发提权并返回 1223；此范围入口修复尚未计为通过。
