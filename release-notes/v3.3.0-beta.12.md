# Nuwax 3.3.0-beta.12

- 新增「允许 Agent 使用内置浏览器」开关（设置 → 系统），新装和升级后默认关闭。开启后，本机 Agent 可以申请
  使用内置浏览器：新建一个会话专用的窗口，在其中新建、切换、关闭页签，任务结束后关闭自己的窗口；也可以申请
  访问已打开的页签。新开页面前会确认目标网址，读取或操作网页仍需逐次授权。关闭开关会立即撤销已有授权。
  用户自己打开网页链接的方式不受影响。目前仅支持在本机运行的 Agent。
- 统信 UOS（Wayland）：截图和录屏不再先弹出系统的共享来源选择，单显示器时直接进入全屏框选；暂停、继续、
  停止和结果回传与原来相同，录制中锁屏会取消录制。多显示器，或系统接口不满足要求时，仍由系统选择来源。
- 除上述变化外与 3.3.0-beta.11 相同。
