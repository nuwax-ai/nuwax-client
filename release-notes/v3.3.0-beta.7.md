# Nuwax 3.3.0-beta.7

- 修复对话请求长时间无响应：Agent 引擎在恢复或新建会话时卡住，请求此前会一直等到后端超时。
  现在引擎启动与握手、恢复会话、新建会话、插件安装各阶段均有时限；超时后回收无响应的引擎进程，
  改用新会话继续。恢复较慢但仍在推进的会话保留原有上下文。
- 会话建立最终失败后，同一项目 5 分钟内的后续请求直接返回可读的失败提示，不再重复等待。
- Linux：原生 Wayland 桌面的合成器不提供文本输入接口时（如统信 UOS 20），客户端自动重启并改用
  XWayland 运行，恢复中文输入法。命令行或环境变量已指定显示后端、或本机没有可用的 X 服务时不介入。
- 已知问题：Agent Desktop 引擎的可执行文件为上游预编译，在 glibc 低于 2.34 的 Linux 系统上无法启动；默认的 CUA Driver 引擎不受影响。
