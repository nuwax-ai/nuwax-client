# Nuwax 3.0.23-beta.8

本版交付 beta.6 后续修复，供 macOS / Windows 实机验证。

- 改善页面初始化、WebView 加载失败及等待过久时的恢复界面，提供重新加载和设置入口；保持窗口控制可用。
- 修复服务就绪缓存与事件竞态，合并重复探测，消费失败并支持安全复查；修复刷新发起失败后按钮无法再次操作。
- 修正截图、Computer Use 等辅助窗口获得焦点时误抑制消息通知，增加脱敏的筛选和系统提交诊断。
- 统一自启动设置路径，补充 Dock 异步恢复和窗口、唤醒、解锁时的检查。
- 包含新客户端加载旧 PC Web 的可选空字段兼容，以及文件不存在的提示和按运行电脑隔离最近目录等前端修复。

PC Web 源码固定为 `874f4f6a9`。直连服务器模式仍加载服务器当前页面；新的网页恢复界面需服务器同步部署此提交。浏览器及旧客户端继续兼容，不新增宿主桥协议。

重点验收：首次重启、临时网络失败后的恢复、macOS 通知中心真实消息保留与点击唤回、Dock 隐藏/最小化/唤醒、本机与远端文件路线、新旧页面组合。自动化通过不代表这些实机问题已关闭；本版不清除登录态或重置系统权限。
