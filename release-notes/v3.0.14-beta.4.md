# Nuwax 3.0.14-beta.4

补齐 Linux 截图与录屏，并将采集来源、窗口行为和编码器差异集中到平台适配层。

## 变更

- Linux X11 支持截图、标注、区域录制；Wayland 通过系统授权选择来源，在同一授权流中预览和框选。
- 客户端截图与录屏入口统一为截图、MP4、GIF；既有 WebM API 保持兼容，IM 可继续通过结果句柄读取并回填原会话。
- Windows/Linux 应用菜单支持鼠标悬停展开和切换，Linux 提供托盘及客户端内暂停、继续、停止操作。
- Linux 录制隐藏控制窗，修复静止来源输出、首尾帧控件残留、停止清理和 X11 选区坐标问题；增加录制期间防自动息屏。
- 三端编码资源随安装包准备并校验，Linux 使用固定源码构建的 FFmpeg、libvpx 和 OpenH264；Unix 包额外核对编码器执行权限。

## 验证与限制

- Ubuntu 24.04 GNOME X11 真机及同机隔离 GNOME 46 Wayland 桌面已通过动态、静止录制、取消复用和清理回归；商业测试 2815 项、脚本测试 322 项通过。
- 旧版 Sway 的静止源和连续采集仍有已知问题；物理多屏、混合 DPI、KDE、长时间录制、真实 IM 会话回填及正式安装包安装/升级仍需验收。
- Linux 录制期间通过托盘操作，或切回客户端使用 Ctrl+Alt+R 停止、Ctrl+Alt+P 暂停/继续；这些快捷键不是系统全局快捷键。
- Windows beta 安装包未签名，仅供测试。完整证据与边界见仓库 docs/acceptance/20261013-linux-native-capture.md。
