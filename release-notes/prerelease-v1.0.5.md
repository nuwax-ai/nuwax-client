# 女娲Nuwax 1.0.5（beta）

品牌与启动体验版：安装向导与系统显示名改为中文「女娲Nuwax」（文件名/包名仍为 ASCII）；换域确认弹窗明示新旧域名；未登录不再误报「配置同步失败」；启动等待态只留图标动效。

## 变更

### 显示名改为「女娲Nuwax」（三平台）

面向用户的**显示名**与**文件名**彻底分离——显示名走中文营销名，文件名、包名、数据目录一律保持 ASCII `Nuwax` 不变。

- **Windows**：安装向导标题与正文显示「女娲Nuwax」（新增 `build/installer.nsh`，`customHeader` 宏重写 NSIS `Name`）；开始菜单/桌面快捷方式同步改名。**底部「Nuwax 1.0.5」版本行按产品要求保持不变**（刻意不重写 `BrandingText`）。
- **macOS**：访达与「关于本机」显示「女娲Nuwax」（`CFBundleDisplayName`）；`CFBundleName` 保持 ASCII 以兼容访达排序。
- **Linux**：应用菜单显示「女娲Nuwax」（`desktop.entry.Name`）；deb/rpm 包名仍为 `nuwax`。

### 换域确认弹窗明示新旧域名

设置页修改服务域名时，确认弹窗此前只说「保存后需要重启服务」，不显示改成了什么。现改为结构化对照展示「当前 ↓ 新值」，并明确提示**修改后将退出登录并重启本地服务**。四语言同步。

### 未登录不再误报「配置同步失败」

全新安装尚未登录时，界面会弹出红色错误「配置同步失败 / Error: Login required」，让新用户误以为客户端故障。实际上这是**正常的登录前门禁态**——注册请求根本没有发出。现降级为蓝色信息提示并引导登录，登录后自动消失。真实的同步失败仍保持原有错误提示与重试按钮。

### 启动等待态只留图标动效

去掉「正在启动本地服务…」文案，加载语义由图标自身的呼吸动效表达，启动瞬间只见品牌图标。启动失败态的标题、未就绪明细与重试按钮全部保留。

## 升级须知

- **数据目录、工作空间、自动更新不受本次改名影响**：userData（`APPDATA\Nuwax` / `Application Support/Nuwax`）、数据目录 `~/.nuwax`、默认工作空间 `~/Nuwax`、卸载程序 `Uninstall Nuwax.exe` 全部保持原样，存量机升级**原地复用**旧目录，登录态不丢，不会产生「女娲Nuwax」新目录。
- 产物文件名不变（`Nuwax.Setup.1.0.5.exe` / `Nuwax-1.0.5-arm64.dmg` / deb 包名 `nuwax`），更新通道与 v1.0.4 一致。
- **全新机器首登注册**：2026-09-15 实测后端已放行「已登录会话」注册——全新设备仅凭登录态即可完成注册（mac mini 全新安装实证：登录到服务就绪 7 秒闭环）。若仍提示「动态认证码或密码不能为空」，为后端会话校验未就绪，存量升级用户不受影响。
- Windows 包已代码签名；SmartScreen 信誉积累需要时间，首次运行仍可能提示「未知发布者」，选择「仍要运行」即可。mac 双架构自动签名+公证。
- 数据目录 `~/.nuwax` 与旧应用互不迁移，旧品牌 beta 客户端请手动下载安装。
