# Nuwax 3.0.16-beta.3

- 修复部分早期 Windows 10 系统内嵌终端无法启动的问题，增加 WinPTY 兼容后端，保留中文输入输出、缩放、Ctrl+C、工作目录隔离及进程清理。
- 修复 macOS 安装包缺少 `app-update.yml`、导致发现新版本后下载失败的问题；所有商业打包入口在签名前生成配置，发布前核验实际应用、ZIP 和 DMG。

本轮以 3.0.15 为基线。Windows 11 回归已通过；Windows 10 1511（Build 10586）的兼容性待原反馈用户安装此 Beta 复测确认。

已安装且缺升级文件的 macOS 旧版，请下载完整 DMG 覆盖安装本版。
