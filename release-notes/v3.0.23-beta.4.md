# 女娲Nuwax 3.0.23-beta.4

- 修复 Computer Use 开启偏好在设置保存、升级恢复或助手启动失败后被关闭的问题。
- 商业更新源统一下载完整安装包，修复 macOS 更新依赖差分下载时的失败。
- 修正 Windows 驱动状态判断，以及 Agent 同时传入窗口身份、新版原生工具 token 参数时的兼容问题。
- Computer Use 浮层操作改为图标，鼠标悬停或键盘聚焦时显示完整提示；保留独立的暂停、停止和关闭开关语义。
- 本地化界面增加本机会话文件的新建、编辑保存、重命名及回收站删除；预览、系统打开和文件管理沿客户端本机桥处理。直连模式的页面功能取决于线上前端部署版本。
- 增加 macOS、Windows、Linux 的 CU 与本机文件代码回归门禁。

## 验收说明

- Mac 同源码验证包已实测完整更新、Computer Use ON→ON 保留及安装资源核对。正式 Beta 的来源与产物哈希另由发布流程核验。
- Windows EXE 的剩余实机升级与真实任务回归由用户补验；文件 UI、控制动作和长时间稳定性仍需实机验收。
- Windows ARM 环境中 Nuwaxcode 1.3.13 存在此前已记录的初始化崩溃；本轮未修改该第三方引擎，可使用 Claude Code 路径继续 CU 验收。
