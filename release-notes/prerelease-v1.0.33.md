# 女娲Nuwax 1.0.33（beta）

桌面会话隔离与系统权限体验强化版：收紧业务桥接范围，隔离外部页面，并改进 Computer Use 与权限检查。

## 变更

### 会话与访问安全

- 业务桥、更新能力和登录凭据限制在受信的业务会话中；外站、重定向和新窗口使用隔离会话。
- 企业域切换时收敛旧域窗口与权限，减少跨域会话残留。
- 已知业务链接继续在客户端内打开；外部网站、部署内容、API 和文件保持隔离。

### Computer Use 与权限

- Computer Use 启用前增加明确确认，并检查 macOS 辅助功能、屏幕录制和捕获状态。
- 改进 helper 安装回滚、能力端点校验与启停收敛；未完成系统授权时保持关闭。
- 全磁盘访问探测区分已授权、明确拒绝和未知状态，未知状态不再触发主动引导。

### 发布可靠性

- Beta 与 stable 构建锁定客户端、基座和前端来源，并校验平台安装包与更新元数据。
- 上传后回读核对对象字节，再更新 beta 通道指针。

## 升级须知

- 这是预发布版本，建议在测试设备上体验。
- macOS 安装包需通过签名、公证及 Gatekeeper 校验；Windows Beta 安装包完成签名后才会进入 beta 更新通道。
- 存量 beta 客户端可通过「关于」页检查更新。
