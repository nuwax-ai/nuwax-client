# Nuwax 3.1.1-beta.25

基于 release/v3.1.0 已合并的 PR #119，补齐 Agent Desktop 随包声明并修复正式发布的完整声明链。

- “开源信息”包含 Agent Desktop 1.2.0 的许可全文、各平台 Rust 依赖与标准库归属，可展开查看 Windows 修改说明。
- 正式包在签名前生成完整声明，包装后校验清单、许可证与源码归档；既有 capture 源码归档只携带一份。
- 固定第三方下载包缓存不再受无关 Agent Desktop、Harness 或传输脚本改动影响，减少未变化依赖的重复下载。
- 保留现有 Computer Use 执行引擎选择和默认项，以及 Beta.24 的浏览器、引擎、截图和文件面板修复；同时包含 PR #118 的截图标注工具保持修复。

前端源码与产物 pin 均沿用发布基线。终端持久化、跨会话终端保活、多终端及运行实例管理继续排除。Windows Beta 安装包未签名；本轮等待安装包与真机验收后再推进正式版。
