# Nuwax 3.2.0-beta.10

本轮把引擎升到 nuwax-harness 0.18.54、适配器升到 1.2.46，并统一了本地引擎数据目录的命名。

- 引擎数据目录由 `.codex` 统一为 `.nuwax-harness`（含项目工作区与引擎自身 home）。升级后首次打开旧项目会自动完成迁移，**历史会话照常可以继续对话**。
- 迁移只做同盘改名、不删除数据：旧目录整体保留为 `.codex.migrated-<时间戳>`（保留 30 天，可手工回滚），并在旧路径留下指向新目录的链接，兼容引擎里已记录的旧绝对路径。Windows 使用 junction，不需要管理员权限；若环境不支持建立链接，会自动回退到旧目录名，保证会话可用。
- 引擎侧的模型请求现在会带上本机客户端标识（User-Agent / originator）。此前请求不带标识，按客户端身份准入的模型网关会直接拒绝。
- 鉴权类错误（401/403 等）不再重试：此前一次凭据失效会连续重试多次、并附带重复的"压缩会话"提示，现在只报一次错误；服务端 5xx 与限流仍按退避重试。
- 模型上下文窗口取自平台下发或本地配置时，不再误报"未设置上下文窗口"的告警。

本地开发调试：`make dev` / `make harness-local` 默认开启模型请求抓包（日志在 `logs/model-capture.log`，每次启动清空，凭据自动打码），并默认拉取源码类资源的最新版本。

引擎与适配器版本：nuwax-harness 0.18.54、nuwax-harness-acp-ts 1.2.46。

验证：引擎协议 384 项、rig wire 132 项、model catalog 83 项测试通过；适配器 2600 项测试通过；客户端引擎目录相关 455 项单测通过（含迁移、合并、回滚、跨平台链接策略）。旧会话恢复、新旧目录并存、迁移失败回退三种场景均已在实机验证。

Windows Beta 按既有流程发布无签名原包；签名场景使用独立本地签名副本验证。
