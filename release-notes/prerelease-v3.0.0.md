# 女娲Nuwax 3.0.0（beta）

新版本序列首版（v3.0.0 起）：消息/资料库微前端（qiankun）接入与微应用升级版——消息、资料库正式迁移 qiankun 微前端架构并支持应用内升级、终端连接保活、推荐语多提示词维护、输入区底栏布局优化。同时并入 1.0.45 以来全部修复（Windows 图标圆角、文件服务 1.5.4、源码管理搜索、首页布局等）。

## 变更

### 版本序列

- 版本序列升级为 v3.0.0 起点（beta 与 stable 同步起跳），老版本（1.0.x）可正常收到本版更新。

### 微前端架构（qiankun）

- 消息、资料库微应用接入 qiankun 微前端框架，与主应用边界收敛（嵌入式形态定稿）。
- 微应用支持单个与全部升级，升级流程增加 prebuild 步骤。

### 终端

- 新增终端连接保持功能，应用就绪检测优化。

### 推荐与开场白

- 预置问题升级为预置提示词，支持重复推荐与多提示词维护。
- 开场白预置问题样式优化，提交异常处理。
- 首页智能体详情按推荐标签 recId 区分拉取。

### 界面与体验

- 聊天输入区底栏悬浮于输入卡下方，出现/收起不再撑高布局跳动。
- 消除首屏连续加载提示。
- 多语言更新：新增 CNAME 提示信息，域名输入提示优化。

### 平台修复（并入自 1.0.45）

- Windows 任务栏/桌面图标圆角化（新品牌视觉）。
- nuwax-file-server 升级 1.5.4。
- 源码管理按文件名搜索变更文件、提交后预览刷新、「产物面板」文案。
- 首页常规项目统一开放沙箱自选。

## 升级须知

- 从 1.0.x 任意 beta/stable 均可平滑升级到本版。
- 本地化加速用户升级后首次启动会重新拉取微应用资源，属预期行为。
- Windows 用户升级后若任务栏图标仍显示旧样式，请将旧固定项取消固定后重新固定（刷新系统图标缓存）。
