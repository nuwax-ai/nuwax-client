# 女娲Nuwax 3.1.0 Beta.6

- 调整 Computer Use 浮动工具栏：右侧按钮改为「停止当前操作」，停止本次任务后保留功能开启状态，供后续任务继续使用（2692）。
- macOS 截图、录屏快捷键改为请求系统独占注册，保留原默认键及自定义组合；与飞书同时使用时的触发效果请通过本 Beta 实机验收（2694）。
- 截图文字标注支持 Enter 换行，使用 Command/Ctrl + Enter 完成编辑（2695）。
- 截图工具栏在取消按钮左侧增加保存图片入口，通过系统保存面板导出 PNG；取消保存或保存失败后可继续编辑（2696）。

本版本基于 release/v3.1.0，包含基座代码内置化调整，供上述问题安装验收。请重点确认「停止当前操作」后新任务可继续执行、飞书与客户端快捷键共存、多行标注及保存图片的实际效果。
