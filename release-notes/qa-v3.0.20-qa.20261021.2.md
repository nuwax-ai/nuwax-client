# Nuwax 3.0.20-qa.20261021.2 安装恢复验收包

本候选用于 Windows 安装、升级及卸载异常的签名完整包验收。仅输出 Actions artifacts，不创建发布 tag、Release 或更新指针；Windows CI 输出未签名文件，签名及真机验收另行记录。

- 完整包提供修复/升级和先修复再卸载，处理旧卸载器缺失、启动失败或返回非零。
- 有效恢复事务优先恢复或回滚；备份丢失时归档对应失效指针并重新保全。损坏清单和冲突需在完整包明确选择保护旧备份后修复。
- 默认保留个人数据和未知文件，失败保留登记、卸载入口及恢复材料。
- 保持所选安装路径及用户范围；两种范围并存时仅维护所选副本，保护其他副本及其快捷方式。

合成载荷夹具及界面默认值已验证，详见 `docs/acceptance/20261021-windows-installer-recovery-source-verification.json`。完整商业载荷、签名、真实历史包、自动更新及 UAC 结果须单独验收。候选 .1 未产出完整安装包，后续候选使用新编号保留其记录。
