# Nuwax 3.1.1-beta.7

- 修复开启 Dev 后，同一版本系列的 Alpha 因版本号低于 Beta 而无法作为切换候选的问题。
- 主动切换更新通道时，可选择同一基础版本的较低版本；安装前展示当前版本和目标版本并确认，较低版本不会在退出时自动安装。
- 保留普通检查禁止降级、跨基础版本禁止降级，以及下载和安装期间禁止更换通道的限制。
- 取消切换安装后保留已下载状态，修复设置页和内置页面把取消显示为更新失败的问题。
- 包含发布线已合入的日志 ZIP 导出，便于提交故障诊断信息。

当前使用 Beta.6 且已开启 Dev 的用户，请先关闭 Dev、保持 Beta 开启，检查更新并升级本版，再重新开启 Dev，即可收到同系列 Alpha 切换候选。Alpha 体验版用户继续留在独立 Dev 通道，不会被本次 Beta 发布覆盖。
