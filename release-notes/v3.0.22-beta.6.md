# 女娲Nuwax 3.0.22-beta.6

- 重构电脑操作浮窗：采用更紧凑的圆角卡片，默认位于客户端右上角，突出当前操作对象、运行状态、接管和停止；暂停、继续、拖动及关闭入口保持可用。
- 拖动和缩小客户端窗口时按浮窗实际尺寸限制位置，统一单任务与后台多窗口预览的亮暗主题和操作样式。任务历史继续从托盘「电脑操作」进入，关闭浮窗仅隐藏预览。
- 包含 Beta.5 的 Computer Use 设置布局和打包流程优化。Computer Use 默认关闭，任务沿用当前会话的 Agent 和模型，无需额外配置绘画模型。

本版用于 mac-dbg 与 win-dbg 正式安装包升级和真实任务验收；源码组件预览不代表安装包验收通过。首次授权、多窗口切换排序、锁屏恢复、长时运行及全版本回归继续按验收清单记录。

已知旧版及此前 Beta 的 macOS 更新退出仍有卡住风险，本版未纳入更新加强方案；如长时间停留在安装中，请正常退出客户端后使用官方 DMG 安装。Windows 首轮任务工具误选、旧安装目录缺失时的维护入口继续列入验收。已安装 3.1 Beta 的用户需手动安装本版；MSI 保持手动安装。
