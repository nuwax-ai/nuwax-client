# Nuwax 3.3.0-beta.18

- 随包 Agent 引擎升级到 0.18.71，适配器升级到 1.2.59。
- **引擎日志真正落到客户端日志目录**。此前只有适配器日志（`logs/nuwax-harness-acp-ts/`）在客户端日志目录下，引擎自己的日志仍写在各项目隔离的 `CODEX_HOME` 里；现在适配器会把日志目录传给引擎，引擎日志统一落在 `logs/nuwax-harness/`（`logs_2.sqlite`），排查本机 Agent 问题不用再逐个项目目录翻。
- 宿主机把 `NUWAX_HARNESS_LOG_DIR` 设成相对路径时会被忽略并回退默认值，不再让 Agent 起不来。
- 随包适配器版本不支持该日志目录传递时，会明确提示一次（带实际版本与所需版本），不再出现“配了但没生效”却无人知晓的情况。
- 服务端/容器部署可用 `/etc/nuwax-harness/config.toml` 作为系统级配置，优先级高于 `/etc/codex/config.toml`，旧路径继续兼容；系统技能目录不随该选择改变，已有 `/etc/codex/skills` 不受影响。

> 0.18.70 因 Windows 构建的跨平台编译问题未发布，本版直接跳到 0.18.71（已修复）。
