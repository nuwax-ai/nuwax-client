# 女娲Nuwax 1.0.15（beta）

提测问题修复版：登录态同步（改域后登录/退出重登）、本地加速切换生效、外链菜单整页刷新、Windows 托盘图标、登录页收起按钮五项收口。

## 变更

### 登录态同步（提测 #1 / #4）

- 修复切换后端域名后登录、以及开启本地加速后退出再登录时，壳子不同步登录状态的问题：换域/登出会重置会话代次并重载页面，重载后的新登录会话此前被壳当作过期会话静默拒绝，现改为重新登记，登录状态可正常进入壳并拉起服务。
- 全新安装默认域名改为测试环境 `testagent.xspaceagi.com`（此前因种子时序缺陷实际回落 `agent.nuwax.com`，需手动改域）。已显式配置过的域名不受影响；存量测试装机升级后同样补齐默认域。

### 本地加速（本地化加载，提测 #1）

- 修复设置页切换「本地加速」开启/关闭后页面不重新加载的问题：此前刷新链路被登录门禁拦截，未登录时切换完全无效。现切换即时刷新回环网关并自动重载页面（登录前后均生效），失败会明确提示且开关状态回退。

### 客户端内导航（提测 #2）

- 修复点击左侧导航「消息」「资源库」「生态市场」等外链型菜单时整个页面刷新一下的问题：改为站内路由直接跳转（与网页端行为一致），不再整页重载。浏览器端不受影响。

### 托盘（提测 #3）

- Windows/Linux 系统托盘图标更新为黑色品牌标识（与任务栏/应用图标一致）。
- macOS 菜单栏托盘同步更换为新品牌字形的单色剪影（保留系统 template 单色语义，随深浅模式自动着色；此前一直是旧版字形）。

### 登录页（提测 #5）

- 登录页/验证码登录页不再显示顶栏「展开/收起」按钮（此前登出后残留显示）。

## 升级须知

- 含 1.0.14 全部变更（休眠控制）及此前 beta 版全部变更。
- 数据目录 `~/.nuwax`、更新通道不变，存量 beta 客户端可直接在线更新。
- Windows beta 包为未签名构建（正式版手签）；SmartScreen 提示「未知发布者」选「仍要运行」。mac 双架构自动签名+公证。
- 已知外部依赖：切换到新域名后的首次设备注册依赖后端放行登录会话；若后端仍未放行，登录状态可正常同步，但会保留「配置同步失败」提示（后端对齐项跟进中）。
