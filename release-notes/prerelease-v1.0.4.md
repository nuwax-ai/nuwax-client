# 女娲Nuwax 1.0.4（Prerelease）

web 工作空间选择打通版：nuwax web 端选定的本机目录可直接作为 Agent 工作目录；登录同步链三断点根治；客户端设置入口迁移至 web 用户区。

## 变更

### Agent 工作目录支持绝对路径（web 工作空间选择）

- nuwax web 目录选择弹窗（我的电脑 → 工作目录 → 打开电脑文件夹）选定的**本机绝对路径**现可直接作为 Agent 工作目录；此前仅支持项目标识符，带目录创建会话在客户端侧必失败。
- 客户端双轨校验：标识符（存量项目）完全兼容；绝对路径要求目录**已存在、是目录、可写**（不存在不代建，分类报错：目录不存在 / 不是目录 / 不可写），并自动归一化（软链接、路径别形统一为唯一形态，保证会话稳定复用）。
- 修复两个存量校验缺口：project_id 兜底值绕过格式校验、IPC 入口无校验。

### 登录同步链加固

- 开发形态 token 准入与 webview 地址解析同源（NUWAX_DEV_HOST 统一），登录态进壳不再依赖手工配置。
- 注册凭据（savedKey/username）只在**换账号 / 换域名**时清除：token 过期重登、登出后重登、设备升级均保留——修复存量升级用户「清掉后永远无法重新注册」的死局。
- 准入拒绝留日志（此前静默拒绝零日志，断链难排障）。

### 设置入口与界面

- 客户端设置入口迁至 nuwax web 用户区（侧栏底部「客户端设置」，仅客户端内显示）；壳顶行设置按钮在商业宿主下移除，社区版不变。
- 设置页行式重构：分组行列表、即点即存；商业黑标图标四件套。

### 其他

- 下载/另存按真实落盘结果反馈（不再触发即报成功），Electron 重定向正确处理（v1.0.4 QA 线修复）。
- 前端整批更新随包带入：会话详情拖拽调宽与详情弹窗、单栏滚动与桌面纯色背景修复、模型选择三 tab、私有服务器部署、全栈应用详情页、快捷导航缩小左移等。

## 升级须知

- beta：Windows 包未签名，SmartScreen 可能告警；mac 双架构自动签名+公证。
- **全新机器首登注册仍待后端放开**（免密/免 key 注册）：新设备首次登录可能提示「配置同步失败」，重试或等后端就绪后自动恢复，不影响登录本身；存量升级用户不受影响。
- web 选目录端到端依赖后端透传链（workspacePath → 会话请求）：后端就绪前，web 端带目录创建会话仍会失败在后端侧；客户端侧已就绪并通过直连验证。
- 同一项目后端须稳定下发同一路径（客户端已做归一化，但调用方频繁改路径会导致会话重新初始化）。
- 数据目录 `~/.nuwax` 与旧应用互不迁移。
