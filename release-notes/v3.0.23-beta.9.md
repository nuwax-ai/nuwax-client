# Nuwax 3.0.23-beta.9

本版整合 beta.8 后续修复，供 macOS / Windows 实机验证。

- PDF 预览等待面板获得有效尺寸后初始化，通过已有鉴权读取文件；切换文件、关闭面板和手动重试时正确取消旧请求，保留非本机 PDF 原有容量口径。
- 识别内置页面与线上构建的差异：相同版本号但不同构建不推断先后；仅对实际加载的内置页面显示可关闭的设置提示，离线、超时及旧桥不阻塞启动。
- 修复快照握手页面卸载后的 IPC 监听清理，避免反复进入页面后积累监听器。
- 客户端正在安装更新时，隐藏重复的网页更新入口。
- 合入聊天历史滚动锚定、剪贴板文字优先、工作台历史初始化、数学公式百分号及浏览器导出文件名修复；改善应用预览服务重启和取消部署时的状态展示。

构建侧优化 helper 缓存键，排除运行工具根目录的下载缓存，并为空间充足的 Windows CI 隔离并行封装 MSI/EXE；空间不足时安全回退。实际包体与耗时以本次 Actions 结果为准，首次新缓存仍可能需要编译。

PC Web 源码固定为 `1cc086aa5d26320c5559ea4b9cfd2dcf04d80f39`；壳基座保持 `d12d001a0d51e28513cba2b60e76413275cad161`。Beta 从固定源码构建，现有产物仓 pin 保留。repo-web 源码和其嵌套 pin 不变，NW-274 不属于本版交付。直连模式仍加载服务器当前页面，内置快照中的修复需启用本地化加速后验收。

实机验证由用户执行。重点包括首次重启与 WebView 失败恢复、PDF 首次预览/切换/重试、新旧客户端与页面组合、本机/远端文件路线、文件不存在、macOS 通知中心保留与点击唤回、Dock 间歇消失、升级过程的更新入口。自动化通过和安装包生成不代表这些现场问题全部关闭。
