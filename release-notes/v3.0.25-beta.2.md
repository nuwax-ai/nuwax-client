# 女娲Nuwax 3.0.25 Beta.2

- 补齐当前电脑文件树面板的本机文件访问流程，覆盖预览、编辑保存、新建、删除、重命名、移动、文件及文件夹上传、ZIP 导入和工作区导出。
- 新增文件和文件夹「移动到」入口，移动后同步更新预览和已打开的页签。
- 修复首次读取失败后重试、新会话服务暂未就绪时的本机来源判定，避免已确认的本机文件静默改走云端。
- 修复本机中文 HTML 及旧格式 CSS、JS、Markdown 图片引用的预览兼容问题。
- 优化默认高画质 GIF 生成速度，保留原有输出尺寸、帧率和色数；最高画质档沿用原算法。
- 修复 Linux 上传及 ZIP 条目判重误拒绝大小写不同文件名的问题。

Mac 开发客户端和 Windows 实机已完成主要文件操作验证；Windows GIF 同素材三轮基准平均耗时降低约 38%。Windows 原生目录选择器、ZIP 导入完整 UI 流及 Linux 实机仍需在本 Beta 验证。

本版本包含 Beta.1 的冷启动截图图标、全局快捷键、选框缩放及断网预览修复。验收包内前端请启用设置中的「本地化加速」并重启；直连线上页面的版本以站点部署为准。
