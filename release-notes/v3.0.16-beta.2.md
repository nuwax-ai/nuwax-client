# Nuwax 3.0.16-beta.2

- 修复部分早期 Windows 10 系统内嵌终端无法启动的问题，增加无需系统 ConPTY 的兼容后端。
- 保留终端中文输入输出、窗口缩放、Ctrl+C、会话工作目录隔离及关闭后的进程清理。
- 较新 Windows 和其他平台继续使用原终端后端。

本轮以 3.0.15 为基线。Windows 11 回归已通过；Windows 10 1511（Build 10586）的兼容性待原反馈用户安装此 Beta 复测确认。

beta.1 在 Windows 资源校验阶段因 Git 换行转换中止，未产出复测包；beta.2 固定许可证 LF 检出规则并加入模拟测试，保留原标签和源码。
