# 女娲Nuwax 3.0.3

新版本序列首个正式版（v3.0.0 起，3.0.3 为首个实际发布号）：消息/资料库迁移 qiankun 微前端并支持应用内升级、商业版 IM 未读徽标与原生通知、收银台与下载体验修复、终端连接保活、Windows 图标圆角化。

## 变更

### 版本序列

- 版本序列升级为 v3.0.0 起点（beta 与 stable 同步起跳），1.0.x 任意版本均可平滑升级。

### 消息（IM）

- message 微应用升级：@我消息基线实时抬升与滚动优化、边缘 tooltip 溢出修复（757bcf0→65779cc）。
- repo-web 微应用升级（188224f→ff0e6e6）。
- 乾坤子应用滚动条统一为「滚动时才出现」（宿主锚点通配 mixin + capture 委托）。

- 商业版原生未读徽标与系统通知：会话未读状态实时呈现，新消息到达即时提醒。
- message 微应用适配层重制（vite rename 段回归），构建链稳定性修复。

### 微前端架构（qiankun）

- 消息、资料库微应用接入 qiankun，与主应用边界收敛；支持单个与全部微应用应用内升级。

### 收银台与下载

- 收银台挂起窗口关闭确认与前端产物 pin 对齐；真实收银关闭验收记录归档。
- 修复 Electron 下载弹窗偶发空白。

### 终端

- 终端连接保持，应用就绪检测优化。

### 桌面与平台

- 电脑选择列表生命周期状态桥（实时刷新）。
- Windows 任务栏/桌面图标圆角化（新品牌视觉，11 层 DPI 全档）。
- 聊天输入区底栏悬浮布局；首屏连续加载提示消除。
- 源码管理变更文件搜索与「产物面板」；首页沙箱自选与推荐多提示词维护。
- nuwax-file-server 升级 1.5.5。

## 升级须知

- 从 1.0.x（beta 或 stable）升级均为常规增量更新。
- 本地化加速用户升级后首次启动会重新拉取微应用资源，属预期行为。
- Windows 用户升级后若任务栏图标仍显示旧样式，请将旧固定项取消固定后重新固定（刷新系统图标缓存）。
