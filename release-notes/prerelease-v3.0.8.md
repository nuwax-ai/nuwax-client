# 女娲 Nuwax 3.0.8（beta）

本版改善客户端内网页访问、站内链接登录和微应用构建稳定性。

- 任意 HTTP/HTTPS 网站可在原窗口、新窗口和 iframe 加载；跨域跳转、重定向保留在原网页窗口。
- 业务页、启用的本地网关与配置镜像共享登录；站内新窗口不受页面中无关第三方 iframe 影响。
- 第三方网站保留自己的浏览器 Cookie。业务 ticket 与宿主能力继续按实际来源隔离；网关同主机其他端口或 Cookie 来源读取失败时会保守过滤 ticket。
- 原生打开的网页窗口在加载失败、下载结束或来源窗口关闭后正确清理。
- 修复关闭网页窗口时活动状态监听可能访问已销毁对象的问题。
- 前端生产构建使用固定微应用源码，避免构建时自动更新导致适配补丁失配；修复消息卸载后的异步续跑与资料库门户宽高计算。
