# 女娲Nuwax 3.0.18

基于 3.0.16 稳定版的登录与 Windows 安装维护修复。

- 应用和系统显示名称统一为「女娲Nuwax」，包含 macOS Finder、Dock、菜单及 Windows 卸载列表。
- 更新入口可先查看版本日志，再明确发起升级；下载、安装及失败重试提供进度和状态反馈。
- Windows NSIS 安装版支持由客户端一次发起下载、安装并自动重启；需要系统提权时仍会出现 Windows 授权提示。该能力适用于 3.0.18 发起的后续升级，旧版本升级到本版仍沿用旧版本操作步骤。
- 修复登录校验遇到服务异常、网络中断或异常响应时误跳登录页的问题，保留会话并支持恢复后重试。
- 内嵌前端的全局积分与通知轮询失败时静默等待下次刷新，不弹提示、不主动跳登录。
- 修复 Windows 升级中断恢复、安装路径识别与快捷方式图标指向；卸载默认保留本地数据和个人文件，失败时保留重试入口。
- 后台清理有完整所有权证据的过期升级备份，保留最近一次和七天内备份；无法确认安全的旧备份继续保留。
