# 女娲Nuwax 1.0.25（beta）

退出完整性与窗口基线版：macOS 全磁盘访问检测与授权引导、退出清理补杀 Computer Use 进程、商业版窗口最小分辨率 1200×720；前端禅道 bug 群修复批次。

## 变更

### macOS 全磁盘访问检测与授权引导

- 文件链路（「我的电脑」文件浏览、引擎读写工作空间）是裸文件 IO、不经系统文件选择器，被 macOS TCC 拦截时会静默失败且无授权入口；本版新增全磁盘访问（FDA）检测与初始化授权引导，受保护目录（桌面/文稿/下载/资源库等）一次授权全覆盖。
- 「暂不」选择会记住，不再重复弹引导。

### 退出完整性

- 修复正常退出时 Computer Use 后台进程残留：退出链显式补杀，卸载/升级前等待清理完成（上限 10 秒）。
- 引擎空闲驱逐默认 30 分钟（可用环境变量调整）；Windows 管道清理通配匹配修复。

### 窗口基线

- 商业版窗口最小分辨率调整为 1200×720：主窗口、webview 弹窗、会话独立窗统一生效，避免过小窗口下界面挤压。

### 界面与交互（前端）

- 会话调试面板新增「环境信息」：版本/页面地址/登录状态/环境四分区，支持一键复制全部（排障提效）。
- 个人资料弹窗按视口收敛尺寸（适配最小窗口 1200×720），内容区可滚动。
- 会话修复批次：进页自动发送首条消息即时可见、执行期重复渲染收敛、首页入口发送参数归一修 400、空会话可选电脑、思考行耗时 0 秒兜底、首页输入框刷新跳动收敛、系统管理侧滑遮罩不再挡工具栏等（禅道 bug 群修复）。
- 预览页窗口缩放不再触发自动重启。

## 升级须知

- 含 1.0.24 全部变更（Codex 引擎修复系列）及此前 beta 版全部变更。
- 数据目录 `~/.nuwax`、更新通道不变，存量 beta 客户端可直接在线更新。
- Windows beta 包为未签名构建（正式版手签）；SmartScreen 提示「未知发布者」选「仍要运行」。mac 双架构自动签名+公证。
