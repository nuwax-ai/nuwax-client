# Nuwax 3.0.16-beta.5

前端跟进版：提测部署脚本自动升级子模块、多应用类型删除确认文案、常规项目翻译精简、useInitProjectMetadata 支持 PUSH 以外导航、原生捕获 IM 集成快速上手文档。

## 变更

### 前端

- 提测部署前自动升级子模块（deploy auto-upgrade）。
- 删除确认提示语支持多种应用类型；移除常规项目相关冗余翻译条目。
- useInitProjectMetadata 优化，支持非 PUSH 导航。

### 文档

- 原生捕获 IM 集成一页快速上手。

## 升级须知

- beta 通道；从 3.0.16-beta.4 平滑升级。
- Windows beta 包未签名，仅供测试。
