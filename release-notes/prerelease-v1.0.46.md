# 女娲Nuwax 1.0.46（beta）

消息/资料库微前端（qiankun）接入与微应用升级版：消息、资料库正式迁移 qiankun 微前端架构并支持应用内升级、终端连接保活、推荐语多提示词维护、输入区底栏布局优化。

## 变更

### 微前端架构（qiankun）

- 消息、资料库微应用接入 qiankun 微前端框架，与主应用边界收敛（嵌入式形态定稿）。
- 微应用支持单个与全部升级，升级流程增加 prebuild 步骤。

### 终端

- 新增终端连接保持功能，应用就绪检测优化。

### 推荐与开场白

- 预置问题升级为预置提示词，支持重复推荐与多提示词维护。
- 开场白预置问题样式优化，提交异常处理。
- 首页智能体详情按推荐标签 recId 区分拉取。

### 界面与体验

- 聊天输入区底栏悬浮于输入卡下方，出现/收起不再撑高布局跳动。
- 消除首屏连续加载提示。
- 多语言更新：新增 CNAME 提示信息，域名输入提示优化。

## 升级须知

- beta 通道版本，从 1.0.46 恢复独立编号（stable 已转正 1.0.45，交替策略继续）。
- 本地化加速用户升级后首次启动会重新拉取微应用资源，属预期行为。
