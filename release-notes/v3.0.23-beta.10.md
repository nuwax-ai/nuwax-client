# Nuwax 3.0.23-beta.10

本版整合 Windows 截图与 GIF 录制优化（禅道 2687），供 Windows / macOS 实机验证。

- Windows 截图/录屏快捷键注册为全局热键：客户端失焦或隐藏到托盘时仍可全局触发截图，快捷键设置冲突时安全回滚原绑定，退出/关闭时释放；后台快捷键捕获前不提前置顶主窗口，截图成功后再行唤出。macOS 与 Linux 保持原有前台/系统策略。
- 截屏选区支持右键全局取消：多显示器环境下任意位置右键直接取消整次捕获并关闭全部屏幕选区窗口，不产生误选区或残留标注；录制控制条右键不影响正在进行的录制。
- GIF 录制与编码性能优化：GIF 采集帧率按最终输出档位上限对齐（默认高档调整为 15 fps；MP4/WEBM 保持原有高帧率）。编码阶段使用两个独立读取通道分别生成调色板与应用调色板，显著降低整段解码帧排队峰值内存（实测下降约 54%～65%），保持尺寸、色数、抖动与循环契约完全一致。

PC Web 源码固定为 `1cc086aa5d26320c5559ea4b9cfd2dcf04d80f39`；壳基座保持 `d12d001a0d51e28513cba2b60e76413275cad161`。Beta 从固定源码构建，现有产物仓 pin 保留。

实机验证由用户执行。重点包括：Windows 物理多屏环境下的全局快捷键触发、失焦/最小化/托盘唤起、选区右键取消、录屏与 GIF 编码耗时表现。
