# 女娲Nuwax 1.0.28（beta）

文件服务升级版：内置 nuwax-file-server 升级至 1.5.2，补齐工作空间目录管理所需的服务端能力。

## 变更

### 内置文件服务升级（1.5.0 → 1.5.2）

- 文件选择框支持新建目录与重命名：补齐 1.0.27 前端「工作空间目录选择弹窗新建/重命名」所需的服务端能力，功能至此全链路可用。
- 文件名支持前后空格。

## 升级须知

- 含 1.0.27 全部变更（更新链路三修与启动体验统一版）及此前 beta 版全部变更。
- 数据目录 `~/.nuwax`、更新通道不变，存量 beta 客户端可直接在线更新。
- Windows beta 包为未签名构建（正式版手签）；SmartScreen 提示「未知发布者」选「仍要运行」。mac 双架构自动签名+公证。
