# Nuwax 3.0.14-beta.3

原生捕获完善版：应用菜单四采集动作接线（宏菜单集成）、macOS x64 改用 Intel 原生 runner、capture 商业资源准备链、Windows 安装验收归档。

## 变更

### 原生捕获（capture）

- 应用菜单集成四采集动作（截图/mp4/webm/gif），与截图按钮共用 CaptureLauncher 并发锁。
- macOS x64 构建改用 macos-15-intel 原生 runner；capture 资源准备链独立（ffmpeg 工具链+Winpthreads 分裂安装）。
- capture 菜单重构（移除废弃 handler 通路）与测试适配。
- Windows 真机安装验收记录归档（20261013）。

## 升级须知

- beta 通道；从 beta.2 或 3.0.13 stable 平滑升级。
- Windows beta 包未签名，仅供测试。
