# Nuwax 3.0.11-beta.6

- 纳入 codex/frontend-beta5-pins 的前端双 pin：源码 4dfea90cd2、产物 4a497a055；微应用 pin 与 adapter 声明一致。
- 包含桌面 IdP 登录/绑定回调、验证码、License 界面、IM 与会话轨迹更新；生产 License provider 尚未接通。
- 包含发布线的 OAuth 会话与弹窗导航修复、桌面状态反馈和 Windows 图标优化。
- 应用 OAuth 导航保留当前平台会话，弹窗按当前平台 origin 匹配。
- 首次安装默认开启开机启动，已有用户设置继续保留。
- macOS 打包压缩级别与 stable 对齐，保留 DMG/ZIP、完整资源、签名和公证。
- 延续统一 v 标签和完整 beta.N 版本、Windows 短输出目录、卸载失败保留登记与可重试机制。
- Beta 五平台全部成功后自动公开并同步 beta 入口；正式订阅保持兼容版 3.0.10。升级和重启保留订阅选择，禁止自动降级。
- 前端允许消费线中的历史 pin，按冻结输入构建；历史 tag 续跑使用目标提交的子模块声明。
- S3 同步优先核对服务端 SHA256，缺少校验值时完整读回，来源与元数据校验通过后才更新指针。

macOS 安装包签名并公证；Windows beta 安装包未签名，仅供测试。真实客户端验证由用户进行。
