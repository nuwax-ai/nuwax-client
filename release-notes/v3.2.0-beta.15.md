# Nuwax 3.2.0-beta.15

- ACP 适配器 `1.2.49`，随包 `nuwax-harness` 引擎 `0.18.59`（与 beta.14 相同依赖）。
- 修复 Windows 发布校验：终端兼容资源准备改用 Windows 自带 bsdtar 解压
  （`tar -xf`），不再依赖 Windows PowerShell 5.1 的 `Expand-Archive`——2026-11-22
  的 runner 上其 Archive 模块会调用该宿主不支持的 .NET 3 参数重载，且错误不终止，
  导致后续误报 `SHA256 mismatch: LICENSE`。资源缺失时现在明确报
  `missing resource: <name>`，与哈希不匹配区分。
- 图片：工具输出图片入口限额可用环境变量调整（`NUWAX_IMAGE_MAX_COUNT`、
  `NUWAX_IMAGE_ENTRY_MAX_BYTES`、`NUWAX_IMAGE_ENTRY_MAX_TOTAL_BYTES`，默认
  8 张 / 16 MiB / 24 MiB 不变）。
- 图片：视觉收缩按 `detail` 与本次工具预算触发；40–80 MP 的合规原图会先缩图保留；
  桥侧 `original` 计费与入口口径一致；省略提示按稳定格式严格识别。
- chrome-devtools-mcp：补全启动参数，新增 `--maxTabs=10` 与 `--no-usage-statistics`，
  避免 agent 页面跨会话累积。
