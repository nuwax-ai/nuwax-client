# Nuwax 3.0.14-beta.1

消息性能与主页应用版：DEV-377 历史消息上翻卡顿性能优化（message 微应用升级 518be4d）、智能体主页打开已发布应用、协议选择页等改进。

## 变更

### 消息（IM）

- 历史消息上翻卡顿性能优化（DEV-377）。
- message 微应用升级至 518be4d（适配基线同步重制）。

### 主页与应用

- 智能体主页支持打开已发布的应用（space-square）。

## 升级须知

- beta 通道版本；从 3.0.11-beta.6+ 或 3.0.13 stable 均可平滑升级。
- Windows beta 安装包未签名，仅供测试。
