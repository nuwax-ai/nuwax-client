# Nuwax 3.0.11

3.0.11-beta.1–beta.6 全量转正：桌面 IdP 登录/绑定回调与验证码、OAuth 会话与弹窗导航修复、License 界面、IM 与会话轨迹更新、macOS 通知原生模块与授权页检测、Windows 图标画布补齐与深链主导航恢复；发布链升级（统一 v 标签、S3 服务端 SHA256 校验、卸载失败保留登记可重试）。

## 变更

### 登录与身份（IdP）

- 桌面 IdP 登录/绑定回调：业务域顶层 origin 保留与校验；验证码流程完善。
- 应用 OAuth 导航保留当前平台会话，弹窗按当前平台 origin 匹配。
- License 界面就绪（生产 License provider 接通另随后续版本）。

### 桌面体验

- 深度链接直达时恢复主导航。
- Windows 任务栏图标画布补齐；首次安装默认开启开机启动（已有用户设置保留）。
- macOS 授权页新增消息通知状态检测与系统设置入口；打包校验通知原生模块解包位置、架构与签名。
- IM 与会话轨迹更新。

### 发布链与安装器

- 统一 v 标签与完整 beta.N 版本形态；升级和重启保留订阅选择，禁止自动降级。
- S3 同步优先核对服务端 SHA256；Windows 独立卸载遇占用保留登记、可重试。
- 前端允许消费冻结 pin 构建；微应用 pin 与 adapter 声明一致。

## 升级须知

- 从 3.0.10 或任意 3.0.11-beta 均为常规增量更新；1.0.x 老版本可直接升级。
- Windows 正式版经 win-pc EV 签名；macOS 签名并公证。
