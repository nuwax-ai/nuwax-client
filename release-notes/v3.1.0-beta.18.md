# 女娲Nuwax 3.1.0 Beta.18

- 会话支持多个终端，切换页面后保留终端；补齐可信终稿恢复与纯文本粘贴。
- 资料库阅读器保留登录态、查找与前进后退；最大化预览时保留正文、滚动和草稿。资料库增加递归文件夹上传。
- 任务侧栏支持正文检索和历史消息定位，修复置顶提示的生命周期问题。正文检索需配套测试后端，旧后端保留标题搜索。
- IM 修复备注刷新、群列表恢复和迟到发送失败的状态隔离；补齐本人多端未读刷新。
- 客户端补齐迟到身份响应校验和页面恢复去重，修复 Windows 关闭自启后的遗留启动项清理及并发写入。
- macOS/Linux 内置 ACP 增加影子 grep/find 的超时、内存观测与单次安全回退；Windows 保持现有执行方式。

请重点验证终端切换、Office 文本粘贴、资料库阅读/目录导入、备注与发送重试，以及 Windows 自启开关和重启行为。原现场未复现的问题继续搁置，独立修复通过测试不表示原事故已关闭。Windows Beta 安装包未签名，仅供测试。
