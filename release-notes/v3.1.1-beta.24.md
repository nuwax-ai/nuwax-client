# Nuwax 3.1.1-beta.24

基于 Beta.23 的完整发布代码，合入 PR #113 的浏览器历史导航回归验证，替代已取消、未公开的 Beta.23。

- 内置浏览器采用紧凑标题胶囊；刷新、更多、页内查找、复制和置顶入口参照微信调整。
- 顶栏、菜单和加载失败页复制链接后统一显示 toast：成功提示“链接已复制”，失败提示重试；重复操作刷新提示时间。
- 前进、后退按钮在当前页面存在可用历史时显示，两个方向分别启用；真实 Electron 回归确认各页面历史和导航命令独立。

保留 Beta.23 的 Windows 桌面快捷方式升级选择、自启动历史入口清理、配套引擎版本选择修复，以及 Beta.22 的截图、Computer Use、扫码登录、文件面板及引擎更新。适配器 1.2.33、引擎 0.18.37 和前端双 pin 均沿用已提交发布基线。

终端持久化、跨会话终端保活、多终端及运行实例管理继续排除。新包由发布 CI 构建与校验，供测试回归；Windows Beta 包未签名。本轮替换构建为第 2 次，Beta.23 的 tag/SHA 与草稿保留，不公开旧候选。
