# 女娲Nuwax 3.1.0 Beta.9

- 新增网页链接打开方式设置，可选择应用内独立窗口或系统默认浏览器，修改后立即生效。
- 应用内网页采用简洁工具栏，支持后退、前进、刷新、停止，以及标题、域名和完整网址查看。
- 网页菜单支持复制链接、系统浏览器打开、页内查找、缩放和打印；窗口可独立开启置顶。
- 浏览器作为内置桌面特性接入，首次打开网页时创建窗口；能力不可用时回退系统默认浏览器。
- 优化客户端内置页面的更新日志样式，补齐列表圆点、缩进和段落间距。
- 更新执行适配器，完善模型思考参数兼容、文件导出与下载诊断，并整合当前 3.1 维护线修复。

请重点验收链接打开方式切换、网页导航与菜单、跨应用置顶，以及支付、登录和附件下载流程。使用线上业务页面时，更新日志样式将在业务前端发布后生效。
