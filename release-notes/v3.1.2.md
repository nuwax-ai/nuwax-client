# Nuwax 3.1.2

相对上一正式版 3.0.25，本次更新包含以下内容。

## 功能更新

- **扫码登录与团队邀请**：支持 App 扫码、手机确认登录；完善团队邀请链接与二维码加入、加入确认和登录回跳，新增用户昵称与头像引导。
- **文件与会话体验**：优化工作区文件树、文件预览及导入导出入口；资料库阅读页保留登录态和最大化前的页面状态。截图可进入当前会话输入框，修复剪贴板同时包含文本时 Office 附件丢失的问题。
- **模型用量统计**：支持按用户查询 Token 消耗、排名和趋势，修复积分大数精度及零余额展示问题。

## 体验优化与问题修复

- **内置浏览器**：普通页面在同一浏览器窗口中以独立页签打开，支付及其派生页面使用独立窗口。优化紧凑顶栏、页签切换关闭、前进后退、页内查找、复制链接反馈和主题同步；完善证书异常站点的风险确认，修复接受证书后页面灰屏的问题。
- **截图与日志**：优化截图启动和首次采集恢复，支持 PNG 保存、多行文本标注，以及同一次截图中连续使用所选标注工具；截图及日志文件名采用电脑本地时间。
- **智能体引擎**：长对话支持自动压缩上下文，超大工具截图优先缩小；改进模型 Responses 协议、推理档位默认值和权限审批兼容性，输入超限时给出明确提示。修复配套引擎误选旧版本的问题。
- **会话稳定性**：改进 IM 断线恢复、未读刷新、过期屏幕锁和任务终态恢复。
- **升级与 Windows 安装**：新增需显式订阅的独立 Dev 更新通道，完善通道切换提示。Windows 覆盖升级保留用户删除桌面快捷方式的选择，关闭自启动时清理历史入口并隔离其他产品；支持导出日志 ZIP 以便排障。

建议所有用户升级，获得最新功能与稳定性改进。
