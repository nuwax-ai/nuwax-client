# 女娲Nuwax 1.0.26（beta）

语言切换闭环与终端体验版：客户端切语言全链修复（本修复此前因未进包在 v1.0.23~25 缺失）、mac 终端中文输入与目录落点、顶栏菜单收起、页面内右键菜单、设置面板入口调整；web 侧随本批同步禅道 bug 群修复。

## 变更

### 语言切换（bug 2428）

- 修复客户端设置切换语言无效果：壳 i18n:setLang 向 webview 转发 set-lang 的代码此前仅存在于开发工作树、从未进入 v1.0.22~25 任何发包，本版补齐提交并随包发布；同值同步跳过（避免启动期 guest 白吃一次重载）。
- web 侧配套加固：set-lang 先同步落语种再拉字典，弱网下壳重载不再回退旧语言。

### 终端（bug 2526）

- mac 从 GUI 启动的终端保证 UTF-8 locale，中文输入/回显不再逐字节乱码。
- 终端起始目录可用性守卫：拼接目录不存在或为空时回退最近活跃引擎工作区/配置工作区/HOME。

### 界面与交互

- 顶栏自绘菜单（Win/Linux）点击 webview 内容或窗口失焦自动收起（bug 2427）。
- 页面内右键菜单恢复：复制/粘贴/另存图片等系统编辑命令直达 webview（bug 2473/597）。
- 设置-会话面板「新建会话」入口隐藏（保留底层能力，bug 2530）。
- web 侧（随 nuwax dist df987b3b9）：右上角按钮对齐与沉浸壳顶部退让（bug 2429）、个人资料弹窗尺寸收敛（bug 2439）、会话发送按钮异常结束恢复与重进会话消息连续（bug 2528/2520）、消息收起控件气泡内化（bug 2529/2470）、会话分享功能全量下线（bug 2527）、系统管理侧滑/横滚批次（bug 2456-2458/2460）。
