# Nuwax 3.1.1-beta.15

- Computer Use 设置新增执行引擎选择，可切换 CUA Driver 与 Agent Desktop（实验性），默认继续使用 CUA Driver。
- 引擎选择按本机保存，任务运行或暂停期间禁止切换，沿用现有授权、黑名单、敏感操作确认及暂停、停止和接管入口。
- 加强任务代次和旧引用校验，停止后清理私有观察记录，避免重放未确认的操作。
- 修复 Windows 打包时 Agent Desktop 原生资源的解包路径兼容问题。

Agent Desktop 首版支持无障碍控件观察与操作；视觉定位、浏览器专用工具、物理键鼠及实时预览暂不支持。各平台真实业务任务仍需继续验证。
