# Nuwax 3.2.0-beta.12

- Windows 安装成功后，后台清除属于当前安装且事务已结束的 `Nuwax-preserved-install-files-*` 目录，包括其中没有归属记录的文件和仅存在于旧归档的副本。重解析路径会被跳过，仍占用的文件留待后续成功安装处理。
- Nuwax Harness 适配器升级至 1.2.47。修复测试开关下切换带供应商前缀的模型失败，以及配置为 Responses 协议时请求落到 Chat Completions 的问题。

Windows Beta 提供无签名原包。升级后可在 `%TEMP%\Nuwax-installer-recovery-active-*-cleanup.log` 中查看 `Preserved cleanup:` 的删除量和剩余量。
