# Nuwax 3.1.1-beta.21

适配器 hotfix：`@nuwax-ai/nuwax-harness-acp-ts` 1.2.32 → **1.2.33**。

- **修复 `value default is invalid`**（1.2.32 的遗漏）：`runTurn` 此前把会话身份串
  的 `[default]` 哨兵原样传给引擎，引擎把它当自定义档位发到 wire 上，网关拒绝。
  1.2.33 在 runTurn 读到哨兵时传 null（引擎省略该字段，厂商按自己的默认执行），
  与 `createCodexCollaborationMode` 的映射保持一致。
- 其余与 beta.20 相同（引擎 0.18.37 全部功能）。
