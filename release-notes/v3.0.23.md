# 女娲Nuwax 3.0.23

## 新增功能

- **本机文件直连**：会话中可直接新建、编辑、重命名文件，删除的文件进入回收站可随时找回；支持文件预览，也可用系统默认方式打开。设置中新增「本机文件直连」开关，默认开启。
- **截图与录屏快捷键**：截图、GIF 录制、屏幕录制支持自定义快捷键；Windows 上注册为全局热键，客户端切到后台或收进托盘也能一键触发。
- **通知直达会话**：点击系统消息通知即可唤起客户端并定位到对应会话。
- **电脑操作安全边界**：敏感操作前二次确认，支持应用黑名单，并附截图隐私说明。

## 优化

- **电脑操作（Computer Use）体验**：操作浮窗改为图标形态，悬停即见完整提示；操作预览始终跟随当前会话，不与其他任务画面互串；MCP 设置列表中相关条目改为跟随 Computer Use 开关统一管理，避免误改。
- **GIF 录制性能**：大幅优化编码内存占用，长时间录制更从容。
- **更新与安装**：macOS 更新改为下载完整安装包，速度与成功率更稳定；Windows 安装前检查磁盘空间，不足时提前提示。
- **页面恢复**：加载失败或等待过久时提供一键恢复界面，可重新加载或直达设置。
- **安全加固**：加强外部链接的来源与协议校验。

## 问题处理

- 修复 Windows 下开启电脑操作后会话中无相关工具的问题。
- 修复电脑操作开启状态在设置保存、版本升级或助手启动失败后被意外关闭的问题。
- 修复 macOS 更新因差分下载失败导致无法升级的问题。
- 修复 macOS 通知权限无法完成授权的问题；截图等辅助窗口激活时不再误拦消息通知。
- 修复 PDF 预览加载异常，切换或关闭预览不再卡住旧请求。
- 优化验证码失效提示，防止重复提交；登录收尾失败后可正常重试。
- 修复若干影响启动、服务就绪与后台清理的稳定性问题。

建议所有用户升级体验。
