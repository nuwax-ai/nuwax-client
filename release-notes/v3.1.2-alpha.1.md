# Nuwax 3.1.2-alpha.1 · Dev

- 新增独立「主题」页，以卡片预览并点击切换主题；外观、主题包、本地目录和管理操作统一为左侧说明、右侧控件的设置项。
- 双模式主题可跟随系统自动切换，或固定浅色、深色；单模式主题自动使用其支持的外观。
- 官方默认主题固定浅色；外观开关放在卡片上方。移除反复出现的内置页面版本差异浮层，版本诊断保留在「关于」页。
- 二级菜单使用独立的主题背景，保留与一级导航的颜色层次；悬停与选中态跟随主题，背景图场景更协调。
- 新增默认关闭的「完整主题预览」：主动开启后使用此版本内置页面体验完整主题，无需部署测试站；切换可能重新加载当前页面。
- 主题预览独立保存，不修改原有本地加速偏好；关闭后恢复原加载配置。
- 新增「扩展与实验」页，集中管理 DS Bot 开关、模型授权、兼容插件和 Agent 环境授权。
- DS Bot 使用独立的精简工作台，显示语言随 Nuwax 主壳实时同步。

本版本通过 Dev 通道分发。Beta / Stable 默认加载行为不变；Agent 环境授权仍默认关闭。模型需要使用当前账号已开放外部调用的授权。
