# 女娲Nuwax 3.0.17-beta.7

本版在 beta.6 基础上修正两处体验：

- Windows 隐藏没有预先授权操作的「授权」菜单、页面和首次引导；旧引导事件也不会再打开空白或说明页。macOS 授权流程与 Linux 现有说明、自测保持。
- 客户端关于页和包内前端版本徽标在下载、安装时仅保留按钮及行内状态，不再延迟弹出额外 loading／进度框；失败详情、关闭及重试入口保留。

Windows 一键下载、安装、重启，以及 macOS／Linux 下载后再次点击安装的策略保持。beta.6 的其它功能和业务新窗口放行规则保持。

[功能与验证清单](https://github.com/nuwax-ai/nuwax-client/blob/v3.0.17-beta.7/docs/acceptance/20261018-beta7-validation.md)。首次升级到本版时，界面由正在运行的旧版决定；上述改动在运行 beta.7 后生效。在线站点提供的版本徽标随该站点的前端部署更新；本包内嵌前端已包含修复。

Windows beta 沿用现有未签名发布策略；平台包、macOS 签名公证和更新源状态以最终发布校验为准。
