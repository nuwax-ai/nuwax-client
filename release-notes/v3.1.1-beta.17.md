# Nuwax 3.1.1-beta.17

基于 beta.15/beta.16（含 Agent Desktop 引擎与归档修复）叠加引擎与 ACP 链路更新：

- 升级 ACP 适配器 `@nuwax-ai/nuwax-harness-acp-ts` 至 1.2.30，引擎 `nuwax-harness` 随之更新至 0.18.33：上下文超窗不再要求换会话——引擎自动压缩/裁剪并保留对话（含 resume 回放一致性、轮内中途压缩检查点、按网关真实拒绝点提前调度）；本轮经 `_meta.codex.sessionFailure` 判定失败并提示重试/缩短输入/换更大窗口模型。
- 引擎环境变量改用 `NUWAX_*` 前缀，URL 与凭据绑定同源路由（不再跨来源借用 key），后端下发的模型上下文窗口优先生效。
- 新增 `make harness-local` 本地引擎联调（源码构建替换 dev 资源，`make dev` 自动还原发布版）。

本版验证：资源同步（adapter 1.2.30 + 引擎 0.18.33 二进制冒烟）、engines 416/416、主进程 tsc 通过。
