# 女娲Nuwax 3.0.25 Beta.1

- 修复 macOS 冷启动后进入截图时，客户端图标可能从 Dock 和应用切换器消失的问题。
- macOS、Windows 与 Linux 的截图、屏幕录制和 GIF 快捷键支持系统全局触发，客户端在后台时也可使用。
- 截图和录屏在最终确认前支持拖动选框、拖动边框或角点调整大小。
- 修复部分消息含 HTML 包装时，正文列表丢失分段或无法正确显示的问题。
- 确认当前电脑后，首次工作区解析失败、上下文失效、重新挂载及导出均保留本地来源，避免静默改走云端文件接口。
- 补齐本机 Markdown 图片路径转换；PDF 中文字符映射随包提供，预览不再依赖外部 CDN 加载映射。

本版本供测试验证，重点请检查 macOS 冷启动截图图标、后台快捷键、选框缩放，以及当前电脑文件的断网预览。

前端修复包含在安装包内。验收包内页面请启用设置中的「本地化加速」并重启；直连线上页面使用的前端版本以站点部署为准。
