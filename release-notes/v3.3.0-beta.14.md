# Nuwax 3.3.0-beta.14

- 内置 Agent 引擎升级到 0.18.68。MCP（外部工具）配置里的服务器名称含中文等非 ASCII 字符时，
  不再整台服务器启动失败：非法字符会替换为下划线并照常运行，日志里同时给出原名与替换后的名字。
  此前这种配置不报错、工具却用不了，只会在会话里看到一个失败的启动调用。
- MCP 工具的调用参数改为按工具自身参数上报（与 Claude Code、opencode 一致）。依赖该形态的
  `ask_question` 表单在网页端可以正常弹出；桌面端两种形态都支持，不受影响。
- 精简系统未安装根证书时，模型请求会回退到内置根证书，不再出现"请求全部失败且没有任何回复"；
  两条路径都不可用时会直接报错并提示安装方式。
- Agent 适配器里用户可见的文案统一为 Nuwax Harness 品牌，登录时上报的客户端名称改为
  `nuwax-harness-acp`。
- 除上述变化外与 3.3.0-beta.12 相同。
