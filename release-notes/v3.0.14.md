# Nuwax 3.0.14

## 改进与修复

- 修复普通项目中多个会话共用工作目录时的任务串扰：各会话独立执行，取消一个会话不会打断其他会话。
- 文件服务例行升级至 nuwax-file-server 1.6.0。
- 完善原生截图和录屏：支持悬停识别窗口，采集时自动隐藏客户端，结束或取消后恢复；录制默认最多 30 分钟，可在「截图与录屏」设置中调整，控制条显示剩余时间。
- 保留截图预览的剪贴板复制、截图编辑、MP4/GIF 录制及业务页面调用。本次暂不展示应用菜单中的「截图与录屏」，其他入口和快捷键继续可用。
- 托盘菜单新增设置入口，修正授权状态标签的垂直对齐，整理 Computer Use 设置页面。
- 跟进 Linux 更新安装时的管理员授权流程。
- 更新内嵌前端与消息微应用，包含语音消息播放和切换会话体验改进。

## 升级说明

- 本版本为正式版，延续现有账号与本机配置。
- macOS 截图和录屏需要系统屏幕录制权限；首次开启后按系统提示重启应用。
- 本机文件直访继续保持关闭，文件列表、预览和下载使用现有服务路径。
