# 女娲Nuwax 1.0.12（beta）

更新体验与视觉打磨版：更新徽标文案与进度圆环优化、Windows 任务栏图标修复、Win/Linux 顶部避让微调。

## 变更

### 更新徽标打磨

- 有新版本时徽标文案改为「更新」胶囊；更新下载完成后改示「重启更新」并带加载态，操作指向更明确。
- 下载进度圆环加粗缩小（22/10 → 16/18），顶栏视觉更轻。

### Windows 任务栏图标修复

- 任务栏图标发糊、不满幅修复：icon.ico 重制（90% 满幅 + 补齐 20/40/96 DPI 层），运行时窗口图标改走 ico 多分辨率取层。

### 布局微调

- Win/Linux 内容区顶部避让高度 28 → 32：修复字形下沿压卡片上沿，回加留白间隙。

## 升级须知

- 含 1.0.11 全部变更（测试环境接入与本地化默认开）及此前 beta 版全部变更。
- 数据目录 `~/.nuwax`、更新通道不变，存量 beta 客户端可直接在线更新。
- Windows beta 包为未签名构建（正式版手签）；SmartScreen 提示「未知发布者」选「仍要运行」。mac 双架构自动签名+公证。
