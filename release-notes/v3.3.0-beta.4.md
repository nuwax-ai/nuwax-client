# Nuwax 3.3.0-beta.4

- Linux 安装包：安装包内不再包含跨 `/opt` 与 `/usr` 的硬链接。此前在 `/opt` 与 `/usr` 分属不同分区的系统上（如统信 UOS 20 Pro 1050），安装会失败。
- Linux 安装包：内置的 SQLite、录屏编码器和电脑操作助手改为在 glibc 2.28 环境下构建，不再要求 glibc 2.34 及以上。
- 内置 `nuwax-harness-acp-ts` 升级至 1.2.51 及以上：引擎版本改为运行时解析，修复干净机器上启动适配器时提示引擎未安装、或有旧缓存的机器静默使用旧引擎的问题。
- 已知问题：Agent Desktop 引擎的可执行文件为上游预编译，在 glibc 低于 2.34 的 Linux 系统上无法启动；默认的 CUA Driver 引擎不受影响。
