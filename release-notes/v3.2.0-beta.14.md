# Nuwax 3.2.0-beta.14

- ACP 适配器升级到 `1.2.49`，随包 `nuwax-harness` 引擎升级到 `0.18.59`。
- 图片：工具输出图片入口限额可用环境变量调整（`NUWAX_IMAGE_MAX_COUNT`、
  `NUWAX_IMAGE_ENTRY_MAX_BYTES`、`NUWAX_IMAGE_ENTRY_MAX_TOTAL_BYTES`，默认
  8 张 / 16 MiB / 24 MiB 不变）。
- 图片：视觉收缩按 `detail` 与本次工具预算触发；40–80 MP 的合规原图会先缩图保留，
  不再整张丢弃；桥侧 `original` 计费与入口口径一致。
- 图片：省略提示按稳定格式严格识别——配置变更后旧历史仍可识别，且不再误吞形似文本。
- chrome-devtools-mcp：补全启动参数，新增 `--maxTabs=10` 与 `--no-usage-statistics`，
  避免 agent 页面跨会话累积（此前实测 9.8 天攒 33 个标签页 / 6.7 GB RSS）。
