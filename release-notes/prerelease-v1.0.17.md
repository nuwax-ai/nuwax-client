# 女娲Nuwax 1.0.17（beta）

电源保活与应用菜单版：设置页新增「允许锁屏运行」三档电源保活；标准应用菜单落地（mac/win 各自对齐规范）；本地化加速行显示实际加载源；界面性能与项目创建优化。

## 变更

### 电源保活

- 设置页新增「允许锁屏运行」三档开关：锁屏后按所选档位保持任务运行，长时任务不再因锁屏中断。

### 标准应用菜单

- 标准应用菜单规范 v1 落地：mac 六菜单 / Windows 五菜单对齐，「文件」菜单提供新建任务（⌘N）、搜索（⌘K）、工作空间目录等入口。
- 编辑命令（复制/粘贴/撤销等）显式路由到焦点控件，修复部分场景菜单恒灰。
- Windows 自绘菜单观感优化：Win11 原生菜单风格 + 快捷键提示列。

### 本地化加速

- 设置页本地加速行显示当前实际加载源（直连域名 / 本地网关），切换后肉眼可验，不再需要猜测是否生效。

### 界面与交互（前端）

- 侧栏页签切回加活动门控：静止状态下切回页面不再发起多余请求。
- 远程桌面（vncDesktop）文件系统接口迁移为静态资源请求。
- 项目创建弹窗支持图标上传，创建接口返回字段优化。
- 智能体网页应用点击不再计入「最近使用」。

## 升级须知

- 含 1.0.16 全部变更（Computer Use 首发预览）与 1.0.15 全部变更（提测五问题修复，含本地化加速开关即时生效）及此前 beta 版全部变更。
- 数据目录 `~/.nuwax`、更新通道不变，存量 beta 客户端可直接在线更新。
- Windows beta 包为未签名构建（正式版手签）；SmartScreen 提示「未知发布者」选「仍要运行」。mac 双架构自动签名+公证。
