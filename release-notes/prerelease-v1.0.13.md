# 女娲Nuwax 1.0.13（beta）

会话进度胶囊重构与未读提醒版：进度胶囊按参考 UI 重构为分区面板并全面打磨动效；已完成会话未读通知；项目面板与侧栏同步修复。

## 变更

### 会话进度胶囊重构

- 按参考 UI 重构为分区面板：新增更改统计、分支、终端折叠与任务结果区，宽度上限放宽至 320px。
- 任务结果行改为 `<task-result>` 标签产物驱动，可点击直接打开文件预览；收起按钮固定右上。
- 动效整体打磨：面板双向开合（展开右滑出/收起反向收回）、JS 逐帧驱动绕过环境动画冻结、运行行扫光收敛到工具名、收起态紧凑贴合内容宽度、阴影减弱。

### 会话与侧栏

- 已完成会话新增未读通知与视觉标识，回访后自动清除。
- 会话详情页的开始/结束状态及时同步侧栏；侧栏任务终态核对与回访刷新；会话结束后释放隐藏会话的页面缓存。
- 项目面板改复合键定位项目：修复项目撞号导致的置顶串标记与幽灵重复行。

### 其他

- 智能体/专家类卡片图标裁圆（圆形开关），技能/连接器/资料库维持方形口径。
- 应用「最近使用」列表条数收敛为 100，应用类型过滤新增第三方应用。
- 缓存遥测拆独立调试面板（带 DEBUG 标识，面向排障）。
- 仓库 CI：push 触发收窄为仅 main，工作分支一律走 PR 双轨门禁。

## 升级须知

- 含 1.0.12 全部变更（更新体验与视觉打磨）及此前 beta 版全部变更。
- 数据目录 `~/.nuwax`、更新通道不变，存量 beta 客户端可直接在线更新。
- Windows beta 包为未签名构建（正式版手签）；SmartScreen 提示「未知发布者」选「仍要运行」。mac 双架构自动签名+公证。
