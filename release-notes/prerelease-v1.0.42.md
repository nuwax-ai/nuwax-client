# 女娲Nuwax 1.0.42（beta）

客户端截图问题修复版：菜单语言切换（含 macOS 原生菜单四语言）、全栈会话滚动白区修复、会话蓝点未读恢复；注册链路升级 reg/v2 与设备身份算法对齐。

## 变更

### 客户端截图四问题（验收记录 docs/20260927）

- 菜单语言切换：macOS 原生应用菜单补齐四语言（33 个菜单键），语言切换即时重建菜单；此前仅部分界面跟随。
- 全栈开发会话滚动白区：结构修复，会话切换与滚动恢复正常。
- 会话蓝点「读后又出现」：去重逻辑恢复（原修复随前端 pin 切换丢失），同项目切换长时间观察不再复现。
- 「点击会话后置前、时间变刚刚」：当前账号未复现，本版含观测加固，待复发证据继续跟进。

### 注册链路（内部）

- 注册端点升级 `/api/sandbox/config/reg/v2`；设备身份算法注释对齐（安装 ID → 硬件 ID）并补注册派生测试。

### 界面与交互（前端）

- 项目面板选择与定位修复；含 1.0.41 全部变更。

## 升级须知

- 数据目录 `~/.nuwax` 不变；Windows beta 包未签名（SmartScreen 选「仍要运行」）；mac 双架构签名+公证。
