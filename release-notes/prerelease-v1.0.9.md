# 女娲Nuwax 1.0.9（beta）

自动更新与稳定性版：客户端后台自动发现新版本；修复 mac 标题栏拖拽间歇失效；前端界面整批修复与优化（顶部避让回调、会话列拖宽、会话 UX 三连修复、AppDevPro 功能批次）。

## 变更

### 客户端自动获取新版本

- 新版本发现改为后台自动进行：启动 10 秒首查 + 每小时轮询 + 唤醒补查，发现新版本即亮出更新入口，静默失败不打扰使用。
- 顶栏撤除「下载中」进度胶囊，下载过程不再占用顶栏。

### 壳层修复

- 修复 mac 标题栏拖拽间歇失效：顶栏行常驻拖拽手柄 + 空热区宽限期，拖不动窗口的问题不再出现。
- Win/Linux 顶部避让高度回调至 28/36（上一版调到 40 实测退让过多，按用户反馈恢复）。

### 界面与交互（前端）

- 单栏（style3）主会话列宽度支持拖拽调节，与会话分栏共用分隔条，宽度按比例持久化。
- 会话 UX 三连修复：发送后草稿不再复活；删除当前会话不再跳走到别的会话；首条消息发送延迟收敛。
- 首页「+」连续点击不再带出全站默认智能体工具（竞态三修）；首页分类排样式对齐参考原型（分段胶囊 + 分类图标）。
- 单栏二级列标题裁顶修复、工作空间头部间距对齐；二级菜单列收起/展开保持挂载同速过渡，消除瞬移。
- 用户弹层加宽至 240px 并改为左上对齐弹出，积分行恢复单排。

### AppDevPro

- 新增远程桌面工作区支持、发布版本记录功能及发布进度模态框优化。
- 预览新增运行时控制按钮；项目创建后恢复已选工具；加载状态与标签栏宽度优化。
- 模型选择器：模型数据收敛单接口，选择按钮展示模型与供应商图标。

## 升级须知

- 含 1.0.8 全部变更（设置弹窗重构与更新体验版）。
- 数据目录 `~/.nuwax`、更新通道不变，存量 beta 客户端可直接在线更新。
- Windows beta 包为未签名构建（正式版手签）；SmartScreen 提示「未知发布者」选「仍要运行」。mac 双架构自动签名+公证。
