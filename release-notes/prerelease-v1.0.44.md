# 女娲Nuwax 1.0.44（beta）

常驻性能与会话体验版：常驻流与隐藏页工作回收、文件列表按需拉取（深度/类型参数）、会话阅读位置保持与权限容错。

## 变更

### 性能（常驻资源回收）

- 常驻流与隐藏 UI 工作回收：后台页面不再持续占用流与渲染资源（常驻性能审计批次落地）。

### 会话体验

- 会话阅读位置保持：切换回来停留在原位置，同时支持跟随最新历史。
- 过程叙述与工作轨迹折叠优化；智能体权限拒绝不再崩溃（容错处理）。
- 工作台聊天面板对齐与 agent-dev 面板可拖宽。

### 文件体验

- 文件列表请求支持深度与类型参数（按需拉取，配合文件树懒加载契约）；文件树懒加载断言跟平。

### 其他

- SDLC 工具链（hooks/skills）需求处理与部署门禁更新（内部）。
- 含 1.0.43 全部变更（deviceId 硬件身份、reg/v2、logo 更新）。

## 升级须知

- 数据目录 `~/.nuwax` 不变；Windows beta 包未签名（SmartScreen 选「仍要运行」）；mac 双架构签名+公证。
