# 女娲Nuwax 3.0.25 Beta.3

- 调整截图工具界面：顶部切换截图与录屏，选区下方使用浅色图标工具栏，保留标注、样式、撤销重做及选框调整。
- 通用截图入口确认后直接复制图片到剪贴板，不再打开结果预览；复制失败会明确提示。消息会话中的截图附件流程沿用现有行为。
- 录屏选区提供开始录制和 MP4/GIF 格式选择；录屏结果预览支持播放、下载和复制，GIF 保留循环预览。
- 客户端设置 → 系统新增「新消息提示音」，默认开启，修改后即时生效并在重启后保留。
- 后台新消息的提示音在所有会话间按 3 秒节流，避免密集消息连续响铃；通知横幅和未读角标继续正常更新。声音遵循桌面通知权限、免打扰和系统声音设置。

本版本包含 Beta.2 的本机文件面板、离线预览及 GIF 生成优化。验收包内前端请启用设置中的「本地化加速」并重启；直连线上页面的版本以站点部署为准。

截图、录屏和提示音已通过源码及独立 Electron 验证；本 Beta 的真实安装包、物理多屏/DPI、系统剪贴板与 Mac/Windows 通知发声效果仍需实机验收。
