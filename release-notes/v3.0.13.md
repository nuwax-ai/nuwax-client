# Nuwax 3.0.13

纯黑新图标版：应用图标与托盘图标换用纯黑底新版；nuwax-file-server 升级 1.5.8；IM 系统角标计数修正；OAuth2 审计与国际化完善。

## 变更

### 品牌与图标

- 应用图标与托盘图标换用纯黑底新版。

### 文件服务

- nuwax-file-server 升级 1.5.8。

### 消息（IM）

- 系统角标只使用 unread-total 的 total，不再累加勿扰计数。

### 其他

- OAuth2 授权审计状态筛选默认展示全部申请记录。
- 新增网站应用闲置回收超时相关文案。
- 移除遗留 GUI 与 Windows MCP 冗余载荷。

## 升级须知

- 从 3.0.10+ 任意版本常规增量更新。
- Windows 正式版经 EV 签名；macOS 签名并公证。
