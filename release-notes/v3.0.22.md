# 女娲Nuwax 3.0.22

- 支持 Windows 10 早期版本（如 1511 / Build < 17763）的内置终端兼容：在内核不支持 ConPTY 的老旧 Windows 系统上，按系统版本号自动路由至兼容终端后端，锁定基础 x64 指令集，解决终端初始化失败或黑屏问题。
- 优化客户端鉴权与会话稳定性（NW-151）：主进程注册与会话检查链路增加 HTTP 401 双样本确认机制，首次 401 延迟 1.5 秒自动复核，单次网关抖动或瞬断自愈恢复，避免正常使用中被误踢回登录页；业务错误码 4010/4011 依然保持立即登出。
- 优化客户端退出与自动更新可靠性：
  - 更新触发安装退出时，主动释放资源与数据库后执行短延迟强制退出保障，macOS 补充安全退出超时，彻底消除安装器被旧进程锁定无法接管覆盖的问题；
  - 优化退出清理顺序，底层守护进程停机超时压缩至 1.5 秒并补充操作系统级强杀兜底，防止退出客户端后后台残留孤儿进程；
  - 登出及服务重启时特性清理异常降级处理（NW-173），不阻塞客户端主登录或重启流程；
  - 多语言更新弹窗及设置页关于文案统一精简为“立即更新 / 更新”。
- 修复 Windows 标准用户模式安装误触发提权的问题：当系统已存在所有用户（all-users）安装时，标准用户安装仅当前用户（/currentuser）不再误触发 UAC 提权或返回 1223 错误。
- Computer Use 能力保持就绪（含控制窗口置顶与坐标保护、推理模型视觉测试兼容），默认保持未开启状态，绝不占用系统资源或干扰主程序交互。
- 延续 3.0 维护线已有修复：全新安装路径解析、只读数据卸载保护、端口冲突自动避让、输入法组字回车保护及附件卡片双击预览。

本次使用 3.0 维护线及稳定前端。已安装 3.1 Beta 的用户需手动安装本版；线上 PC 页面随 PC Web 部署生效；MSI 保持手动安装。

已知问题：若旧卸载已删除整个安装目录、仅残留私有登记，且未指定原安装目录，重试可能安全停止（退出码 2），现存数据与备份保留；请按原安装范围传 /currentuser 或 /allusers，并以 /D=原安装目录 参数启动完整包重试；/D 放在命令末尾，不加 /REPAIR。此类无 /D 入口尚待修复和验收。扩展原生矩阵及其他范围的自动更新端到端仍单独验收。
