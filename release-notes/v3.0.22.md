# 女娲Nuwax 3.0.22

- 新增 Computer Use：在会话中让 Agent 查看屏幕、操作电脑，沿用当前会话的 Agent 和模型。功能默认关闭，可在设置中按需开启；已开启的设置会保留。
- 电脑操作支持选择目标窗口、管理多个窗口任务，并提供更紧凑的操作浮窗。可随时暂停、接管或停止，也可从托盘查看正在进行的任务和历史记录。
- 完善 macOS 权限引导，帮助你为客户端及电脑操作助手完成必要授权。
- 提升登录和会话稳定性，减少短暂网络波动引起的意外退出登录。
- 优化客户端退出和更新时的后台清理，减少后台进程残留。
- 改善 Windows 安装和卸载体验，修复部分安装路径、权限及只读文件引起的问题；提升早期 Windows 10 系统的内置终端兼容性。
- 修复输入法组字时误发送的问题，改善附件预览，并减少本地服务端口冲突对使用的影响。

更新说明：已安装 3.1 Beta 的用户需手动安装本版；MSI 用户请使用完整安装包更新。若此前安装中断且原安装目录已被删除，自动恢复仍可能失败，请保留本地数据并联系支持。
