# Nuwax 3.1.1

本次正式版汇总 3.1.1-beta.25 的客户端更新。

- Computer Use 支持在设置中选择 CUA Driver 或 Agent Desktop，保留现有默认引擎；切换执行引擎时同步对应 MCP 能力。
- 补齐 Agent Desktop、平台依赖和 Rust 标准库的开源声明，可查看许可证全文和组件修改说明。
- 改进内置浏览器标题栏、页面查找、历史导航和复制链接反馈。
- 修复截图首次采集失败、标注工具状态保持，以及 Agent Desktop 操作结果误判和任务结束清理问题。
- 保留 Beta 系列的 Windows 升级安装、自启动清理、文件面板、扫码登录和引擎管理修复。
- 优化固定第三方依赖的构建缓存，减少重复下载与编译。

终端持久化、跨会话终端保活、多终端及运行实例管理继续排除。
