# Nuwax 3.3.0-beta.11

- ACP 适配器 `nuwax-harness-acp-ts` 升级至 `1.2.55`，随包 `nuwax-harness` 引擎为 `0.18.67`：
  - 修复开启快模式的会话：恢复后开关显示为关闭、且首轮请求会清掉线程原有档位的问题；
    切换开关立即写入线程并等待引擎确认，同一会话的连续切换按顺序执行；
  - Amazon Bedrock 与 Google Cloud Vertex AI 会话的认证状态改由提供商本身描述，不再显示
    「未登录」，Codex 账号的登录/退出也不再覆盖它；
  - 引擎报告「模型不存在」时不再提示重试；
  - 新增 `NUWAX_HARNESS_CACHE_DIR`：用绝对路径覆盖 harness 二进制缓存根目录，适用于运行期
    `HOME` 与安装期不一致的容器环境（安装期与运行期须设同一个值）。
- 客户端侧：
  - 引擎空闲回收不再回收仍在使用的引擎，长对话结束后紧接着的请求不再触发冷启动；ACP 日志中的
    stdin/stdout 预览已脱敏；
  - 会话建立连续超时后，将卡住的引擎 home 隔离并重试一次，「导出日志」附带会话建立诊断信息；
  - 支持选择自动下载更新；
  - 浏览器内置页面的 Nuwax 请求头限定在业务域名。
