# Nuwax 3.0.23-beta.12

本版修复 Windows 下 Computer Use 开启后不生效的问题，并联动 MCP 设置列表的托管展示，供 Windows / macOS 实机验证。

- 修复 Windows 开启 Computer Use 后会话无 CU 工具：cua MCP 中继脚本此前以 `node -e <多行内联脚本>` 注入，Windows 引擎侧拼命令行时参数在换行处被截断（node 报 `-e requires an argument`），cua 服务器被静默跳过；现改为中继脚本落盘后以文件路径传参，与其他 MCP 条目同构。存量机器升级后开机自动重写旧条目，无需手动处理。
- MCP 设置列表 cua 条目托管显示：cua 条目显示「跟随 Computer Use 开关」金标（含 tooltip 说明），开关/编辑/删除一律禁用，「全部停用」豁免；唯一入口为设置页 Computer Use 开关。
- MCP 设置列表地址展示优化：cua 条目显示「node（Computer Use 运行时中继）」，普通条目长路径缩略为基名、内联 `-e` 脚本缩略为占位符，悬停保留完整命令。
- 前端配套 `921ba1880`：预览容器启动失败状态展示与重启提示逻辑优化。

PC Web 源码固定为 `921ba18806f0358294d5764fec0016b701b66f79`；壳基座保持 `d12d001a0d51e28513cba2b60e76413275cad161`。Beta 从固定源码构建，现有产物仓 pin 保留。

实机验证由用户执行。重点包括：Windows 开启 Computer Use 后新建会话工具列表出现 CU 工具（此前仅 38 个常规工具）、MCP 列表出现金色托管条目且开关/编辑/删除灰置、macOS 侧 cua 开关与列表显示不回归。
