# 女娲Nuwax 1.0.45

图标观感与源码管理体验版：Windows 任务栏/桌面图标圆角化（对齐新品牌视觉）、文件服务升级 1.5.4、源码管理新增变更文件搜索与产物面板改进、首页项目布局调整。

## 变更

### 图标与品牌

- Windows 任务栏/桌面/窗口图标补圆角：以品牌圆角母版重制全部 11 层 DPI 图标（16–256），Linux 安装图标四件套同步圆角化；深色圆角方块 + 白色四角星形态在各缩放档一致呈现。
- 新版品牌 logo（深底白色四角星）自 1.0.44 起替换全套应用图标（加载屏/关于页/托盘），本版补齐 Windows 侧圆角观感。

### 文件服务

- nuwax-file-server 升级至 1.5.4。

### 源码管理（工作区变更）

- 新增按文件名搜索工作区变更文件，改动列表快速定位。
- 提交后预览区自动刷新；「文件预览」多语言文案统一为「产物面板」。
- 预览地址栏宽度与最小/最大值调整，适配新设计。

### 首页

- 常规项目卡片统一开放沙箱自选；项目栏与工作目录栏同行展示，首页信息密度提升。

## 升级须知

- 本版自 beta 通道 1.0.44 转正并叠加上述变更；beta 通道后续从 1.0.46 继续。
- Windows 用户升级后若任务栏图标仍显示旧样式，请将旧固定项取消固定后重新固定（或重启资源管理器），使系统图标缓存刷新。
