# 女娲Nuwax 1.0.37（beta）

与正式版 1.0.36 同内容的 beta 通道追平版：webview 会话策略归位修复（外部 iframe 权限边界）、发布链同步可靠性加固。

## 变更

### 会话策略归位修复（承接 1.0.36 正式版）

- webview 权限边界修正：白名单权限仅在顶层文档与实际请求帧均属业务域时放行；业务页内嵌第三方 iframe 的媒体/剪贴板等权限请求恢复拒绝（1.0.36 beta 引入的策略覆写残缺所致）。
- 业务域来源动态判定（登录域名/本地网关/覆盖配置）回归基座统一实现。

### 发布链（内部）

- beta 通道同步的 S3 校验改走 API 通道并带重试与显式报错（公网校验在构建机上连接层不稳）。

## 升级须知

- 含 1.0.36 全部变更（桌面会话隔离与登录态强化：外部页面隔离、ticket 会话镜像、Windows 升级可靠性、Computer Use 三平台等）。
- 本版与正式版 1.0.36 内容一致，用于 beta 通道用户追平；此后 beta 将从本版继续向前。
- 数据目录 `~/.nuwax` 不变；Windows beta 包未签名（SmartScreen 选「仍要运行」）；mac 双架构签名+公证。
