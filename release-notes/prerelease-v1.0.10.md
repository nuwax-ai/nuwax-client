# 女娲Nuwax 1.0.10（beta）

标题栏拖拽手势化版：窗口拖拽/双击最大化架构重构，页面任何控件点击零吞没；多页面页头按钮失效问题根治；含 1.0.9 全部变更。

## 变更

### 标题栏拖拽手势化（架构重构）

- 窗口拖拽不再依赖壳层覆盖的拖拽热区（旧方案在页面上盖一层隐形拖拽层，挖洞遗漏即吞点击），改为壳层完全穿透：页面所有按钮、链接、输入框点击天然不受影响，项目详情、工作流画布、系统设置等多页面页头控件失效问题根治。
- 拖拽改为事件命中判定：在窗口顶部空白带（mac 36px / Win·Linux 28px）按下且目标为空白时开始拖窗，主进程跟随光标移动窗口，松手即停；双击空白带切换最大化/还原。
- 壳顶栏（左上按钮群与右侧之间）保留原生拖拽手感；旧版本/浏览器环境无此桥时自动降级无副作用。

### 界面与交互（前端）

- 工作流画布（Antv-X6）头部样式与容器布局优化。

### 稳定性

- mac 标题栏拖拽间歇失效的根因修复（空热区宽限 + 观测日志）延续带入；排障日志可区分「未判定空白 / 主进程未收到」两类情形。

## 升级须知

- 含 1.0.9 全部变更（自动更新、壳层修复、会话 UX 与 AppDevPro 批次）及 1.0.8 全部变更（设置弹窗重构与更新体验版）。
- 数据目录 `~/.nuwax`、更新通道不变，存量 beta 客户端可直接在线更新。
- Windows beta 包为未签名构建（正式版手签）；SmartScreen 提示「未知发布者」选「仍要运行」。mac 双架构自动签名+公证。
