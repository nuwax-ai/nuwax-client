# Nuwax 3.0.14-beta.6

包含 beta.5 的三端截图与录屏功能和编码工具链修复，进一步修复 macOS 发布在 Apple 网络故障时重复整包构建的问题。beta.5 因 Intel Mac 公证查询和票据嵌入时的连接中断未公开发布。

## 发布修复

- macOS 按“签名 app → 公证与嵌入票据 → 生成安装包”的顺序执行，避免 builder 和 afterSign 重复公证。
- 公证查询、票据下载和校验对网络中断有界重试；保留 submission ID，仅允许同一个签名 app 续跑。身份、签名和 Invalid 结果继续立即阻止发布。
- 公证票据校验完成后使用已签名 app 生成 DMG/ZIP；生成前后再次核对签名与票据。
- 公证失败时将签名 app 和恢复状态保留为短期 CI artifact，便于继续处理；恢复数据不公开上传到 Release。
- Intel 使用通过完整公证验证的 macOS 26 runner，编译最低目标仍固定为 macOS 12.0。

## 截图与录屏

Linux X11 支持截图、标注和区域录制，Wayland 使用系统授权并在同一流内预览、框选；客户端菜单支持悬停切换，入口为截图、MP4、GIF。既有 WebM API 与 IM 结果读取/回填契约兼容。Windows/macOS/Linux 编码资源按固定来源构建并随包核验。

## 验收边界

旧版 Sway 的静止源和连续采集仍有已知问题；物理多屏、混合 DPI、KDE、长时间录制、真实 IM 会话回填及正式安装包安装/升级仍需验收。Windows beta 安装包未签名，仅供测试。
