# Nuwax 3.2.0-beta.5

本轮集中修复 Windows 安装、升级及卸载反馈，并合入 release/v3.2.0 的最新修复。

- 安装前实际检查程序目录、临时目录和更新缓存的写入权限。失败时指出具体目录，并在退出旧客户端和解压前停止。
- 卸载可处理安装清单内只读的 LICENSE 等程序文件；权限不足时提前停止并提示重试，保留历史数据与卸载入口。保留/删除历史数据两种选择均已覆盖。
- 安装升级及用户文件恢复成功后，后台清理可核验的已完成程序备份；保全未知和个人文件，避免清理拖慢安装完成。
- 改善 Windows 签名包的安装逻辑来源校验，兼容签名导致的空间估算变化。
- 修复 macOS 标题栏拖动区对页面操作的影响（NW-430），并更新本地引擎资源与运行输出稳定性修复。

验证：Windows 11 UTM 高、低权限令牌下，安装权限预检各 14 项、卸载回归各 17 项通过；完整 NSIS 编译及相关检查通过。原 Windows 11 23H2 首装解压报错尚未在 UTM 复现，仍需原机用本版验收；新增诊断脚本可收集包签名、目录权限与维护日志。

Windows Beta 按既有流程发布无签名原包；签名场景使用独立本地签名副本验证。
