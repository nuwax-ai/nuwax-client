# 女娲Nuwax 1.0.11（beta）

测试环境接入与本地化默认版：beta 期默认接入测试环境域名；本地化加速对存量安装默认开启（一次性迁移）；界面细节批次（返回图标统一、会话进度胶囊终态等）。

## 变更

### 默认域切换测试环境（beta 期设计行为）

- beta 包首启默认接入测试环境域名（testagent.xspaceagi.com），注册/网关反代/i18n/语言代理探测随域整体切换；实现收进商业版 overlay 种子，社区版默认域不受影响。
- 设置页服务域名预置建议改为「默认域 + 测试域」去重集合：测试期默认测试域，恢复正式后两项并存，可来回切换。

### 本地化加速默认开启（存量安装迁移）

- 本地化加速（loopback gateway）此前只对新安装默认开启，存量安装保持原值；本版补一次性迁移：升级后首次启动自动对齐开启（此后用户显式关闭不再被覆盖）。
- 本地化加速 = 页面资源本地回环加载 + 业务请求反代，弱网/远域名下打开更快。

### 界面与交互（前端）

- 返回图标全仓统一：18 处 antd 箭头统一替换为项目内导航返回图标，视觉一致。
- 会话进度胶囊终态常驻：todo / 终端 / 子智能体 / 文件变更四组内容在任务结束后保留展示，不再消失。
- 模型选择器：选中个人/团队 tab 模型时按钮展示单/多用户图标。
- 项目详情页新建任务功能增强。

### 其他

- 开发态 vite dev server 显式绑定 127.0.0.1，根除 localhost 解析族序漂移导致的连接拒绝（仅影响开发环境）。

## 升级须知

- 含 1.0.10 全部变更（标题栏拖拽手势化）及 1.0.9、1.0.8 全部变更。
- beta 期默认接入测试环境域名，属测试期设计行为；已有登录态/接入配置不受影响，如需切回正式域可在设置页服务域名中切换。
- 数据目录 `~/.nuwax`、更新通道不变，存量 beta 客户端可直接在线更新。
- Windows beta 包为未签名构建（正式版手签）；SmartScreen 提示「未知发布者」选「仍要运行」。mac 双架构自动签名+公证。
