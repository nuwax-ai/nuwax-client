# 女娲Nuwax 1.0.16（beta）

Computer Use 首发预览版：AI 可在本机图形界面「看屏幕、点鼠标」——新增设置页 Computer Use 分组（macOS/Windows，Linux 不支持时自动隐藏）。

## 变更

### Computer Use（新增，默认关闭）

- **开关与状态**：设置页新增 Computer Use 分组——启用开关、运行状态灯（未安装/已启用·待启动/运行中）、权限状态（辅助功能/屏幕录制）、视觉模型配置三行（模型/接口地址/API Key，即点即存）与「测试连接」。
- **随包分发+首用安装**：辅助程序「Nuwax Computer Use」随客户端安装包分发，首次开启前在设置页一键安装到本机稳定路径（安装前校验签名与包标识）。
- **会话能力注入**：开启后向本地 MCP 配置注入 `cua` 条目，会话侧即可使用 56 个（Windows 57 个）电脑操控工具（应用/窗口管理、元素级点击输入、截屏校验、剪贴板等）。
- **macOS 授权引导**：首次开启弹出系统授权引导（辅助功能+屏幕录制，「Nuwax Computer Use」会出现在系统设置列表）；可随时点「去授权 / 检查」复查。辅助程序随主包 Developer ID 签名，授权跨版本升级保留。
- **生命周期**：客户端退出自动停止后台服务；开关关闭即移除会话注入并停机。

### 已知边界（提测口径）

- 视觉循环为配置通道（模型连通性可测），任务级视觉自动化循环后续版本提供；无视觉模型时会话仍可用元素树模式。
- Windows 辅助程序需在用户桌面会话运行（客户端内使用不受影响）；Windows beta 包未签名，SmartScreen 选「仍要运行」。
- 默认域名仍为测试环境（与 1.0.15 相同）。

## 升级须知

- 含 1.0.15 全部变更（提测五问题修复）及此前 beta 版全部变更。
- 数据目录 `~/.nuwax`、更新通道不变，存量 beta 客户端可直接在线更新。
- Computer Use 默认关闭，不影响存量使用；开启即装（约 30MB 磁盘）。
