# Nuwax 3.0.23-beta.11

本版整合 IM 系统通知点击跳转与 CDP 诊断配置通道，供 Windows / macOS 实机验证。

- IM 系统通知点击跳转对应会话：点击系统原生 IM 通知（新消息及结构化分类指令）唤起客户端并定位到对应会话；通知载荷新增结构化指令类型，前端经典/单栏两种布局统一接桥事件完成跳转（前端配套 `86e97c941`）。
- 新增 CDP 诊断配置通道：仅在 userData 下手工放置 `diagnostics.json` 且显式 `cdp.enabled=true` 时开启本机回环（127.0.0.1）调试端口；默认关闭、配置异常一律 fail closed，外部命令行注入的调试开关启动时统一剥离，不提供命令行绕过路径。
- CI：防同名 tag 双 run 竞态（旧 run 自行取消）并浮出构建缓存 MISS 告警。

PC Web 源码固定为 `86e97c94160ed74b76e452640c7bfb3ff0910918`；壳基座保持 `d12d001a0d51e28513cba2b60e76413275cad161`。Beta 从固定源码构建，现有产物仓 pin 保留。

实机验证由用户执行。重点包括：托盘/失焦/后台态下点击通知唤起并落位对应会话、分类指令通知跳转、无 diagnostics.json 时启动行为与默认关闭不回归。
