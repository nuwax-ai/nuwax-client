# 女娲Nuwax 3.0.17-beta.2

本版在正式版 3.0.16 基础上，合入 Windows 10 1511 内嵌终端兼容与系统应用名称修复。

- 旧版 Windows 10 x64 使用独立 WinPTY 终端后端，支持中文输入输出、项目工作目录、窗口缩放、Ctrl+C 和多会话独立运行；新系统继续使用原终端后端。
- 修复 macOS Finder 与原生菜单中的应用名称，并统一 Windows NSIS/MSI 快捷方式、Linux 启动器显示名为「女娲Nuwax」，保留既有安装路径、更新身份与用户数据目录。
- 保留 3.0.16 的 macOS 更新配置、完整中文更新说明及已验证前端更新。发布前校验更新配置、Windows 终端资源和 macOS 实际系统名称。

Windows 10 1511 / Build 10586 真机兼容仍待原反馈人安装本版复测。本版不包含 Pi Agent 接入。

**macOS 升级提示：旧版若提示缺少 `app-update.yml`，请退出客户端，下载完整 DMG 并替换「应用程序」中的旧应用。**
