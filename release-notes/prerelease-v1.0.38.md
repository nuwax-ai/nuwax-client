# 女娲Nuwax 1.0.38（beta）

本版整合桌面客户端问题修复，并同步 2026-09-26 已提测的 Web 前端（`9de6e210cb`）。

## 桌面客户端

- 下载优先使用系统保存能力，并等待文件实际保存完成后反馈结果。
- 改善 Webview 加载失败后的恢复，以及登录态变化时本地网关启停、刷新的一致性。
- 修复主菜单语言跟随应用语言、迟到设置回调覆盖当前语言的问题。
- 终端使用当前会话的工作目录，避免误用其他会话目录；修复部分环境下中文字符显示异常。
- 保留近期版本的 ticket 登录有效性、会话隔离和 Windows 升级修复。

## 内嵌 Web 前端

- 全栈应用开发页复用会话胶囊、智能体详情、文件树、终端和云电脑组件；当前应用开发页隐藏详情入口，胶囊入口位于右上角按钮区最左侧。
- 修复独立智能体会话在宽屏空白的问题。
- 改善停止、恢复和错误事件后的会话收尾，防止旧连接回调干扰新一轮会话。
- 文件变更工具结束后刷新工作区文件，保留任务结束时的兜底刷新。
- 包含已提测 Web 分支中的会话电脑恢复、文件搜索与预览路径条等更新。

## 测试注意

- 本版为 beta 测试渠道，Windows beta 安装包未签名。
- 数据目录仍为 `~/.nuwax`；沿用 ticket 登录策略，升级后如登录态失效请重新登录。
- 请重点回归登录、下载、Webview 恢复、会话停止/恢复、终端目录与中文输入输出，以及文件树/云电脑面板。
- 不包含后端 Java 或移动端修改；真实 Windows/Mac 安装、输入法及真实沙箱联调仍需测试验证。
