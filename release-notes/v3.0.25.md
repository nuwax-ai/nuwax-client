# 女娲Nuwax 3.0.25

## 功能更新

- **本机文件管理更完整**：完善文件面板的预览、编辑保存、新建、删除和重命名，支持文件及文件夹移动、上传、ZIP 导入和工作区导出；移动后同步更新预览与已打开的页签。
- **截图与录屏界面升级**：顶部可切换截图和录屏，选区下方提供浅色标注工具栏；确认前可移动选框、拖动边框或角点调整大小。通用截图确认后直接复制到剪贴板。
- **录屏结果预览**：支持选择 MP4/GIF 格式，录制后可预览、下载或复制；视频支持播放与定位，GIF 支持循环预览。
- **新消息提示音**：客户端设置中新增提示音开关，默认开启，修改即时生效并在重启后保留；密集消息按 3 秒节流，遵循系统通知权限与免打扰设置。

## 体验优化

- 完善 macOS、Windows 和 Linux 的截图、录屏及 GIF 全局快捷键，客户端在后台时也可触发。
- 加快默认高画质 GIF 的生成速度，保留原有输出尺寸、帧率和色数。
- 改善本机文件的离线预览，补齐 Markdown 图片路径和中文 PDF 字符映射支持，优化中文 HTML、旧格式 CSS/JS 及本机资源引用的预览兼容性。

## 问题处理

- 修复 macOS 冷启动后进入截图时，客户端图标可能从 Dock 和应用切换器消失的问题。
- 修复通过菜单或全局快捷键启动截图、MP4/GIF 录制时，误报页面失效、无法启动捕获的问题。
- 修复新会话服务未就绪、首次工作区解析失败或文件上下文恢复时，本机来源判定及重试异常的问题。
- 修复 Linux 上传和 ZIP 导入时，大小写不同的文件名被误判为重复的问题。
- 修复部分带 HTML 包装的消息列表分段显示异常的问题。
- 修复私聊系统通知仍显示旧账号名的问题，优先使用通讯录中当前的备注、昵称等显示名称。

客户端当前使用直连（direct）模式加载线上业务页面，页面相关更新以线上前端部署版本为准。
