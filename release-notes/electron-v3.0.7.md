# 女娲 Nuwax 3.0.7

本版本更新桌面客户端与前端资源，改进启动时的本地网关行为、Windows 未读角标和应用部署服务器设置。

## 修复

- 启动及服务重启时，避免无变化的本地网关重复重启，减少页面连接中断。
- 缩小 Windows 任务栏的 IM 未读角标，改善显示比例。

## 更新

- 应用详情中的部署服务器可在私服列表内直接切换并保存；同步调整相关操作文案。
- 更新前端源码及对应构建产物 pin，正式安装包使用锁定的同一份前端资源。

## 发布验收

核对五平台安装包来源、macOS 签名与公证、Windows 签名及 stable 更新指针；在安装包中验证登录、页面连接、IM 未读角标和应用部署服务器设置。
