# 女娲Nuwax 1.0.7（beta）

版本信息与更新体验版：关于页新增系统信息明细；单栏左栏 logo 旁常显客户端版本号并承担新版本提醒；壳顶栏右上更新入口撤除，更新入口统一收敛。

## 变更

### 关于页「系统信息」明细

「客户端配置 > 关于」的版本区新增四行系统信息：

- **客户端版本**：当前客户端版本号（与页面主版本一致）。
- **界面版本（nuwax pc web）**：当前加载的 nuwax 界面构建版本（含构建提交号）。
- **系统**：操作系统名称、版本与架构（如 macOS 26.6 · arm64）。
- **本地化（loopback）内置版本**：随客户端打包的本地化前端构建版本（含构建提交号），便于排查界面与内置版本不一致的问题。

### 单栏 logo 旁客户端版本徽标

- 单栏（style3）左栏 logo 旁常显客户端版本号（仅客户端内显示，浏览器端不显示）。
- 有新版本时展示主题色下载图标（悬停提示在右侧）：点击弹出**版本更新说明弹窗**（目标版本、发布日期、更新说明）。
- 弹窗内点击「下载更新」后关闭弹窗，logo 旁图标变为**带进度的圆环**（无精确进度时平滑模拟推进）；下载完成后变为重启安装图标，点击即重启安装；失败时显示红色提示图标，可在弹窗内重试。
- 与壳关于页共用同一更新器，不会重复下载。

### 壳顶栏右上更新入口撤除

更新提醒统一由上述 logo 旁徽标承担，壳顶栏不再显示右上更新图标（社区版壳不受影响）。macOS 应用菜单「检查更新」与关于页完整更新流程保持不变。

## 升级须知

- 含 1.0.6 全部变更（客户端反馈与窗口交互版：更新提醒收进关于页、状态圆点语义收窄、沉浸式顶部拖拽与双击）。
- 数据目录 `~/.nuwax`、更新通道不变，存量 beta 客户端可直接在线更新。
- Windows beta 包为未签名构建（正式版手签）；SmartScreen 提示「未知发布者」选「仍要运行」。mac 双架构自动签名+公证。
