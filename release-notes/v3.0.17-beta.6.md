# 女娲Nuwax 3.0.17-beta.6

本版基于 3.0.17-beta.5，集中整合近期桌面客户端 worktree 中的修复与权限引导，供组合验证。

- 新增系统权限引导：首次使用显示权限总览，可逐项查看用途、当前状态和系统设置操作步骤；支持稍后设置、重新检测和重启提示，提供简体中文、繁体中文、香港繁体及英文。设置中的授权页可随时重新进入。
- 截图、录屏遇到权限不足时进入统一授权引导；Windows、Linux 显示对应平台说明，不显示 macOS 的授权开关。
- Windows 卸载默认保留本地数据，只删除安装清单中的程序文件，保留安装目录内额外放入的工作区与文件；需要清除当前用户数据时，可在卸载向导中主动勾选，并查看清除范围。
- Windows 升级恢复安装目录及嵌套目录中的额外文件；遇到与新版文件冲突时保留新版程序，并将旧副本留在恢复备份中。
- 修复 NW-050：模型请求失败、HTTP 400、输出截断、轮次上限及拒答不再误报为正常完成；明确的 HTTP 400 不因近期 MCP 重连重复发送请求。
- 收紧客户端主窗口导航和外部链接的来源、协议校验，封闭旧的自定义 runner 启动入口；现有内置 ACP 引擎继续可用。
- macOS Computer Use 辅助应用改用主应用图标。
- 保留 beta.5 的 Windows 一键下载安装与重启、升级进度、安装中断恢复、早期 Win10 内嵌终端兼容、中文应用名、截图/录屏及剪贴板能力。

验证重点及未纳入项见 [完整验证清单](../docs/acceptance/20261018-beta6-validation.md)。本地文件直访重开、Computer Use 产品化大分支、终端多开和 pi-agent 未纳入；前端源码及产物沿用 beta.5 的固定版本。

旧版首次升级到本版时，交互由旧版更新器决定。Windows beta 沿用现有未签名发布策略；新候选的签名、公证、五平台安装包与公开更新源状态应以实际发布结果为准。
