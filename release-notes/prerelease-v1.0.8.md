# 女娲Nuwax 1.0.8（beta）

设置弹窗重构与更新体验版：设置弹窗整体样式对齐参考设计（无顶栏+自绘左导航+关于钉底）；更新徽标 hover 直接弹更新日志卡片；账号状态区按商业版口径收敛。

## 变更

### 设置弹窗整体重构

- 弹窗去掉顶部标题栏，改为左导航 + 右内容区布局：「关于」固定在导航底部，右栏顶部为当前页标题与关闭按钮。
- 内容区加宽至 1000px，导航项高度 38px，卡片圆角统一 12px；侧栏与内容区之间不再显示竖线，间距收窄、宽度让给内容区。
- 「设置」页改为分组行式布局（服务/高级/系统/目录），行内即点即存；「关于」页信息行式重排（承接 1.0.7 系统信息明细）。

### 更新徽标 hover 日志卡片

- 单栏 logo 旁更新徽标：hover 即弹出更新日志卡片，无需点击。
- 点击徽标直接进入下载流程（不再先弹版本说明弹窗）。
- 更新说明文字展示上限由 500 提升至 2000 字。

### 账号状态区收敛

- 「客户端设置 > 客户端」页账号状态区：已登录仅展示账号与接入域名状态，不再显示「开始会话 / 扫码使用」按钮（会话入口统一在 Web 端）。
- 未登录时展示「前往登录」引导，跳转主窗口登录页。

## 升级须知

- 含 1.0.7 全部变更（版本信息与更新体验版）。
- 数据目录 `~/.nuwax`、更新通道不变，存量 beta 客户端可直接在线更新。
- Windows beta 包为未签名构建（正式版手签）；SmartScreen 提示「未知发布者」选「仍要运行」。mac 双架构自动签名+公证。
