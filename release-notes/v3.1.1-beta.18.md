# Nuwax 3.1.1-beta.18

基于 beta.17 升级引擎与 ACP 链路：

- 引擎 `nuwax-harness` 0.18.33 → 0.18.34：轮内剪枝的重试目标改为按网关真实拒绝点（min(宣称窗口, 观测值)）计算，被拒后不再原样重发；到下限的工具输出跳过并继续压缩其余条目。app-server v2 新增 `inputTooLarge`——"本次输入本身装不进窗口"现在端到端可判（客户端提示缩短输入/换更大窗口模型，不再当作可重试的 provider 故障）。
- 适配器 `@nuwax-ai/nuwax-harness-acp-ts` 升级至 1.2.31（仅引擎 pin 0.18.34）。

本版验证：资源同步（adapter 1.2.31 + 引擎 0.18.34 二进制冒烟）、engines 416/416、主进程 tsc 通过。
