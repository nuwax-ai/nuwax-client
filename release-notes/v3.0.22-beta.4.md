# 女娲Nuwax 3.0.22-beta.4

- 合入 3.0.22 维护修复：改善 macOS Dock 图标常驻及开机启动体验，隐藏会话列表中暂不适合使用的“打开”入口。
- 整合 Computer Use 电脑操作能力，默认关闭。沿用当前会话的 Agent 和模型，无需额外配置绘图模型。
- 电脑操作预览收进客户端窗口，默认右上角，可拖动、关闭、切换正在操作的窗口；支持用户接管和停止。任务列表及历史从托盘的“电脑操作”入口查看。
- 统一客户端与电脑操作助手的权限入口；macOS 授权引导采用白色圆角卡片、圆角应用图标及对应授权对象名称，跟随系统设置窗口并保持可见。
- 改善电脑操作取消、退出及更新时的资源回收，权限请求在退出时可取消。锁屏时暂停电脑操作，解锁后由用户继续。

本版用于 Beta 测试。完整的跨平台权限、多窗口和长时运行验收仍在推进；正式稳定版暂不随本次发布。已安装 3.1 Beta 的用户需手动安装本版；MSI 保持手动安装。
