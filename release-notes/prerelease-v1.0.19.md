# 女娲Nuwax 1.0.19（beta）

Computer Use 三平台收官与项目管理版：Computer Use 补齐 Linux 支持（三平台全矩阵）、外部落盘收进数据目录；本地化加速下消息/资料库 iframe 404 修复；项目管理与首页界面批次。

## 变更

### Computer Use

- Linux 支持加回，达成 mac / Windows / Linux 三平台全矩阵：新增 GNOME Wayland portal-input 输入通道（与上游官方发行同款）、Linux 首次安装流文件名对齐、CI 依赖修正。
- 运行时外部落盘收进数据目录 `~/.nuwax/computer-use`（进程/遥测/历史/浏览器配置等），机器上不再散落 cua-* 独立目录。

### 本地化加速

- 修复本地化加速形态下「消息」「资料库」页面 iframe 404：网关补充微应用前缀反代（临时垫片，微前端方案接入后回收）。

### 项目管理与首页（前端）

- 项目管理：新增常规项目 / 全栈应用 / 三方应用三形态的样式与国际化，项目编辑弹窗与创建接口优化。
- 首页经典任务列表单行化 + 左缘收窄 + hover 交互统一。
- 会话：文件树懒加载回归收口（开面板才拉取、嵌套选中竞态、已加载目录不再全量刷新）；思考行运行中「正在思考」动效；会话恢复终态守卫（滞后快照即到即收敛）。

### 其他

- 品牌拼写统一为 Nuwa（去除变音符）。

## 升级须知

- 含 1.0.18 全部变更（界面细节与 Computer Use 权限提示修复）及此前 beta 版全部变更。
- 数据目录 `~/.nuwax`、更新通道不变，存量 beta 客户端可直接在线更新。
- Windows beta 包为未签名构建（正式版手签）；SmartScreen 提示「未知发布者」选「仍要运行」。mac 双架构自动签名+公证。
