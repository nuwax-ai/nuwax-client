# 女娲Nuwax 1.0.36（beta）

Windows 旧版升级修复候选版：处理旧卸载器遇到安装目录内 `nul` 等保留设备名时，误报“Nuwax 无法关闭”的问题。

## 变更

### Windows 安装与升级

- 升级前检查旧版安装目录。旧卸载器无法正常重命名 `nul` 等 Windows 保留设备名，以及名称末尾带句点或空格的路径；这类失败此前会显示为应用无法关闭。
- 在运行旧卸载器前，将旧安装目录内容搬到同一磁盘上的 `Nuwax-installer-recovery-*` 目录，并记录原路径与保全路径，避免旧卸载器删除工作区或再次卡在异常名称上。
- 新版安装完成后，把原安装路径下除 Electron 程序文件外的目录和文件恢复到原位置，包括自定义名称的工作区；原有程序文件和路径冲突项留在恢复目录供核对。
- 保全或恢复失败时停止相应步骤并给出明确错误与恢复位置；尽可能将已搬移的内容还原到原处。
- 补齐不同安装模式及提权安装流程中的应用进程检查和旧安装目录检查。

### 内置引擎与发布

- 内置 nuwaxcode 升级至 1.17.11，并更新运行时依赖版本与旧缓存识别。
- 五平台构建完成后自动核验并同步 beta，包括未签名的 Windows 安装包，并公开预发布下载；正式版本由独立 stable 流程签名并同步。beta 与 stable 使用各自的更新通道。
- 全新安装的 beta 包默认连接正式业务服务并订阅 beta 更新；升级时保留用户已有的服务域名和更新通道选择。

## 升级须知

- 这是待验证的 beta 修复，需要在此前升级失败的 Windows 真机上，从旧版升级并检查应用启动、工作区与恢复目录；当前不声明已通过实机验证。
- 如安装目录旁出现 `Nuwax-installer-recovery-*`，请先确认工作区和旧文件已找回，再自行清理该目录。
- 恢复目录会保留旧版程序文件和未自动归类的文件，占用一定磁盘空间；核对前请勿删除。
- 存量 beta 客户端可通过「关于」页检查更新。
- 曾经安装 beta 且当前仍连接测试业务域的用户，可在设置里切到正式业务域；升级不会擅自覆盖已有域名设置。
