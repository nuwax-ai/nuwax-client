# Nuwax 3.1.1-beta.19

基于 beta.18 保留现有引擎与 ACP 更新，合入 PR #102：

- 从 IM 等入口打开证书不可信的 HTTPS 页面时，新增风险确认框，说明站点、证书错误与信息泄露风险，默认取消；用户可选择“继续访问（接受风险）”。
- 修复接受证书后只显示灰色背景的问题，同源脚本与依赖可复用已明确授予的证书授权，完整展示页面。
- 确认框明确说明授权在本次客户端运行的共享浏览会话中按主机和当前证书复用，其他窗口也会生效；重启后失效，其他主机、证书或会话保持独立校验。

本版验证：引擎、浏览器与语言一致性定向测试 445 项及主进程类型检查通过；真实 Electron 的取消/重试、带 Cookie 的模块加载、隔离及重启失效回归通过。用户已反馈本机证书访问场景验收通过。
