# Nuwax 3.1.1-beta.19

引擎 nuwax-harness 0.18.37 + ACP 适配器 1.2.32：

- **上下文超窗不再要求换会话**：引擎自动压缩/裁剪并保留对话（含 resume 回放一致、
  轮内中途压缩检查点、按网关真实拒绝点提前调度）；本轮经 `_meta.codex.sessionFailure`
  判定失败并提示重试/缩短输入/换更大窗口模型。
- **超大截图先缩小再丢弃**：工具输出图片入口界此前超限即整张丢弃（12MB Retina 全页
  截图 → 一行 marker，模型完全看不到画面）。现在按「像素 → 单张字节 → 合计字节」
  三级收缩（最长边压到约 1430px、JPEG 质量阶梯 85→75→65、最旧的先缩），仍放不下
  才丢弃。无法解码的 payload 原样透传。
- **effort 档位默认不传**：删掉适配器硬编码的 medium 兜底——无显式档位时引擎在
  wire 上省略该字段，厂商按自己默认执行（GLM-5.3 官方默认 max）。GLM-5.3 不再报
  "effort tiers do not include medium"。客户端同步删除按模型名播种 effort 的逻辑
  （单一策略源：后端显式下发才生效）。
- **审批默认问用户、不问模型**：默认 session mode 从 auto_review 改回
  workspace-write（沙箱完全不变），guardian reviewer 不再抢占客户端的 ask/yolo
  权限弹窗（此前实测 842 次模型审查、0 次权限请求，ask 模式形同虚设）。
- **Responses 协议开关**：provider 名含 `-responses` 时直连引擎原生 Responses 线，
  跳过 chat 翻译默认。
- 未配置任何 provider 时 fail-fast 点名该配什么，不再把请求打到默认域名吃 401。

本版验证：资源同步（adapter 1.2.32 + 引擎 0.18.37 二进制冒烟）、engines 416/416、
主进程 tsc 通过；适配器单测 2583/2583。
