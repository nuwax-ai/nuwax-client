# Nuwax 3.0.11-beta.1

- 首个规范 beta.N 测试版本，标签为 v3.0.11-beta.1，应用、安装包与更新元数据使用完整版本。
- Beta 订阅接收较新的 beta 或正式版；Stable 订阅只接收正式版。升级、转正和重启保留已保存的选择，禁止自动降级。
- 旧客户端请先升级兼容正式版 3.0.10，再接入 beta.N 序列。
- 五平台由 GitHub Actions 构建，成功后自动公开 prerelease 并同步 beta 入口；正式订阅保持 3.0.10。
- 发布同步优先核对 S3 服务端 SHA256，缺少校验值时并行完整读回，减少重复安装包下载并增加逐文件耗时日志。

macOS 安装包签名并公证；Windows beta 安装包未签名，仅供测试。正式版仍需 win-pc EV 签名和真实安装验收。
