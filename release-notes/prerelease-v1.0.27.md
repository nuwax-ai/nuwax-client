# 女娲Nuwax 1.0.27（beta）

更新链路三修与启动体验统一版：修复 Windows 点「更新」误跳网页下载页；「重启更新」全屏加载反馈；启动/安装 loading 统一为图标扫光动效；前端工作空间与界面批次。

## 变更

### 更新链路三修（QA 真机问题）

- 修复 Windows 上点「更新」被误判为 MSI 安装包而跳转网页下载页的问题：注册表卸载项判定容忍 DisplayName 携带的版本后缀，版本比较改为 semver 语义。
- 下载页地址支持构建期配置（NUWAX_DOWNLOAD_PAGE_URL），误判兜底路径可控。

### 更新反馈

- 点击「重启更新」立即进入全屏加载遮罩，覆盖退出清理链的空窗期，不再像无响应；更新失败时错误信息浮出。

### 启动与安装体验

- 启动/安装阶段 loading 统一为应用图标扫光动效，并覆盖 webview 首载（3.5 秒宽限后放行页内 loading），去掉加载中文字案。

### 工作空间与项目（前端）

- 目录选择弹窗支持直接新建与重命名文件夹。
- 项目列表新增归档/收藏筛选；文件树根目录含 workspace.manifest.toml 时才允许自动启动。
- ChatBot 输入框「+」点击直接打开附件选择器；专家提示问题一键填入草稿。

### 界面与交互（前端）

- 布局批次：页头按钮成组换行、Windows 二级菜单位置对齐、style3 二级列标题/沉浸圆角收敛、拖宽分隔条加 hover 延迟防误触、Markdown 正文字号收敛 14px。
- 深色模式可读性修复：经典深色导航前景色与次级文字变量。
- 会话：deepagents TodoWrite 渲染为 V2 todo 卡片、进度胶囊改由头部按钮驱动、修复会话异常结束后输入框卡「执行中」与重进末轮断档、首条消息自动发送时序收敛。
- 远程桌面面板增加容器状态处理；预览页全屏模式尊重客户端工具栏。
- 连接器扫码授权支持二次再授权（已授权且未带连接 ID 的场景）。

## 升级须知

- 含 1.0.26 全部变更（web 修复群：切语言全链/终端/顶栏菜单/右键菜单等）及此前 beta 版全部变更。
- 数据目录 `~/.nuwax`、更新通道不变，存量 beta 客户端可直接在线更新。
- Windows beta 包为未签名构建（正式版手签）；SmartScreen 提示「未知发布者」选「仍要运行」。mac 双架构自动签名+公证。
