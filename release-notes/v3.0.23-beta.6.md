# 女娲Nuwax 3.0.23-beta.6

- 设置中增加本机文件访问开关，默认开启，修改后重启客户端生效。
- Computer Use 任务详情仅在主动点击入口时打开，避免自动弹窗遮挡会话。
- 修复 macOS 通知权限“添加”无法注册应用的问题，并统一消息通知投递方式。
- 优化 macOS 截图与录屏快捷键的前台注册、冲突提示及保存失败回滚。
- 加强外部链接打开的来源和协议校验，拦截危险链接。
- Windows 安装前检查相关磁盘的可用空间，空间不足时提前提示。
- 更新内嵌界面及消息、资料库模块。

## 验收说明

- 已通过社区、商业代码回归及隔离 Electron IPC 校验；首次通知授权、后台真实消息、物理热键冲突和 Windows 安装升级仍需实机验收。
- 直连模式的页面功能以线上前端部署为准；本地化模式使用本次发布固定的前端版本。
