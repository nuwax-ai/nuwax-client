# Nuwax 3.0.14-beta.5

包含 beta.4 的三端截图与录屏改动，并修复 beta.4 构建过程中发现的编码资源工具链问题。beta.4 未完成五平台构建，未公开发布。

## 构建修复

- Windows 固定版本编码运行库通过 pacman 安装事务强制校验可信签名，解决 MSYS2 `pacman-key --verify` 与 keyring 配置不一致的问题；保留包 SHA256、版本和实际工具链检查。
- Windows 编码源码解压使用 MSYS 路径，避免 GNU tar 将盘符误判为远程主机。
- Windows 显式安装 MSYS2 Perl，避免误用 Git 自带 Perl 导致 libvpx 汇编依赖生成错误。
- macOS Intel 使用锁定 libvpx 源码支持的 Darwin target，并为 macOS 发布 runner 显式准备 NASM、pkg-config。

## 截图与录屏

- Linux X11 支持截图、标注和区域录制；Wayland 使用系统授权，在同一授权流中预览和框选。
- 壳菜单支持悬停展开和切换，展示截图、MP4、GIF；既有 WebM API 和 IM 结果句柄兼容。
- Linux 录制时隐藏控件，可通过托盘或切回客户端后使用 Ctrl+Alt+R 停止、Ctrl+Alt+P 暂停/继续。
- 采集来源、窗口策略、编码器差异集中到平台适配层；补齐静止录制、取消复用、状态清理与编码资源打包验证。

## 验收边界

Ubuntu 24.04 GNOME X11 真机及同机隔离 GNOME 46 Wayland 桌面的动态、静止录制已有通过证据。旧版 Sway 的静止源和连续采集仍有已知问题；物理多屏、混合 DPI、KDE、长时间录制、真实 IM 会话回填与正式安装包安装/升级仍需验收。Windows beta 安装包未签名，仅供测试。
