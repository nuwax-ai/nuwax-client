# Nuwax 3.3.0-beta.2

- 更新至 Electron `43.8.12`，内置 SQLite 组件升级至 `better-sqlite3` `13.2.0` 并随客户端构建。
- Linux 原生 Wayland 下，页面加载后主窗口等待首帧超时时会自动显示。
- NW-418：Windows 安装向导遇到安装失败时，显示安装阶段日志的完整路径。
- NW-419：扩大内置页面版本差异提示的关闭按钮。关闭后记住当前后端与线上构建版本，新的构建可再次提示。
- NW-453：主页面就绪后可继续操作。加载较慢的图片或子框架继续在后台加载，主页面加载失败时仍提供恢复入口。
- Windows 打包：统一 uv、Node.js 和 ripgrep 的 ZIP 解压方式。独立验包流程为 Rust 构建指定 Visual Studio 链接器。
