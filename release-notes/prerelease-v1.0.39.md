# 女娲Nuwax 1.0.39（beta）

客户端修复与文件体验版：语言跟随、加载形态生命周期串行化、文件下载原生桥修复、文件树/上传/预览体验批次；内置文件服务升级 1.5.3。

## 变更

### 客户端修复

- 客户端语言设置跟随 web 端 guest 语言（界面语言一处设置全局一致）。
- 本地化加速（loopback）加载形态生命周期串行化，切换竞态不再产生异常形态；加载失败的 webview 自动恢复重载。
- 拖拽热区展开的菜单在拖拽开始时正确关闭；终端连接修复（feat 线系列收口）。
- 文档类产物下载保存改走原生文件桥（此前部分场景被拒），真实落盘结果反馈。

### 文件体验（前端）

- 文件树：工具栏支持新建文件/文件夹（含标题与提示文案）、重命名优化（临时节点处理）、缩进与加载体验改进。
- 文件上传逻辑优化；聊天页文件预览增强（避免不必要的文件树刷新）；文件提交返回提交状态。

### 内置服务

- nuwax-file-server 升级 1.5.3。

### 工具链（内部）

- 双子模块 pin 工具链（sub:update/sub:align）与准备缓存、远端 pin 守卫收口。

## 升级须知

- 含 1.0.38 全部变更及此前版本全部变更。
- 数据目录 `~/.nuwax` 不变；Windows beta 包未签名（SmartScreen 选「仍要运行」）；mac 双架构签名+公证。
