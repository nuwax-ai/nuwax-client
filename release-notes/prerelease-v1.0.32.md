# 女娲Nuwax 1.0.32（beta）

登录态与更新体验强化版：cookie 会话跨网关/业务域镜像、Windows 升级恢复、更新检查提速，前端文件树与多标签批次。

## 变更

### 登录态与安全

- ticket 会话在本地网关与业务域之间镜像同步，登录态跨形态保持一致。
- cookie 登录链路稳定性修复与原生会话校验收紧；过期 ticket 自动清理并留痕可追踪。
- webview 导航过程中保持宿主身份标识。

### Windows 更新可靠性

- 升级安装时主动关闭应用进程树之后，进一步修复「安装目录名异常导致的升级失败」：可从非法安装名状态自动恢复。
- NSIS 安装器资源查找改用 Windows 路径语义。

### 更新体验

- 打开「关于」页时静默刷新一次更新检查；启动阶段的更新检查延迟缩短，新版发现更及时。

### 界面与交互（前端）

- 文件树（Git 源面板）支持虚拟滚动与文件树索引，大仓库浏览更流畅。
- 应用标签行支持刷新与复制链接；移除全栈应用详情页冗余头部。
- 应用切换逻辑优化：状态同步与清理更彻底。
- VNC 代理 URL 生成逻辑优化；远程桌面预览面板样式与加载反馈改进。
- 终端连接修复：常规项目会话判定提取为纯函数并加竞态守卫，防 service_type 错配。
- 问题设置模态框内容与标题支持国际化；i18n 静默失败容错。
- 收银台 guest 页面内嵌对齐宿主工具栏；右键菜单与光标位置对齐。

### 其他

- 网关对上游请求失败的日志补充方法与路径信息（排障增强）。

## 升级须知

- 含 1.0.30/1.0.31 全部变更（更新可靠性、避让收口、file-server 1.5.2）及此前 beta 版全部变更。
- 数据目录 `~/.nuwax`、更新通道不变，存量 beta 客户端可直接在线更新。
- Windows beta 包为未签名构建（正式版手签）；SmartScreen 提示「未知发布者」选「仍要运行」。mac 双架构自动签名+公证。
