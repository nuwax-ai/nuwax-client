# 女娲Nuwax 3.0.20-beta.2

- 本地服务自动选择可用端口，遇到占用自动避让；升级迁移旧配置，设置页无需填写端口。包含服务重启状态、启动错误分类及 Windows 跨盘构建修复。
- Windows 完整安装包增加修复/升级、先修复再卸载入口；处理备份丢失、失效恢复标记和旧卸载器缺失或失败，保留现存个人数据与未知文件。清单损坏或冲突时，自动升级停止，完整包可明确选择保留现场后修复。
- 完善 Windows 安装目录及 per-user/all-users 范围隔离，保护并存副本、未知工作区和其他副本的快捷方式；只清理所选安装自身的程序载荷。
- Windows 安装使用 ZIP 直接解压，减少重复写盘；保留实际安装目录识别、卸载性能、快捷方式及图标修复，按安全保留策略清理过期成功备份。
- 有更新时显示“新版本就绪”，点击或悬停可查看日志；macOS 与 Windows NSIS 可从日志底部一次发起下载、校验、安装和重启。
- PC 重命名弹窗支持输入法组字回车保护，补齐历史记录页入口；记住分组与项目的展开/收起状态。
- PC 附件上传完成前禁止发送并提示状态，支持图片及附件卡片双击打开；Web 导航切换时主动刷新伙伴未读数。
- 保留服务异常不误登出、全局轮询静默、登录态发码 ticket 及女娲Nuwax 系统名称等 3.0 已有修复。

本次 Beta 使用 3.0 维护线及 9.30 前端，替换原 3.1 Beta 订阅入口；已安装 3.1 Beta 的用户需手动安装本版。Windows Beta 安装包未签名，真实安装、升级与卸载体验仍需验收。线上 PC 页面随 PC Web 部署生效。旧客户端升级到本版仍使用旧入口，macOS 一键流程从本版发起后续升级时生效；MSI 保持手动安装。
