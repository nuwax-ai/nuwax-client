# Nuwax 3.1.1-alpha.4 · Dev

- 增加会话插件工作台，提供文件预览、终端以及用户与 Agent 共用的内嵌浏览器。
- 支持保存、恢复和删除命名布局，恢复两栏比例、浮动位置及尺寸；布局方案和用户锁可跨重启保留。
- Agent 可在授权后通过 MCP 编排面板和修改已安装插件的公开配置；布局调整支持版本冲突检查与用户锁，浏览器支持人工接管。
- 增加 Android ADB 手机操作的实验入口。
- 修复工作台接入后的特性分层、打包资源测试清单及前端导航测试适配。
- 修复包含完整插件运行时的 Intel Mac 安装包在深度验签时超时的问题，保留完整签名与公证检查。

本版本通过 Dev 通道提供 Alpha 功能体验。插件工作台仍在完善中，本地动态插件生成与自动修复尚未提供；锁定版 DSH 原生侧栏支持两栏和浮动面板，上下停靠待后续扩展。第三方插件原包兼容性按插件分别验收。
