# Nuwax 3.2.0-beta.11

- Windows 升级成功后，后台清理本次和历史 `Nuwax-preserved-install-files-*` 中可确认的旧程序文件。个人文件和归属不明的内容保留，清理日志记录已删除和可测的剩余字节数。文件被占用时会短暂重试，仍占用的条目留待下次成功安装处理。
- 新窗口浏览器的「更多」菜单新增「强制刷新」。复制链接和切换窗口置顶状态的提示在窗口中央显示。
- 客户端支持通过 USB 连接 Android 手机进行操作。手机控制默认关闭，由用户选择设备并确认授权。缺少 ADB 时可按提示下载安装，USB 连接变化会撤销设备授权。

Windows Beta 提供无签名原包。升级清理的实机验收可查看 `%TEMP%\Nuwax-installer-recovery-active-*-cleanup.log` 中的 `Preserved cleanup:`。
