# 女娲Nuwax 3.0.19

基于 3.0.18 稳定候选，补充登录态验证码发送修复。

- 修复设置页重置密码、绑定邮箱时，有效登录凭证被移除而提示「校验参数异常」的问题。
- 应用、菜单、macOS Finder 及 Windows 卸载列表的名称统一为「女娲Nuwax」。macOS 已有 Dock 固定项的名称刷新仍待安装验收。
- 更新入口可先查看版本日志，再发起升级；下载、安装及失败重试提供进度和状态反馈。
- Windows NSIS 安装版支持一次发起下载、校验、安装并自动重启，需要系统提权时保留 Windows 授权提示。从 3.0.18 及以上版本发起后续升级时生效，旧版本升级仍沿用旧入口步骤。
- 服务异常、网络中断及普通接口错误保留会话，支持恢复后重试；明确的登录失效错误仍进入登录页。
- 内嵌前端的全局积分与通知轮询失败时静默等待下次刷新。
- 包含 Windows 升级中断恢复、安装路径识别、快捷方式图标及卸载数据保全修复。
- 升级备份清理仅处理有完整所有权证据的过期备份，保留最近一次及七天内备份。

本候选包供安装验收；Windows 一键升级完整流程、全用户 UAC、旧图标及 Dock 固定项由安装验收确认后再切正式更新源。
