# 女娲Nuwax 1.0.43（beta）

设备身份升级版：注册链路设备标识算法升级（安装 ID → 硬件 ID，reg/v2 全链就位）；产品 logo 资产更新与文件列表刷新优化。

- deviceId 实现落地：设备标识由安装级 ID 升级为硬件级 ID，注册（reg/v2）与设备识别更稳定（重装不再产生新设备身份）；配套 24 项测试全绿。
- 与 1.0.42 的 reg/v2 端点升级组成完整注册链路升级。

### 界面与交互（前端）

- 产品 logo 资产更新（favicon 缓存标记刷新）。
- 会话文件列表刷新逻辑优化：单层参数拉取、节流调整，长时间会话文件区更稳。
- 含 1.0.42 全部变更（客户端截图问题修复：菜单语言/滚动白区/蓝点未读）。
