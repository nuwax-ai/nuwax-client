# 女娲Nuwax 3.0.22-beta.5

- 统一 3.0.22 维护修复与 Computer Use 到同一开发分支，延续 Beta.4 的电脑操作、权限引导及任务接管能力。Computer Use 默认关闭，使用当前会话的 Agent 和模型。
- 调整 Computer Use 设置卡底部的提示与高级选项布局，统一留白和折叠入口的对齐。
- 优化打包流程：Beta 前端只构建一次供五个平台复用，按源码与工具链缓存未签名原生资源；每次发布仍执行对应的组装、签名、公证和来源校验。实际耗时收益以本轮流水线结果为准。

本版继续用于 Beta 验收，尚未完成全版本验收。已知旧版及 Beta.4 的 macOS 更新退出存在卡住风险，自动更新加强方案尚未纳入本版；如长时间停留在安装中，请正常退出客户端后使用官方 DMG 安装。Windows 首轮任务工具误选、旧安装目录缺失时的维护入口，以及首次授权、多窗口、锁屏恢复和长时运行等场景继续列入验收清单。已安装 3.1 Beta 的用户需手动安装本版；MSI 保持手动安装。
