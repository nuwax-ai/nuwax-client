# 女娲Nuwax 3.1.0-beta.1

3.1 首个集成验收版本，包含 beta.7 的功能与后续客户端修复。

- Windows 安装采用 ZIP 直写方案，修正最终安装器的增量更新校验信息；优化大文件清单卸载预检，并增加等待提示和诊断日志。
- 修复自定义安装目录的卸载器定位和安装范围识别；升级备份保留最新一份，仅清理超过七天且能验证归属的旧备份；保留未知文件和未完成恢复。
- 修复安装后快捷方式图标未刷新、旧 Windows 终端后端选择问题。
- 接入 10 月 PC Web 开发线及对应 IM、资料库微应用。
- 开启本机文件直访，支持现有列表、搜索、预览及下载/导出能力；保留设置开关、目录授权与会话隔离。
- 集成 Computer Use 控制层和能力分层：暂停/继续/停止、浮窗、错误诊断与权限边界；保留 NW-050 的异常终态修复。
- 修复更新日志跨网络分片时的中文、繁体和 emoji 乱码。

本版用于验收。Windows 优化后首装耗时尚待同机对照，现有 QA ZIP 包比 7z 基线大约 30.46%，不作提速比例承诺。win-pc 的真实安装/升级/卸载测试因机器有人使用继续暂停；新包的登录、业务窗口、文件和截图录屏回归需按验收清单完成。pi-agent 和终端多开未纳入；NW-009 尚无独立修复，不标记已解决。

Windows Beta 沿用未签名发布策略；macOS 签名公证和五平台产物状态以发布流水线最终校验为准。完整范围与证据见 [3.1 计划](https://github.com/nuwax-ai/nuwax-client/blob/v3.1.0-beta.1/plans/20261019-client-3.1-beta-plan.md)。
