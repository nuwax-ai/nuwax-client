# Nuwax 3.0.11-beta.3

- 整合 release-channel-rules、desktop-idp-20261008、client-followups-20261007 三个客户端分支。
- 应用、安装包与更新元数据统一使用完整 beta.N 版本。Beta 订阅接收较新的 beta 或正式版，升级和重启保留用户已保存的订阅，禁止自动降级。
- 五平台由 GitHub Actions 构建，全部成功后自动公开 prerelease 并同步 beta 入口；正式订阅保持 3.0.10。旧客户端请先升级兼容正式版 3.0.10。
- Windows 独立卸载遇到文件占用或删除失败时保留卸载登记，并尝试恢复卸载器，解除占用后可以重试。
- 发布同步优先核对 S3 服务端 SHA256，缺少校验值时并行完整读回，减少重复安装包下载并增加逐文件耗时日志。
- 保留业务域顶层 IdP 授权/绑定回调 origin；当前前端 pin 沿用 307a3d6b2，新的三方登录页面未随本包纳入。
- macOS 原生版本字段保持数字格式，应用版本与安装包文件名完整保留 beta 序号。

macOS 安装包签名并公证；Windows beta 安装包未签名，仅供测试。正式版仍需 win-pc EV 签名和真实安装验收。
