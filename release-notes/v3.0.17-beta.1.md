# 女娲Nuwax 3.0.17-beta.1

本版在正式版 3.0.16 基础上合入 Windows 10 1511 内嵌终端兼容修复。

- Windows 10 1511 x64 等尚无 ConPTY 的 Windows 10 系统改用独立 WinPTY 终端后端，保留现有内嵌终端入口；新系统继续使用原终端后端。
- 兼容终端支持中文输入输出、项目工作目录、窗口缩放、Ctrl+C 和多会话独立运行，断连时清理对应进程树。
- 保留 3.0.16 的 macOS 更新配置修复、完整中文更新说明、客户端名称和已验证前端更新；发布前分别校验更新配置与 Windows 终端资源的实际入包内容。

Windows 10 1511 / Build 10586 的最终兼容性仍待原反馈人安装本版复测，现有 Windows 11 回归结果不代表目标系统验收通过。

**macOS 升级提示：旧版若提示缺少 `app-update.yml`，请退出客户端，下载完整 DMG 并替换「应用程序」中的旧应用。**
