# 女娲Nuwax 1.0.6（beta）

客户端反馈与窗口交互版：更新提醒统一收进「关于」页（未登录也可查看版本与更新）；顶栏状态圆点只在「已登录后的确定故障」时出现；沉浸式顶部空白区支持拖动窗口与双击最大化，按钮/文字/输入不再被拖拽层挡住。

## 变更

### 更新提醒与版本号

- 顶栏的更新图标（有新版本/下载中/待安装/失败）现在**只做提醒，点击一律进入「客户端配置 > 关于」**，不再从顶栏直接触发下载或安装——下载、进度、重启安装统一在关于页确认。
- 关于页新增**发布日期与版本说明**展示（来自更新源的元数据，纯文本），检查更新发现新版本时一并显示。
- 更新检查**不依赖登录**：未登录同样能进关于页查看当前版本、检查更新、下载安装。
- 启动时的检查失败（如断网）不再在顶栏制造告警；已发现新版本后的下载/安装失败保留顶栏入口，点击回关于页重试。

### 状态圆点语义收窄

顶栏圆点此前会把「未登录、启动中、服务未跑全」都标成橙色/红色，容易被误读为客户端坏了。现改为**单一红色圆点 = 已登录用户需要处理的确定故障**：

- 仅在**已登录**且出现以下情况时显示：注册流程确认失败、服务启动失败、或服务就绪后连续两轮（约 10 秒）健康探测异常。
- 未登录、启动中、主动停止、单轮探测抖动、正常运行——**一律不显示**。
- 故障恢复、重启成功或退出登录后立即消失；点击圆点进入服务页查看明细与重试。

### 沉浸式顶部拖拽与双击

- 顶部**明确的空白区域**（如导航列顶带、登录页空白处）现在支持按住拖动窗口、双击切换最大化/还原；按钮、文字、菜单、输入框等交互内容不受影响、照常点击。
- 旧版前端页面未上报空白区时，自动回退为顶部 8px 安全窄条拖拽带。
- Windows 窗口控制三键、macOS 红绿灯与壳按钮不受拖拽层影响。

## 升级须知

- 含 1.0.5 全部变更（显示名「女娲Nuwax」、换域弹窗、未登录误报修复、启动等待态优化）；1.0.5 未测试的机型本次一并覆盖。
- 数据目录 `~/.nuwax`、工作空间 `~/Nuwax`、更新通道不变，存量 beta 客户端可直接在线更新。
- Windows beta 包为未签名构建（正式版手签）；SmartScreen 提示「未知发布者」选「仍要运行」。mac 双架构自动签名+公证。
