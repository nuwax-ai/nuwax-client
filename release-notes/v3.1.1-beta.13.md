# Nuwax 3.1.1-beta.13

- 集成扫码登录入口与移动端确认承接，支持本轮三端联调。
- 修复 Windows 自启和历史快捷方式识别，避免其他产品的损坏快捷方式影响关闭自启。
- 增加退出登录的来源诊断，便于定位后台自动退出；尚未将该问题标记为已修复。
- 前端固定到本轮测试候选，包含文件树和预览、用户 Token 排名与趋势、电脑自动选择及 Office 附件粘贴修复。

本 Beta 用于上线前提测；扫码冷/热启动、双端音视频及各平台安装升级仍需完成业务验收。DSH/工作台、ADB、移动 VoIP 和终端持久化不在本次范围。

- 对齐固定 IM 版本的消息恢复验收用例，分别覆盖底层建连、协议 ACK 与后台心跳探测边界。
